租户 / 产品

一个租户 = 一个产品。切换租户后，产品信息、AI 配置、知识库、话术、提示词、已灌水/已回复记录都会整套切换，彼此彻底隔离。

新租户是一张白纸（空知识库/默认提示词），新建后去各 Tab 填写该产品的配置

基本配置

配置你的产品信息和商机筛选关键词

在提示词中用 {product_name} 引用，回复时会自动替换
选择目标后点「应用」，自动设定引导去向并写入话术风格 A/B/C，立即保存生效；措辞可到「话术风格」Tab 微调
在提示词中用 {product_description} 引用
扫描时若发现笔记里已有你这些名字的评论，会直接判定这篇已灌水、跳过 AI，并记入已灌水清单

AI 配置

配置大语言模型 API，支持 DeepSeek 及 OpenAI 兼容接口

选择提供商后，Base URL 和模型会自动匹配
日常使用选「Chat 模型（非推理）」即可：快、便宜、稳定；「推理模型」思考深但慢、费 token，一般用不上

主模型连接失败 / 额度耗尽 / 限流时，自动改用备用模型，避免功能中断。想用主备的话，主模型填通义千问、备用填 DeepSeek 即可。

选择提供商后，Base URL 和模型会自动匹配

话术风格

自定义每个版本的话术风格，AI 生成回复时会按照这些风格要求来写；也可在「基本配置 → 推广目标」一键套用整套样板

话术版本风格配置

自定义每个版本的话术风格与字数范围，AI 生成时会按各版本自己的字数来写（小红书评论超过 300 字发不出去，建议上限不超 300）。字数会自动注入提示词，无需在提示词里再写。

知识库管理

专业知识、个人经历、话术模板统一管理。设置角色后 AI 会自动路由匹配

添加知识库条目

设置角色后，AI 检测到对应角色时优先引用此条目
支持 JPG/PNG，图片会随评论一起发送

提示词管理

👇 点击左侧的场景卡片即可打开该场景的 System / User Prompt 进行编辑（编辑框右下角可拖拽放大）

👈 点击左侧场景卡片打开编辑器
可编辑各场景的提示词，支持拖拽调整编辑框大小

⏱️ 停留时间

统一配置各环节的拟人停留/间隔（单位：毫秒）。默认 = 技术下限（能跑通的最快值）；实际停留会在设定值基础上随机上浮最多 50%，更像真人。注意：贴着下限跑速度最快但风控风险更高，批量操作建议点「填入拟人推荐值」

🤝 互动行为

关注是风控权重最高的动作，可在这里关掉或降频；保存按钮在下方（与停留时间一起保存）

💧 一键灌水

搜索关键词请在插件弹窗左上方输入框填写（单个关键词，回车即搜）；此处查看灌水历史并设置「🔄 循环计划」度控制

🔄 循环计划设置

循环计划每隔一段时间自动搜索并挑选「点赞增长中」的笔记评论（无视已灌水标记，但受下方上限约束，防止打扰博主）
