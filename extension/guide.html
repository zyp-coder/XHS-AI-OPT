功能模块讲解点签切换

从写稿到发出去的一条线：AI 写稿、出图、出片、排期发布，每篇都留档；到点真发到你自己的号上——全都在这台电脑的浏览器里跑。
任务配置

出稿前看的两张默认表——定一次，后面所有稿都按它走。

  • 内容基调：4 种基调挑一种——稿子怎么铺垫、什么时候上广告、广告占多少、写多长。
  • 出图风格：画面风格、印记、配文版式——出图都照这张表来。
笔记档案

这一块的主页——写过的每一篇都在这留档，没写完的草稿也在。

  • 开始一篇：点「✍️ 新建笔记」，填产品和想讲的方向 → AI 先写几份样稿 → 挑中一份 → 逐句改成你的话 → 定稿。
  • 接着做：每行一颗「下一步」，按这篇做到哪了（写稿 / 出图 / 出片 / 预览）直接送过去。
  • 看全貌：图文还是视频、写到哪步了、排到哪天，一张表里全看得见。
发布台

排 + 发一条线。

  • 发布队列：跟着每周排法自动滚 3 周——位子点「＋ 排一篇」从档案里挑；篇写好标「代发」，自动排进最早的空位。
  • 到点自己发：排到点了自动发出去（视频篇连发三家、图文篇两家）。
  • 笔记规划：每周发几篇、分几个阶段、每个阶段讲什么——有 AI 帮忙排。
素材库

备料的地方，一类一个集合。

  • 案例视频段 + 图片混着放；空集合会标「待补充」。
  • 点集合进去看料、传图、连播；写稿出片时直接从这里取。
复盘

发完回头看的地方。

  • 选题盘点：哪类知识、哪个角度讲过了、哪些还没讲——按分类一眼看。
  • 已发复盘：发过的笔记数字趋势都在这——哪篇在涨、互动多少。
从头走一遍：①「任务配置」把基调和出图风格定好（一次性的）→ ②「笔记档案」新建一篇，AI 出样稿你挑一份 → ③ 定稿（要多平台就各改写一版）→ ④ 配图去出图、要视频去出片 → ⑤「发布台」把这篇排进队列（或标「代发」自动排）→ ⑥ 到点自己发 → ⑦「复盘」看数字。
按关键词去刷笔记、扫评论区，把想买的人挑出来，去评论区接话。配词、看清单、真去刷、真去接话，都在这台电脑的浏览器里跑。
任务配置

告诉系统：去哪找、找什么样的人。

  • 词池：搜什么词、每个词跑哪几类笔记、多久跑一次。
  • 盯的账号：同行 / 对标的主页放进来，也跟着刷。
  • 推广目标与承接：评论区接话带什么去向。
队列

到点的活排成一队、串着自动跑。

  • 「词 × 类型」和盯的账号都进队；还有「日常浏览」——按方向随机刷刷首页。
  • 正在跑 / 待跑 / 还没到点 / 已完成，一眼看清。
  • 不想等，也可以现在手动来一轮。
工作台

接话就发生在这。

  • 当前这篇的评论区：哪些评论是想买的、谁在问价，替你挑出来。
  • 挑中的人一键接话；想搜个词现场来一轮，也从这页起。
笔记池

刷过的笔记都进池子，留着底。

  • 按类型标着状态；点开就能去看它的评论区、接话。
  • 哪轮扫的、发了多少条、哪些没打开过——都能回来补。
设置

跑的时候多快、多密。

  • 操作节奏挡位、每步之间停多久、每轮跑多少、多久内不重复。
  • 顺手关注这类互动，开不开。
从头走一遍：①「任务配置」把词、盯的账号、承接方式配好 → ②「队列」到点自己跑——按词去搜、把评论区扫一遍 → ③ 想买的人进「工作台」，挑人一键接话 → ④「笔记池」里留着底，没看到的随时补 → ⑤ 嫌快嫌慢去「设置」调节奏。
谁评论了、谁点赞了、谁私信了，都收拢到这；AI 帮你盯着私信、照着话术帮你回。看、写、回，都在这台电脑的浏览器里跑。
任务配置

定 AI 开口说话的样子。

  • 渠道基调 / 成交引导：AI 说话带什么去向、怎么一步步往成交带。
  • 话术配置：客服话术都存这；「试问答」能先试试它回得像不像你。
通知

平台上所有动静的第一落点。

  • 评论、赞、收藏、关注、新粉丝——来了都在这。
  • 每条旁边能直接：回评 / 让 AI 拟话术 / 去触达。
消息

私信往来都在这。

  • 对方进线等你回；你先开口的，等对方回。
  • AI 照话术先拟好回复，你过一眼就能发出去。
  • 开着「AI客服监听」，新私信自动收进来。
设置

只管一件事：多久扫一次新来的评论和私信。

从头走一遍：①「任务配置」定好去向和话术（还能在试问答里先试两句）→ ② 把「AI客服监听」开上 → ③ 新的评论、点赞、私信自动收进「通知」「消息」→ ④ AI 照话术拟好回复，你过一眼发出去。
