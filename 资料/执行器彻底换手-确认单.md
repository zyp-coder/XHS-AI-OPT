## 一、为什么改（现状体检）

老板的原话：执行器应该只做浏览器里的动作，服务器负责控制它；现在扩展里好像把服务器那些程序也装进去了。

查完三边，结论是：

- **控制关系已经成立**：服务器下单，执行器在客户浏览器里干活、回报，服务器能一键停。
- **分工没有成立**：执行器背着的几乎是整套产品；服务器的"脑子"又是扩展后台的副本。现在是"两头各带一套脑子"。

具体数字：

| 项 | 现状 |
|---|---|
| 执行器包 | 7.7MB |
| 包里最大的东西 | 两套中文字体，原文件约 10MB，主要给本机出片 |
| 界面主文件 | popup.js 1.69MB |
| 后台内核 | exec-core.js 600KB |
| 业务库 | 940KB，含提示词 54KB、截流决策 232KB、排产 87KB、平台适配 70KB |
| 另外还带着 | 设置页 105KB、出片页 74KB、向导页 27KB、引导页 |
| 同源代码 | extension（本机主本）、executor（手包）、web（公网页）三份，靠手工搬 |
| 服务器脑子 | server/bg/background.js 629KB，和 extension 那份 605KB 已分叉 302 行 |
| 版本对话 | 没有。挂线只报名，不说版本、不说会哪些活 |
| 下载包 | 比源目录旧。包里的 theme.js 还是 10-14 的，源目录 10-19 已更新 |

七类活目前是对得上的：发笔记、整页发送、出片、获客、日常浏览、AI客服监听、私信。此前 131 项验收全绿。这轮不是修坏链，是把分层做对。

## 二、目标边界

按"谁做决定、谁动手"切，不按"服务器 / 浏览器"切。

| 角色 | 只管什么 |
|---|---|
| 服务器（脑） | 什么时候干、对谁、干什么、说什么、用哪份料、哪档能用、干完怎么记账 |
| 执行器（手） | 开页、读页面、点、填、传、等、回报；不认识提示词，不排期，不判断业务 |
| 服务器（料） | 稿子、图、片、话术、队列都在服务器，手按单取 |

执行器包里最终只留：

- 挂线、心跳、长轮询、回执；
- 发笔记、评论、私信、监听、浏览这些浏览器动作；
- 一个最小的隐藏工作台（只够机器人跑，没有按钮）；
- 一个隐藏的出片页（只由服务器唤起）；
- 配对/状态面板（客户唯一能点的一页）。

不装：AI Key、提示词、写稿、排产、平台改稿规则、设置页、向导页、引导页、功能锁。

## 三、已定（老板逐条拍板）

### 1. 验收线：1A，并且客户界面一律点不到

- 包里搜不到提示词、写稿、排产、平台改稿规则、设置/向导/引导页。
- 打包按"允许清单"放行，多一个文件就中止。
- **客户能点的只有配对/状态面板**：填配对号、看挂线状态、解绑。
- 最小工作台和出片页如果必须存在，也只能由执行器内部唤起；客户手动打开一律挡页，不能靠改网址、加参数进去。
- 内部页面用一次性票据，跑完即失效；不把可复用的入口留在网址上。
- 即使打包漏了一个产品页面，脏文件扫描也要在发版前拦住。

### 2. 出片留主包：2A

- 出片功能留在主包，不拆第二个包。
- 两套中文字体不再塞进包，第一次出片时从服务器下载。
- 主包目标约 1.5MB；第一次出片多等一会。
- 字体下载失败或没网：用系统字体顶上，并在回执里说明。

### 3. 获客判断：3A

- 服务器给这一轮用什么词、什么筛选、什么节奏，以及每一条该说什么。
- 执行器只做匹配、点击、发送、等待、回报。
- 每扫到一条，手里把这条的公开内容发回服务器，服务器回一句要说的话；发不发、什么时候发，由手里按本轮规则执行。
- 同一轮里重复内容走本地缓存，不重复问服务器。

### 4. 规则生效：4A

- 下一单就带最新规则和话术，立刻生效。
- 改规则、改话术不用重新发客户包，也不用重新挂线。

### 5. 老包：5A

- 现在没有付费客户，直接换新包。
- 老包不再对外发，只留一份给老板自测、出问题能退回。
- 新老协议的字段尽量只加不改，给回滚留一条路。

### 6. 机器人怎么拆：6A

- 抽一个"最小工作台"：只留列表、结果、日志三块和机器人。
- 不装写稿、设置、出片、向导。
- 获客/日常浏览链不重写成"直接读小红书页面"，避免把已经验过的链推倒。
- 先做一次依赖盘点：机器人实际调用了哪些页面元素、哪些后台动作，逐条列出，再定文件去留。
- 如果盘点发现最小工作台离不开 popup.js 的某一段，只抽那一段，不整份搬。

### 7. 账号安全闸：7A

- 静默期、单休、发布占线、节奏这些硬闸留在执行器里。
- 服务器再下一道闸。
- 理由：这是防账号出事的硬限制，不能因为服务器挂了或网络断了就没人拦。

### 8. 出片页：8A

- 出片页算"手"的例外，保留。
- 只由服务器唤起，客户点不到。
- 出片脚本、分幕、封面由服务器随单下发；手里只做渲染和保存。

### 9. 服务器脑子：9A（这轮不动）

- 这轮只换手，不拆服务器上的扩展后台副本。
- 加一张"分叉登记表"：服务器那份允许有自己的网页功能，但每次改动必须登记；没登记的改动，部署前对码时中止。
- 下一轮再评估要不要把服务器脑子抽成独立模块。

### 10. 三份代码的分工：10A

- extension：只做本机自测，不对外发。
- web：公网页，只做界面和服务器调用。
- executor：客户手里的手包，只做动作。
- 新的"脑子"功能一律写服务器；新的"手"动作才写执行器。
- 停用"把 extension 整份搬进 executor"的同步方式；执行器改成自己的小手包，按允许清单维护。

### 11. 功能锁：11A

- 执行器里不再保留"开发版全开"或任何本地档位锁。
- 档位只认服务器派单：服务器不派，手里干不了。
- 包被拿到、被拆开，也不存在"改一改就能全开"的功能表。

### 12. 版本与能力：12A

- 挂线、心跳上报版本号和"会哪些活"。
- 服务器遇到这只手不会的活，直接提示升级，不硬派。
- 执行器收到不认识的命令，也直接拒绝并回报。
- 不做自动更新通道；升级仍是重新装包，但服务器能认出旧版。

## 三·补、干活窗口怎么开、怎么锁（2026-10-21 老板补）

老板原话：机器人要打开浏览器页面去操作，能不能有些动作固定打开它，或者运行时固定有个提示，不让用户去动。

定下来的做法：

- **专用窗口，一趟只开一个**：机器人干活不在客户自己的标签页里跑，另开一个专用窗口；同一趟里换页不新开，干完关。下一趟还是同一个位置、同一个大小。
- **固定开法**：1280×820，屏幕居中；每次派单先找这个窗口，有就摆回原位、提到最前，没有才新建。浏览器不允许把窗口钉死，客户仍可拖走、缩放、关闭。
- **窗口自带地址栏（浏览器的硬限制）**：插件造不出「既没有地址栏、又能接住机器人开的标签」的窗口——浏览器只允许标签在普通窗口之间挪动，所以干活窗口是普通窗口，带地址栏/标签栏。客户改网址也进不了产品页（内部页要一次性通行证），平台页整页锁住；浏览器快捷键拦不死，按下面「拦不死的」处理。
- **干活整页上锁**：机器人操作的页面盖一层锁，点、打字、滚动、右键都不生效；窗口标题和遮罩都写「机器人干活中 · 请勿操作」。
- **锁只挡人手**：不挡机器人自己的点击；客户碰窗口记一次，回执里带「被碰 N 次」。
- **验证码 / 登录失效**：锁自动解开，只让本人处理这一步；处理完自动再锁，机器人接着干。不是把整个工作台开放给客户。
- **干完收尾**：显示结果 3 秒，自动关窗，回到没活。
- **被关掉**：关窗口时手立刻回报；关浏览器 / 杀扩展时心跳断，服务器按掉线处理。这一单停在那一步，不记为成功，不假装发完；重开后手自己挂回来，等服务器重派。
- **拦不死的**：关窗口、关浏览器、杀扩展、切到别的窗口、用浏览器快捷键开新页。前三种 = 停手回报；后两种不拦，但会记进回执。浏览器没有「永远置顶、绝对锁死」这种权限，不对外承诺。

和 1A 的关系：锁层是干活页上的操作层，不是产品界面；客户能点的产品页仍然只有配对/状态面板。验证码解锁只放开平台页面这一步，不放开工作台、设置、出片等产品页。

## 四、按默认冻的（老板没特别说，按推荐走）

### 13. 断网 / 服务器挂了，正在跑的一轮

当前这一步做完就停，不接新活。不拿本地缓存硬跑完一轮。

### 14. 平台改版 / 找不到按钮

停手，回报"卡在哪一步"，带页面截图或页面片段。不自动重试三次，不跳过继续。

### 15. 验证码 / 登录失效 / 素材缺失

停手等人，跟现在一样。不跳过、不自动重试。

### 16. 出片字体下载失败

用系统字体顶上，并回报。不停下等网，也不因此不出片。

## 五、明确不做（防范围膨胀）

- 不把出片搬云端（8A 选的是留主包 + 字体按需下载）。

- 不退役 extension 或 web（10A）。
- 不做自动更新通道（12A）。
- 不保留执行器里的本地功能锁（11A）。
- 不为老包做长期兼容（5A）。
- 不加任何新功能；这轮只做分层、瘦身、收脑、验收。

## 八、风险与回滚

| 风险 | 怎么防 |
|---|---|
| 最小工作台抽出来后获客链跑不起来 | 先做小验证；保留当前整包和源码快照；跑不通就退回"保留精简版 popup.js"的方案，不硬推 |
| 每条都问服务器，一轮变慢 | 本地缓存同一轮重复内容；设置超时；服务器批量预取能预取的部分 |
| 字体按需下载，第一次出片慢 / 没网出不了 | 用系统字体顶上并回报；首次出片前提示要联网 |
| 隐藏页面被懂行的人摸到 | 一次性票据、跑完失效、不把入口留在网址上；包里不放产品页面 |
| 锁层挡住验证码，客户本人没法处理 | 检测到验证码 / 登录失效自动解锁，只放开平台页面这一步；处理完自动再锁，不开放工作台 |
| 客户强关窗口 / 关浏览器 / 杀扩展 | 关窗口立即回报；浏览器/扩展被杀按心跳掉线处理；这一单停在那一步，不记为成功，服务器可重派 |
| 客户把窗口拖走 / 拉大 | 每次派单重新摆回 1280×820 屏幕居中；浏览器不允许钉死，不承诺永远不动 |
| 服务器话术质量下降 | 先用现有话术跑对照，确认再切；保留回退开关 |
| 老包不能再用 | 没有付费客户；保留旧包和旧源码，协议只加不改，出问题能退回 |
| 服务器副本继续漂 | 分叉登记表＋部署前对码；没登记的改动直接中止 |
| 平台改版导致动作失效 | 停手回报，不自动重试；保留页面片段给排查 |

回滚口径：

- 发版前把当前 executor 整包和源码留一份快照，不删。
- 新包先给老板自测；自测通过再换公网下载口。
- 服务器新字段只加不改；老包在过渡期仍能接原有活。
- 出现获客链或发布链回归，先换回旧包，再定位，不在线上硬修。

## 九、验收标准（逐条过）

1. 主包体积 ≤ 2MB（目标约 1.5MB），字体不在包内。
2. 包里搜不到：提示词库、写稿、排产、平台改稿规则、设置/向导/引导页、开发版功能表。
3. 客户只能打开配对/状态面板；工作台和出片页手动打开被挡，改网址、加参数也进不去。
4. 获客一轮：服务器给词、筛选、节奏、每条话术；执行器只做匹配、点击、发送；回执带结果。
5. 发布链：发笔记、整页发送照旧；素材、回执、失败原因都对。
6. 出片：第一次联网下载字体，之后正常；断网用系统字体并回报。
7. AI客服监听、私信照旧。
8. 版本/能力上报：服务器能认出旧版并拒绝它不会的活。
9. 账号安全闸仍在执行器里生效：静默期、单休、节奏、发布占线都拦得住。
10. 断网、验证码、素材缺失三个异常都按第 13–15 条走。
11. EXEC-VERIFY 全量绿；真机发一条、扫一轮、开关客服、出片一次。
12. 公网页的写稿/诊断链不受影响；服务器后台副本这轮不动。
13. 回滚包能装、能挂线、能接原有活。
14. 干活窗口一趟只开一个，开在 1280×820、屏幕居中；窗口是普通窗口（浏览器限制，带地址栏/标签栏），机器人开的平台页自动挪进来；客户改网址进不了产品页。
15. 干活期间整页锁住：点、打字、滚动、右键无效；标题与遮罩都写「机器人干活中 · 请勿操作」；被碰次数进回执。
16. 验证码 / 登录失效只自动解锁这一步，处理完自动再锁；干完 3 秒自动关窗。
17. 关窗口立即回报；关浏览器 / 杀扩展按心跳掉线处理；这一单停在那一步，不记为成功。
