## 二、两条路线对照（同一张工单，两种料）

| | 🎤 路线甲：客户自己念（真人原声） | 🎭 路线乙：照片做数字人 |
|---|---|---|
| 客户交什么 | ① 口播稿（≤250 字）② 一段一段念的录音（页面上点按钮录，电脑或手机都行） | ① 口播稿（≤400 字）② 一张正脸照片 ③ 挑一个音色（可留空「你来挑」） |
| 系统替你做什么 | 自动把稿子断成一段一段、逐段收录音、**合并成一条完整音轨**、缺段催办 | 把三样料收齐、按缺料闸拦住发布 |
| 你做什么 | **本轮不定**（拿到合并好的音轨怎么用由你决定，工单台只记"你交回了成片"） | 剪映里用照片＋文字生成、自己剪、导出 |
| 回片怎么交 | 你把成片传回工单 | 同 |
| 占你工时 | 按同一条额度记（接单量一张表算，不分路线） | 约 20 分钟/条 |

**为什么路线甲也算工单**：他念完不等于有片子，仍然要你交付；两条路共用一套状态与一页工单台，不做两套。

## 三、路由规则（要害：没回片绝不发出去，也不让客白等）

1. **提交工单＝这篇立刻标「代发」**，进周排。但排位子时**只排"发布时间晚于预计交片时刻"的位子**（预计交片＝次日 18:00，旋钮）。
2. **排不上也照常排最近的位子**——不空转等排期。到点没有片，现有**缺料硬闸直接跳过、不记试错**，片回来下一趟自动发。这正是老板说的"过点位顺延/补发没问题"。
3. **客户手动点 ▶ 发布**：按钮灰态，原因直接写在旁边——「⏳ 还在等出片，已等 3 小时（明天 18:00 前给你）」。点不动，不用解释第二遍。
4. **队列行那个「缺料 片 0/1」章**换成工单章：「⏳ 等出片 · 已等 X 小时」／「✅ 片好了，正在取回」。状态词一个都不新增，档案仍是草稿→代发→已发→已归档。
5. **片回来自动落位**：客户机下次打开时自动取回，落进发布素材区（`pub:<篇id>:0`）＋档案成片（`film:<篇id>`），章变 ready，**下一趟到点自动接发**，客户不用再点一遍。
6. **客户不用守着**：交完料可以关掉；工单每变一次状态，客户机下次打开看到通知＋档案行那一句。

## 四、工单状态（页面上的叫法，全是人话）

| 内部 | 界面上显示 | 谁推动 |
|---|---|---|
| await_mat | **等客户交料**（缺哪样写哪样：缺照片 / 还差 3 段没念） | 客户 |
| ready | **料齐了 · 等你做** | 自动 |
| making | **你在做**（你点了「我接这单」） | 你 |
| delivered | **片好了 · 正在送回** | 你传回成片 |
| taken | **已送回 · 等位到点自动发** | 客户机自动取 |
| canceled | **已取消**（只还没被你接走的能取消） | 客户 |
| rejected | **退回补料**（照片不合格，你按这个钮，写明原因） | 你 |

路线甲多一个小节点：录音齐了之后服务器自动合并，合完才进「料齐了」——合好的音轨你在工单卡上直接下载。

## 五、明细（"接多少单，明细记一下"）

- **每单一行流水**：日期、客户称呼、笔记标题、路线、交料时间、你接单时间、交回时间、**这条占用你几分钟**（接单→交回自动算，不用手填）。
- **工单台顶部今日一行**：今日新来 X · 等你做 Y · 今日已交 Z · 今日已用工时 T 小时（对照"每天可做几小时"的额度，用满就变橙）。
- **按天汇总表**（最近 14 天）：日期 / 来单 / 已交 / 未清 / 平均用时。
- **一行「复制今天的明细」**，贴给谁都能看；不做导出文件、不做图表。
- **积压提醒**：「等你做」超过当日额度 → 工单台顶部一条黄横条「今天压了 N 条没交，客户那边还等着」。**不自动撤单、不自动催客户**（第 7 条口径）。

## 六、旋钮（默认值，都在页面上可改，不改代码）

| 名字 | 默认 | 说明 |
|---|---|---|
| 一条大约占用 | **20 分钟** | 用来折算额度，不是硬卡 |
| 每天可做几小时 | **3 小时** | 折算成**每日接单量＝9 单**（1 小时 3 单）；用满不再收新单，明确告诉客户"明天再来" |
| 交片承诺 | **次日 18:00 前** | 就是"今天提、明天好"，写进客户提交后看到的回执句 |
| 甲路线字数上限 | **250 字**（约念 55 秒，最多 12 段） | 250 是"一段一句、点一次念一句，念 12 次不烦"的上限 |
| 乙路线字数上限 | **400 字**（约 1 分半） | 剪映那边你自己剪，可以放宽 |
| 每段断句 | **一句一段，最长 40 字**，超了按逗号再切 | 断完在页面上摆出来，允许手改一次合并/拆开 |

| 料与成片留几天 | **7 天** | 照云端出片同一口径 |
