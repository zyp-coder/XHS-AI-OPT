## 📌 替你按默认定的（不同意就报编号）

**5. 手动那条路保留一半。** 整列撤了，「点笔记 → 看评论 → 找商机 → 手动发」总得有个门：记录里每篇卡片右上角留一颗小「打开」，点了才切成原来的评论／商机视图，顶上多一颗「⬅ 回到这一趟」。不点就永远停在记录上。
　（另一条路是彻底删掉手动评论，那评论刷新／自动评论／评论目的三样一起撤——不建议，删了就回不来。）

**6. 跟列表绑着的东西。**
- 搜索进度不再单开一屏：过程看日志，顶上那一行小字报「正在搜…／搜到 N 篇」。
- 「⬅ 返回列表」改成「⬅ 回到这一趟」。
- 打开态高亮、笔记登记照旧（登记还给「笔记池」用）。

**7. 关键词 / 评论策略**：都在顶上一行做收起式入口，点开还是原来那块（一份配置，跟「队列」页共用）。

**8. 空态。**
- 今天还没跑：中间一句「今天还没跑过 —— 去队列页看看下一步什么时候跑」。
- 执行器没回话：照常铺它最后一次回的记录，上面一行灰字「执行器没回话，下面是它最后一次回的」。

**9. 跨天**：只铺今天的（跟顶上三段条一致），昨天的翻不到。

**10. 抖音签不动**：记录块只在「📕 小红书」签出现，抖音签照旧显示问价线索。

## 验收口径（实现完对着这几条看）
1. 工作台上看不到左边那列笔记卡片；平台页签下面一行是「🔍 搜索 · 队列 · 关键词 ▾ · 评论策略 ▾」。
2. 中间从上到下：这一趟的抬头（几点到几点、类型 × 词、搜到几篇 / 评论几条 / 收进清单几人）→ 一篇一张卡（标题、第几篇共几篇、这轮评论了几条、评论正文、失败红字）。
3. 底下日志还在，按条滚；没有「📋 这一趟明细」这颗按钮了。
4. 点卡片的「打开」能回到原来的评论视图，「⬅ 回到这一趟」能退回记录。
5. 今天没跑／执行器离线／正在跑，三种状态的提示都要对得上。

| 状态 | 结果 |

| 执行器没挂线 | 灰字「🖐 执行器没回话，下面是它最后一次回的（16:58）…」，记录照常铺 |
| 打开 → 回来 | 点「打开」记录块换成「📄 标题 ＋ ⬅ 回到这一趟」，中间区不被小窗状态卡顶掉；点回来原样恢复 |
| 平台页签 | 抖音签记录块收起、回小红书签立刻回来（不用等 5 秒轮询） |
| 控制台 | 无报错、无警告 |

复验中修掉两处：
1. 「打开」那张卡原来画在 `#mainContent` 里，小窗模式每 2 秒会被状态卡重写 → 改画在记录块自己的位置。
2. 点一次「打开」会下一条打开单，记录跟着这条空单跳到「现在」→ 锚定这一趟时把「打开单」排除掉。
