# 房奴计算器 产品简述（可直接复制到扩展设置→基本配置→产品简介）

## 一句话定位
买房贷款全流程工具：从"我能贷多少"到"怎么还最省"，覆盖买房前、还贷中、还贷后三大阶段的真实需求。

## 玩法说明
微信小程序「房奴计算器」，打开即用、免费、无广告。底部4个主功能：快问快答、贷款计算、提前还款、我的（工具集）。所有计算都是输入几个数字、当场出结果，结果页带图表和解读，不是干巴巴的数字。

## 核心功能详解

### 1. 贷款计算（首页）
- 输入：贷款总额（万）、年利率（%）、贷款年限、还款方式
- 支持3种还款方式：等额本息（月供固定）、等额本金（逐月递减）、组合贷（公积金+商贷分比例）
- 输出：每月月供、总利息、总还款额、还款明细表
- 亮点：利率输入框联动LPR，可以±0.01%微调（长按连续调整），旁边实时对比两种还款方式的月供和总利息差异，还带LPR历年走势折线图

### 2. 提前还款（专门页面）
- 提前还款测算：填剩余本金、利率、已还月数、准备还的金额 → 立即算出省多少利息、贷款能缩短多少年
- 最佳时机分析：自动判断你现在处于"黄金期/中段/末期"，并对比"现在还 vs 1年后 vs 3年后 vs 5年后还"哪个更划算（图表展示）
- 违约金计算器：支持两种算法——按还款金额的百分比、按N个月利息
- 缩期 vs 减月供对比：同样还10万，两种方式省息差异直接摆出来

### 3. 工具集（我的页，11个专业工具）
- 公积金可贷额度计算：输入账户余额、月缴存额 → 算出最大可贷额度，并明确告诉你被哪个因素限制（余额不够/还款能力不够/到城市上限）
- 收入反推可贷额度：输入月收入 → 反推银行最多能贷给你多少（按月供≤收入50%的标准）
- 还款方式变更对比：等额本息↔等额本金互转的利息差和月供变化
- 商转公测算：输入剩余贷款、当前商贷利率 → 对比转公积金贷前后的月供和总利息，按60万/80万/100万等多个公积金额度梯度展示
- 个税抵扣计算：输入年收入 → 算出房贷利息每月抵扣1000元后，每月/每年/20年总共能省多少税
- 利率BP诊断：输入你的实际利率和当期LPR → 算出你的利率是上浮还是下浮、几个BP、贵不贵
- 重定价日计算：输入贷款发放日 → 算出你下次利率调整是什么时候、还剩多少天
- 贷款压力测试：输入月收入、月固定支出、月供 → 得出压力等级（非常轻松/轻松/适中偏紧/压力较大/超出承受）和具体建议
- 还款日历：生成你整个贷款周期的还款计划日历
- 贷款总结：汇总你的贷款关键信息一页看清
- 贷款诊断：综合诊断你的贷款方案健康度

### 4. 快问快答（49个买房人真实问题，一半以上是工具不是文章）
按买房阶段组织（贷前/贷中/贷后/买房收房），每个问题分两类，全部当场有产出：

**贷款计算类（18个）—— 点进去就是一个计算器，输入数字立刻出结果**
- 贷前：公积金能贷多少（输余额+月缴存→直接出可贷额度+被哪个因素卡住）、收入够不够贷、等额本息vs等额本金省多少、30年还是20年划算、贷款压力测试
- 贷中：提前还款违约金能免吗、最佳还款时机、部分还款后月供重算、提前结清省多少利息、商转公测算、改等额本金划算吗、违约金计算器
- 贷后：LPR加点诊断（上浮还是下浮几个BP）、房贷利息抵个税省多少、下次利率调整日期倒计时、LPR下调后月供什么时候变
- 联动大计算器：结果页底部一键跳转「贷款计算」或「提前还款」，刚才填过的金额、利率、年限自动带过去，不用重输

**政策阅读类（31个）—— 通俗解答 + 官方查询指引**
- 贷中：银行允许提前还款吗要预约吗、每月几号扣款逾期怎么办、怎么设置还款提醒、还款方式变更流程、公积金余额提取还房贷（月冲/年冲）、贷款期限能延长吗、变更还款账户
- 贷前：首付比例怎么定、征信不好能贷款吗、2026年最新政策解读、贷款合同签约注意事项、房贷利率走势与选择
- 贷后：结清证明怎么开、解押流程怎么走、选浮动还是固定利率、公积金冲还贷、提前还款后要办什么手续
- 买房收房：买房全流程、选房攻略、费用清单、二手房交易、收房验房、契税、限购、公摊、房产证、装修预算、五证合同陷阱、法拍房保障房
- 每篇都附「去哪查」：银行客服电话、官网、公积金12329；部分文章底部也带计算器快捷跳转（组合贷对比、提前还款vs理财）

## 为什么用户会信这个工具
- 所有算法基于银行通用公式（等额本息/等额本金标准公式），不是拍脑袋
- 数据来源明确：公积金政策、LPR历史、个税政策都是官方公开数据，小程序内可查
- 免费无广告，用完即走，没有套路

准备买房的刚需族、正在还贷想提前还款的人、纠结商转公/改还款方式的人、想算个税抵扣的人。
