## 二、改了什么

### `executor/lib/pub-adapt.js`（小红书适配）

1. **`usable()` 加一条**：`b.isConnected === false` 直接判不可点——旧节点被 React 换掉后不再对着空气点。
2. **新增 `pageHints()`**：收页面上 `role=dialog / modal / toast / message / notice` 的可见文字（最多 5 条、每条 120 字、去重），失败时一起带回。
3. **新增 `findConfirm()`**：在文档和 shadow root 里找「发布类」浮层，只认：可见、不是整页外壳（宽高 ≤ 95% 视口）、`position` 为 fixed/absolute、文字 ≤ 300 字且含「发布」、排除「违规/风险/失败/错误/修改/请重新」，按钮文案只认
   `确认发布 / 继续发布 / 发布 / 确定发布 / 立即发布 / 确认 / 继续`，优先 BUTTON。
4. **灰按钮不点**：开页后等它亮，最多 **3 分钟（180 秒）**；等不到直接报「发布按钮一直是灰的（等了 3 分钟）」，并把页面提示带上。
5. **重点击每轮先再等**：一轮点完没动静、按钮又变灰，这一轮先等（≤60 秒），等不到就收手，不再盲点。
6. **点完观察中自动点确认框**：每轮观察里发现发布类浮层就点（最多 3 次），点完继续观察。
7. **失败回执带原话**：`checkDone` 判失败时带 `state.hint / state.url`；4 轮都没成时也带最后一次的页面提示。

### `executor/exec-core.js` → `_npPubBgRunXhs`（发布链）

1. **填字超时补一刀**：FILL 注入超时后等 3 秒，先跑新增的 `NPA_XHS_FILL_STATE` 自查标题/正文里到底有没有字——已经填上就算成功（不重复灌）；没填上再补试一次（90 秒）。
2. **SEND 超时 200s → 420s**：给「等按钮亮 + 点 4 轮 + 每轮再等」留足时间。
3. **失败回执拼页面提示**：`页面提示：…；页面 <url>`，队列里能直接看到平台在说什么。

### 新增的自查小函数

`NPA_XHS_FILL_STATE`：读标题输入框的 `value` 与正文编辑器的 `innerText`，返回 `{title, body, found}`。
