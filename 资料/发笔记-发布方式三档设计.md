## 〇、一句话

每篇的「到点怎么发」从原来的一档（自动发）拆成三档：**📦 只备料（连页面都不开）→ ✋ 备好等您点（默认：填好一切、停在发布按钮前，您点一下）→ 🚀 全自动发（原行为）**。默认档＝「备好等您点」；您手点发布后**扩展自动核收**（标已发 / 落回执），把「人点一下」这半程也接上自动化。发布页当场再做一轮节奏加厚（进页安顿 / 落字前后停顿 / 全自动档发布节拍）。

## 一、三档怎么工作

| 档 | 行尾钮 | 到点这趟干什么 | 开的页面 | 回执 |
|---|---|---|---|---|
| 🚀 全自动发 | 🚀 全自动 | 改稿 → 词表 → 风控检查 → 开页面 → 传料填字 → **自己点发布** | 开，发完关 | ✅ 已发 |
| ✋ 备好等您点（默认） | ✋ 备好等您点 | 改稿 → 词表 → 风控检查 → 开页面 → 传料填字 → **停在发布按钮前**，弹桌面通知「一篇填好了、等你点发布」 | 开，留着等您 | ✋ 已备好 →（您点完）自动核收 → ✅ 已发 |
| 📦 只备料 | 📦 只备料 | 改稿 → 词表 → 风控检查 → **就到这里**；不开平台页面、不传料不填字 | 不开 | 📦 备好待发 |

三种档下**改稿 / 词表扫 / 风控检查完全一样**——变的是「开不开页面、点不点发布」这一截。任何一式真发出去（含手发核收）都照记「发笔记」一笔总账（行为层加固）。

每行一篇一个档，存在 `np_pub_modes`：`{'位子key|篇id': 'auto'|'hold'|'prep'}`。

## 二、默认值与迁移口径

- **缺省（没记过）＝ ✋ 备好等您点**——这是本批对老数据唯一的有意变更：此前没开过「过目」的篇到点会自己发，现在到点会停在发布按钮前等人点。
- 旧键 `np_pub_watch`（true＝过目）直接停用、不再读：旧 true 与新默认 hold 行为一致；旧 false 改走新默认也是有意为之。
- 行尾钮是**三态循环钮**：点一下依次轮换 ✋ 备好等您点 → 📦 只备料 → 🚀 全自动 → 回 ✋（往保守方向一步到位优先）；title 永远预告「下一档是什么」。
- 行上徽章跟着档走：到点自动发 / 到点等你过目 / 到点只备料。

## 三、「备好等您点」的闭环：手发核收

旧缺口：过目模式停在发布前之后，**您手点发布、扩展不知道**——回执永远停在「已填好」，篇不标已发、料不清。本批补齐：

1. **交单**：点桌面通知 / 工作台「去点发布」→ 切到那个已填好的标签页 ＋ 记一笔 `np_pub_handover` `{id, p, tabId, windowId, at}`。
2. **核收**：① 那个标签页 URL 变化 / 加载完成时；② 口袋里每分钟一次兜底轮询（有 handover 记录才开）。注入检测看成功特征——
   - 📕 小红书：URL 跳 `/publish/success` 或页面出现「发布成功」（**已验**）；
   - 🎵 抖音 / 🎥 视频号：跳作品管理 / 列表页 或出现「发布成功 / 发表成功」（**尽力而为，待真机校准**）。
3. **收口**：命中 → 回执该家改 `{ok:true, url, hand:true}`（标「手发成功」）＋ 清该家卡点 ＋ 记「发笔记」一笔；全平台都 ok → 篇标「已发」、清代发区料（与自动档收口同口径）＋ 一条轻通知「已核收」。
4. **不打扰**：没命中就一直等——标签页关了、或超 6 小时，记录自动清掉（回执保持「已备好」态，可「🔁 重试」或改档再发）。

## 六、边界：管得了什么、管不了什么
