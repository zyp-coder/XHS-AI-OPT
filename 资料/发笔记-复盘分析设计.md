## 〇、这一页要回答的两个问题（老板原话口径）

1. **我知识库里哪些选题还没跑过？给我一个规划。**
2. **我已经发出去的笔记，哪些点赞高、哪些涨得快？给我复盘。**

一句话：现在散的「写过 N 次」徽章（写稿①）、「按规划发」卡（写稿「选话题」步）、「本周已发 N 篇」（档案页顶）是三块碎片，合成一页 **复盘分析**。

## 一、页面落点与结构

- **位置**：左栏「发笔记」二级新增一页 **📊 复盘分析**（挨着 任务配置 / 笔记档案 / 发布台 / 素材库）。
- **结构**：一页两块，从上到下
  - **上块 · 选题盘点与规划** —— 知识库选题按「没写过 / 写了没发 / 已发」三堆摆，可勾选排进计划。
  - **下块 · 已发复盘** —— 已发笔记按点赞 / 日均点赞 / 收藏 / 评论排榜，配一句 AI 结论。
- **不动**：`诊断&配置 → 规划` 保持原样（AI 生成排产表那颗钮不搬家），本页**只读**它 + **可写回本周排期**。

## 三、📌 替你按默认定的（扫一眼，不同意就翻）

1. **数据另开一份独立存储**（如 `np_note_stats`），**不挂在档案那一档上**。理由：档案有条数上限（`NP_NOTES_CAP = 300`），超限会先丢最旧的「已归档 / 已发」——点赞快照挂上去会跟着一起被清掉。
2. **页面上展示的顺序**：上块（选题盘点与规划）在下块（已发复盘）之上。理由：先补料再复盘是顺手的动线。
3. **不新增左栏一级项**，只做「发笔记」二级页（跟 素材库 / 发布台 同级）。
4. **榜单默认按日均点赞降序**，可切「点赞 / 收藏 / 评论 / 日均」四根排序轴。
5. 「没写过」清单**按知识库的分组摆**（沿用现有 `知识库` 分组），不给它另建一套分类。

## 六、验收口径（demo 要过什么）

1. 三态分堆准确：一条素材在草稿里出现过 → 落「写了没发」；状态标「已发」→ 落「已发」；库里没碰过 → 「没写过」。
2. 勾几条 → 点排进计划 → 排产表（`note_plan.items`）真的多出这几条，回到写稿「选话题」那一步能看到。
3. 已发复盘：榜单四条排序轴都能切；日均点赞 = 点赞 ÷ 发布天数，数字对得上。
4. 抓一次 → 快照落地；同一天再抓 → 覆盖，不新增一条。
5. 空态 / 抓失败 / 读不到数 三种情况都有话说，不白屏。
6. demo 页与真实扩展逐字镜像（沿用老板 10-06 定的规矩：先读 `popup.js` 真实渲染函数再动手，不许发明简化版）。

## 七、二十改（2026-10-08 老板口头改单，已落 demo）

老板看完十八改 demo 后提两条，② 明确「就这样 OK」：

1. **一页两块 → 两个三级页签**：「📋 选题盘点与规划」/「📈 已发复盘」，页面左上角切换（沿用任务配置的 `nt-tabs` 页签样式）。
2. **① 不按「三堆」摆了**——理由：时间一长几乎全落「已发」，三堆退化没用。改成 **按知识库的「类」汇总**：
   - 每类一行：🏷 类名 · 共 N 条 · ✅ 已发 N / ✍️ 写了没发 N / 🆕 没写过 N（零的不显示）· **这类已发的表现 = 这类已发笔记的日均赞**（没发过 →「还没发过」；没抓过主页 →「—」）。
   - **默认收着**先看汇总；点开一类看该类的条目（按 没写过 → 写了没发 → 已发 排），「没写过」的照旧勾选 →「排进本周计划」。
   - 类级结论一句（绿框）：表现最带劲的类 → 多讲；条目全讲过的类 → 想接着讲先补知识库；还有 N 条没动过 → 勾上排本周。
   - 类＝知识库里的分组（真实版＝知识条目的 `category` 分组）；条目的三态仍按档案推，不另记账。
3. **② 已发复盘**：内容不动（排序轴 / 榜单 / 剔除 / 两位次快照差），只把 ② 结论里原来「没写过的 N 条建议排进本周」那句删掉（那条建议挪进 ① 的类级结论）。

**被本改单覆盖的旧条目**：一、结构里「上块按三堆摆」→ 改为「上块按类汇总」；二、#2 的三态口径**仍然有效**（照旧按档案推），只是展示从「三堆」改为「类内标注＋类级计数」；三、#5「没写过清单按知识库分组摆」→ 升级为「按分组汇总三态」。其余 16 条决定与 🚫 不做清单不变。

## 八、三十一改（2026-10-08）—— B12 picker + KB 录入页 UX 同步落地

本次落两块，不改原结构：

### ① B12 · 复盘分析「🆕 没写过」加 picker（`➕ 加进下次规划`）

「按类汇总」里每类的「还没写过」条目原本只能**勾进排产表**——但排产表是新建一篇的节奏，对「库里已有空白但没动」的口径不顺手。加 picker：

- 每条「还没写过」右边多一颗按钮 **`➕ 加进下次规划`**（淡红描边，红字）
- 点了不勾池、就地弹 picker：候选池 = 所有 `status ∈ {草稿, 代发}` 的档案，按 `title` 升序
- 选一篇 → 调 `npNoteAddKb(noteId, { id, title, cat })`，把这条知识直接挂到那一篇档案的 `kb[]` 上
- 同 id 已挂 → 标「（这条知识之前已挂过，不重复加）」，picker 关
- 不写 `note_plan.items`（与「📥 排进本周计划」是两件事）
- 空态：候选池 0 条 → 一句「还没有草稿/代发的档案可挑——先去「发笔记 → 档案」建一篇草稿。」

—— 见 `资料/复盘分析-页契约.md` §2.6、契约 `资料/发笔记-数据契约补丁.md` §4.4。

### ② KB 录入页 UX 补齐（实时校验）

录入页从「写完再报错」升级为「一边写一边标红 / 字数一接近上限就橙」：

- **标题 / 正文 / 分类**：任一为空 → 红边（`.diag-kb-input-bad`）
- **标题字数**：右下角 `N/80`，≥64 → 数字变橙（`.warn`），**不拒存**、不弹 tip
- **分类 = 「默认」**：黄边（`.diag-kb-input-warn`）+ 字段下方黄字 tip「⚠ 「默认」= 未分类，建议换成 8 类之一（产品介绍 / 玩法与机制 / 数据·成本 / 客户痛点 / 避坑经验 / 个人经历 / 使用技巧 / 笔记架构）」——**过渡态软警示、不拒存**（KB_CAT 升级历史包袱，详见 `资料/知识库维护口径.md` §五）
- **标签**：解析失败 → 红边 + 红字 tip「❌ 标签格式有误：用逗号 / 顿号 / 换行分隔，或 JSON 数组（如 ["A","B"]）」；解析成功 → 灰字「已解析 N 个标签」；空 → 灰字「示例：流量焦虑、付费转化、复购」
- 触发时机 = 打开编辑面板 / 四个字段任一 oninput / 保存失败时（让红框与红字同步）
- 文案锁死在 `资料/知识库维护口径.md` §三，逐字落 demo

## 九、二十三改（2026-10-09）—— 复盘增补落地（#10，已进真实扩展）

对照 demo（`?v=42`）把复盘补齐落进真实扩展；本节自此是本页的落地口径：

### ① 选题盘点的形态：5 列大表（取代「默认收着、点开看」）

每类一行，五列：**知识库类 ｜ 总条目 ｜ 还差 ｜ 结论 · 行末查 ｜ 表现**。结论四档 chip：

| 档 | chip | 触发 |
|---|---|---|
| 全空白 | 🟥 全空白 | 该类条目一条没写过 |
| 有空白 + 有表现 | 🟨 有空白 + 有表现 | 部分讲过（行下挂「还没写过」子行） |
| 全讲过 | 🟩 全讲过 | 该类条目全写过 |
| 待归类 | 🟧 待归类 | 「默认」类（老档没归类） |

行悬停带 tip；排序：全空白 → 有空白 + 有表现 → 全讲过 → 空类（不显示）；同档按类名拼音。

### ② 「还没写过」子行

「有空白 + 有表现」的类行下挂一条子行：**还没写过：** + 条目 chips（前 8 条 + 「… 等 N 条」）；点 chip 开弹层并高亮这一条。

### ③ 「表现」列四档（照真实扩展逐字）

| 情形 | 显示 |
|---|---|
| 该类一篇没发 | 还没发过 |
| 没抓过主页 | 「—」（tip：点赞是抓主页顺带读的——先抓一次才有） |
| 发过但没读到数 | 已发 N 篇 · 表现还没读到 |
| 有数 | 已发 N 篇 · 日均赞 ≈X |

**日均赞 = 均值**：各已发篇 dayAvg（点赞 ÷ 发布天数）取平均；中位数不做。

### ④ 「📅 排进本周计划」走弹层

点类行 / 子行条目弹清单（已写过 N 篇 / 还没写过 N 条）；「还没写过」勾选维持勾选池（按标题）；已被排过的条目挂「📅 已排 周X」徽、不给勾选框；底部「📅 排进本周计划（已勾 N 条）」写回 `note_plan.items`（type howto；在本周排法带「知识」的日子轮着排，没有就落周一；按标题去重）→ toast「已把 N 条排进本周计划——写回排产表了」+ 重开弹层。「➕ 加进下次规划」picker 不变（见 §八）。

### ⑤ 「📚 按规划发」卡（写稿「选话题」步）

「📚 按规划发（已成稿 N/M）」+ 每周固定 weekText + 「下一篇该发：N. 标题」（类型·写法 / 系列 / 凭据 / 📅栏目徽）+「按这条写」钮；已选时显示「已选：第 N 篇…」+「不用规划，自己选话题」；全成稿后提示去「诊断&配置 → 规划」重新生成。

—— 落点：`extension/popup.js`（npUsageByKbCat / npAuditTopicsAlgo / npAuditOpenCat / npAuditPlanPush / npPlanCardHtml）；页签皮肤用复盘页自带的 `.audit-tabs`（未沿用 nt-tabs）；demo `?v=42`（二十三改）；回归日志 `tmp/check10_run2.log`（全 PASS，EXIT=0）。

**被本节覆盖的旧条目**：§七 二十改 #2 的「每类一行…默认收着、点开看条目」→ 升级为 5 列表格 + 子行 + 弹层清单（「按类汇总」的精神不变）；「日均赞」口径统一为均值；② 的「排序轴 / 剔除」**未落地**（行序固定发表日倒序，见页契约 §3.4）。
