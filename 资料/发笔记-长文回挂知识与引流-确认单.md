# 发笔记 · 长文回挂知识/引流两条线 · 确认单（2026-10-21 冻结）

一句话：撤掉「独立长文四屏流＋底子选腔」，两张长文卡各自回到知识/引流线——知识＝挑知识 → 改稿 → 出长文 → 预览；引流＝挑稿 → 改稿 → 出长文 → 预览；腔由入口定死。

> 本单只管「新建长文」和今后两条线的长文。2026-10-20《长文独立方向与预览-确认单》里「独立方向、底子选腔」那一部分由本单取代；**老 `dir='l'` 篇不迁移、继续走老四屏**（老板 2026-10-21 选 C）。统一预览那一层保留，长文预览也用同一张。

## ✅ 已定（老板 2026-10-21 圈选）

1. **腔由入口定死**：📚 知识那张长文卡 → 🔬 科普腔；🔥 引流那张 → 🗣 人设腔。不再有选腔界面，只在「出长文」屏显示一行说明。
2. **知识线流程**：挑知识 → 改稿（短稿）→ ✨ 出长文（拿改好的短稿排长文）→ 👀 预览 → ✓ 存好回档案。
3. **引流线流程**：挑稿（现有「📄 出几版」，五条线里含热点、梗）→ 改稿 → ✨ 出长文 → 👀 预览 → ✓ 存好回档案。
4. **撤掉「底子」整屏**：不再单独敲主题、不再粘现成稿、不再选腔。长文的题材与内容都从改稿那份短稿来。
5. **出长文不自动写**：进这一屏只摆大钮，点了才调 AI；出稿铺在文本框里能直接改。
6. **短稿改过以后**：旧长文保留，但在「出长文」屏标「正文改过了，这版长文是旧的」，给一颗「重新出长文」；不自动重烧。
7. **预览显示全套**：标题、长文全文、字数、腔调一行、发布方式「小红书长文模式」、状态。预览不拦路，但长文空着不让收口。
8. **收口**：只做「✓ 存好，回档案」，标「代发」；发布仍去发布台手动走（长文发布 B 档不变，不自动发）。
9. **档案「📝 改出长文」不动**（老板 2026-10-21 追加：「不要改出长文的功能了」）：这一颗保持现状——点了仍走老 `dir='l'` 四屏流（旧稿当底、不另开重复一篇）；本轮不改它的行为、不接进新两步长文站。
10. **字数各按各的**：知识线 600~1200 字，引流线 800~1500 字；界面卡片文案按各自口径写准。
11. **只动长文**：图文、视频、口播、导图、门面、案例都不动。
12. **老篇不动**：以前用独立长文卡建的 `dir='l'` 草稿不迁移、不改写，继续走老四屏；新建不再产生 `dir='l'`。
13. **边界**：
    - 改稿空着点「出长文」→ 拦住，提示先改稿；
    - 长文生成失败 → 留在原屏显示原因＋「再试一次」；
    - 预览时长文为空 → 不让收口，提示回「出长文」；
    - 预览信息按第 7 条全套显示。

## 📌 替你按默认定的

- **提示词内容不动**：沿用现有后台两套规则（知识 `longform` / 引流 `longformD`），只把入口和流程接回去。
- **标题沿用现有做法**：优先成稿标题，没有就用正文首句/主题；不新开「标题」输入框。
- **「再出一版」口径**：同一份短稿下沿用上一版长文当参考；如果短稿改过，先走「重新出长文」，不拿旧长文当参考。
- **老 `dir='l'` 篇**：入口、四屏、档案「编辑」回落都保持原样。
- **自测副本不动**：`extension/`、`executor/` 本轮不同步；只改主本 `web/`，上公网另等一句「推」。
- **自测先行**：本机改完先跑长文/知识/引流相关冒烟；公网推送、重启按你确认后另行执行。

## 实现落点（给开发看）

- **入口映射**：`npDirPick` / `npDirNewNote`——知识长文 → `dir='k', kOut='text'`；引流长文 → `dir='d', dOut='long'`；不再写 `lTone/lStep`。
- **站表**：`npKStations` 恢复 `text` 分支（0 挑知识 / 4 改稿 / 5 出长文 / 6 预览 / -1 收好）；`npDStations` 恢复 `long` 分支（3 挑稿 / 4 改稿 / 5 出长文 / 6 预览 / -1 收好；讲故事型用 1 编故事 / 4 / 5 / 6 / -1）。
- **导航**：`npGo` 引流长文上限改到 6；`navForStep` 知识/引流长文各加「改稿→出长文→预览→存好」的按钮与守卫。
- **渲染**：`renderStep` 的 s=5 新铺「出长文」屏（`npLongStepHtml`：固定腔说明＋空稿拦＋旧版提示＋稿子框＋再出一版/重新出长文）；s=6 长文预览（`npLongPreviewHtml`，复用 `npPrevScreenHtml`，稿源 `longform`）。
- **生成**：`npGenLongform` 对 k/d 用 `draft.content`，`line = npIsD ? 'd' : 'k'`；成功后写 `longSrc` 快照并重画。老 `isL` 分支保留给老篇。
- **档案**：`npArNext` 对 `form='长文'` 分两路——`dir='l'` 仍 `to:'longform'`；k/d 按「有长文→`to:'preview'`；没长文→`to:'write'`」，载入时按 longform/draft 落到 6/5/0或3。
- **改出长文**：`np-ar-tolong` 与 `npArGoNext(n,'longform')` 一行不改（保持老 `dir='l'` 四屏）。
- **载入**：`npWizLoadArchive` 对 k/d 长文按「有长文→预览 6；有短稿→出长文 5；没稿→挑知识 0 / 挑稿 3」回落。
- **老篇**：`npIsL` 老四屏整体保留不动。
- **自检**：改 `scripts/dev/check_longform_dir_web.py` 为「回挂两条线」断言；另跑知识/引流现有冒烟。

## 验收

- 新建知识长文：点卡 → 挑知识 → 改稿 → 出长文 → 预览 → 存好；档案里是「长文/代发」，稿子＝长文。
- 新建引流长文：点卡 → 挑稿（含热点/梗）→ 改稿 → 出长文 → 预览 → 存好；同上。
- 两张卡的「出长文」屏都只有一行腔调说明，没有任何选腔控件。
- 改短稿后旧长文有「旧版」提示；「重新出长文」拿到新稿。
- 图文/视频两条出口的步骤与按钮不变。
- 老 `dir='l'` 篇仍能打开老四屏并继续。
- 预览空长文不让收口；生成失败留在原屏。
