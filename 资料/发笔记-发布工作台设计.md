## 〇、这一块干什么（一句话）

发布台加第三签「🛠 工作台」：发的时候整签是实时面——正在发哪篇、第几家平台、走到哪步（传素材 40% / 填字 / 点发布），卡住要您接手的（过目 / 输验证码 / 扫码 / 差授权）钉在顶上＋弹系统通知；正发着可以「⏹ 停这一趟」。没发的时候这签显示下一趟预告＋最近几趟结果＋还等着您接手的项。

## 二、语义定稿（按拍板组合出来的完整口径）

### 签的结构（三块，自上而下）

1. **顶条**——
   - 在跑：`▶ 正在发 · 第 1/2 篇 · 小红书（第 2/3 家） · 传素材 40%` ＋「⏹ 停这一趟」。
   - 没跑：`现在没有在发的活` ＋ `下一趟：今天 20:30 ·「篇名」`（队列里最近一个没到点的位子）。
   - 有等接手的：顶条醒目色挂 `⚠ N 项等您接手`。
2. **流水**（跑着时实时；跑完定格，最多留最近 3 趟）——每篇一块，块里每家平台一行，状态到步骤：
   `待发` → `改稿中` → `开页面` → `传素材 40%` → `填字` → `点发布` → 收尾之一：`✅ 已发` / `✋ 已填好·等你点发布` / `📱 等您输验证码` / `🔐 没登录·等扫码` / `🔑 差一次授权` / `❌ 没上成（会自动重试）`。
   - 传素材的进度＝分片喂料的真实片数进度（视频按 3MB 一片，图片一篇一片）；喂完之后等平台自己转的时段显示「等平台转完」动态——平台页面上顺手能读到的进度条就带上。
   - 一家一家来（与执行顺序同构：同一篇里平台是排队跑的，不是同时）。
3. **等您接手**（常驻，不随这趟结束消失）——没解决完的卡住项钉在这，每条一行＋「去处理」：
   - `✋ 已填好·等你点发布` → 去处理＝把那个已打开的标签页切到您面前。
   - `📱 要输验证码` → 切到那个标签页。
   - `🔐 没登录` → 开这家创作者后台给您扫码（与「📜 最近发过」的「去扫码」同一动作）。
   - `🔑 差一次授权` → 走「去授权」（与回执里「去授权」同一动作）。
   - `❌ 没上成`（自动重试用完了）→ 🔁 重试（只补这一家）。

### 实时怎么流到界面

- 跑的时候后台把进度写在一处：`np_pub_live`（与灌水线 `auto_water_state.live` 同款做法）；工作台签开订阅（`chrome.storage.onChanged`），边跑边刷。
- 签名牌上：在跑或有等接手时冒一个小红点/数字（其余时候干净）。
- 弹窗没开时：靠桌面通知送信；下次打开工作台看「上一趟」定格＋等接手清单。

### 叫您（桌面弹窗）

- 只在「要人」的时候弹：等过目 / 等验证码 / 等扫码 / 差授权。发失败自动重试的不弹（它自己会再试）。
- 同一件事只弹一次不轰炸；通知被点＝尽量送到能处理的地方（能切页面的把页面切到面前；扫码/授权这类通知里一句话说清去哪点）。处理掉了通知自动收掉。
- 实现＝`chrome.notifications`；manifest 加 `"notifications"` 权限。

### ⏹ 停这一趟

- 停的是**正在跑的这趟**：当前这家做到收尾就停，后面还没轮到的家、还没轮到的篇，一律不跑。
- 已发出去的不撤回；跑过的照实记进「📜 最近发过」。
- 没轮到的篇留在队列原位，**今天不再自动试**（与「今天试够了」同一道闸）；明天到点会像发失败一样再试一趟——要彻底不发，现有手段是改时间/换位子（「原地举牌停发」列为后续可选，不在这版）。
- 想发的时候手点「▶ 现在发」照常，不受影响。

### 边界（这版不做）

- 不做暂停/继续（停＝停这一趟，没有半场恢复）。
- 不上每一步的内部流水（等了几个 800ms、点了哪个元素这种，只留步骤级）。
- 通知不加按钮（点整条＝去处理）。
- 不做手机推送（本机桌面通知）。
