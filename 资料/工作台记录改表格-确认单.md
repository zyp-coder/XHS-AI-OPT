# 工作台记录区改「表格」— 确认单（2026-10-28 第二轮）

一句话：中间那块「这一趟扫了哪些笔记」不再一篇一张卡、卡里一行一行带时间，改成一页表格——一篇一行，只留要紧的几样，想看细节点行展开。

> 上一轮（左栏撤掉、中间换成这一趟的记录）见 `工作台改成跑批记录-确认单.md`；这一轮只动中间那块怎么画。

| # | 事项 | 定法 |
|---|---|---|
| 1 | 哪块改表格 | **中间那块**（「这一趟」的记录区）。底下那条操作日志不动 |
| 2 | 表格列 | **五列**：笔记 / 我发了什么 / 收进清单 / 状态 / 时间。篇号「3/16」缩成标题前面的小字，不单占列 |

## 📌 替你按默认定的（不同意就报编号）

**6. 抬头汇总留着。** 表格上面一行：「这一趟：14:29 – 14:38 · 🆕最新笔记 × 「瓷砖怎么选」 …… 搜到 16 篇 · 评论 1 条 · 收进清单 5 人」。

**7. 技术行不进表。** 原来卡里那些「✅ 笔记已打开」「⚡ 跑法『抢位』…」的灰字不再单独占行，收进展开里的明细；表格只放人看得懂的四件事。

**8.「打开」按钮留着。** 每行最右一颗小「打开」，点了才切回原来的评论／商机视图——这是手动那条路唯一的门。

**9. 收尾那句话（⏹ 上限 / ⏸ 停在哪个词 / 失败原因）** 用一条红／橙色细条压在表格下面，跟现在一样。

**10. 空态、掉线** 照上一轮：今天没跑就一句「今天还没跑过」；执行器没回话就在表格上压一行灰字。

## 🚫 这轮明确不做
- 不给客户机换包；不加跨天／多趟累计。

- 不改操作日志的写入内容，只改它默认收起。

## 📌 数据天花板（照上一轮，没变）
- **一整趟**的「打开过哪篇、每篇评论前 24 字、失败原因、收进谁」——服务器每天留 400 句，铺得全。
- **话术全文**只从最近一趟的回执里取（执行器只回 40 行），所以通常只有最后一两篇有全文，前面的只能显示前 24 字。
- 回复别人评论的正文执行器没回传，表格里只能写「已回复 @某人」。

## 验收口径
1. 中间是一张表：表头五列＋行末一颗「打开」；一篇一行，标题太长用省略号，鼠标停上去看全。
2. 状态列：已发评论 / 没发出去（· 无商机）/ 还在看评论区 / 没跑成 / 无商机。
3. 点任意一行，下面展开该篇细节；再点收起。展开里能看到评论全文、收进清单的人名、备好的话。
4. 底下操作日志默认收着，点「▴ 展开日志」拉开、再点收起；不再把日志一句一句铺满中间。
5. 表格上面那行汇总（时间 / 类型 × 词 / 搜到几篇 / 评论几条 / 收进几人）在。
6. 跑完 / 正在跑 / 停住 / 今天没跑 / 执行器掉线 / 没跑成，六种样子都对得上。
