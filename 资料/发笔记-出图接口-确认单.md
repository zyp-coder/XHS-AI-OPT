## 四、客户怎么用

1. 进 ⑤ 先看到一条额度：`本月出图 42 / 150 张 · 还剩 108 张`。
2. 点「🖼 一键出图」→ 弹一句：`这一组 5 张（4 配图 + 封面），扣 5 张额度，继续？`
3. 出图逐张走：第 1/5 张、第 2/5 张……出好一张铺一张，不用等整组。
4. 出完自动进传图区；封面单独一格，带「封面」角标。
5. 哪张不满意点「↻ 重出」，只重出那一张，再扣 1 张。
6. 额度不够：按钮变灰，提示「还剩 X 张，不够这一组；加算力包 / 等下月回满，或这一次先点『复制整组提示词』自己生成」。
7. 服务器没配出图 Key：按钮变灰，提示「一键出图暂时用不了——先复制整组提示词去豆包 / 即梦生成，图回来传上来」，其它照常。

## 五、技术落点（内部）

- **服务器配置**（`server/.env`）：
  - `IMAGE_API_KEY=` 方舟按量计费 Key（不是 Coding Plan 那把）
  - `IMAGE_API_BASE=https://ark.cn-beijing.volces.com/api/v3`（默认）
  - `IMAGE_MODEL=doubao-seedream-5-0-flash-260915`（默认同值；4.0 已下线）
  - `IMAGE_QUOTA_TRIAL=10`
  - `IMAGE_QUOTA_MONTH=150`
  - `IMAGE_DAILY_CAP=500`
  - `IMAGE_PRICE=0.12`（只用于老板视角显示）
- **服务器动作**：新增 `genNoteImage`（进 `WHITELIST`）；调方舟 `/images/generations`，拿到图后下载原图 → 走现有 `data/blobs` 托管 → 回 `/api/blob/<id>`；**调用前先按张占额度，接口失败原样退回（失败不扣）**；一次动作出一张。
- **额度账本**：账号级 `image_quota`（`{month, used, trialUsed, total, firstAt, lastAt}`，另带全站 `day` 日计数），和现有 `demo_quota` 分开；正式号按自然月滚（每月 1 日回满），试用号走 `trialUsed`、永不恢复；演示号不限张数，只记全站当日用量与账号累计。
- **网页侧**：⑤ 加额度条 / 一键出图 / 逐张进度 / 重出；单张提示词用现有 `npShotPromptText`，封面用 `npCoverPromptCompose`；出好的图走现有 `npDshUpload` 铺格，缩略图照旧，原图另写代发区（`np_pub_files` / `np_srv_files` / `xhsCase` 的 `pub:` 键），保证排期自动发也能取到图。
- **同步**：只改公网主本 `web/` + 服务器；`extension/`、`executor/` 最后按老规矩同步。
- **推翻旧决策**：`资料/发笔记-出图并线设计.md` §五「不做站内直连 AI 生图」改成新口径。
