## 一、这轮用到的词

- **原视频**：导进来的整条视频，比如拿着手机从门口走到每个房间拍的那一条。
- **切点**：时间轴上的一条竖线。两条切点之间，就是一段。
- **段（素材）**：从原视频里切出来、进了库的一小截，带名字、标签、一句说明。
- **剪辑视图**：新加的一屏。整条视频 + 一条时间轴，专门用来看画面、定切点。
- **认内容**：让「能看图的 AI」看画面，说出这是哪个房间、画面里谁在做什么、施工到哪一步。
- **关键帧**：从一段的中间截一张小图，拿去给 AI 看。
- **看图模型**：能看图片的 AI。现在写文案用的是 DeepSeek，它只能读字，不能看图。
- **施工情况**：这一段画面里看得见的进度，比如「墙砖铺到一半」「橱柜装好了、台面还没上」「地面做了成品保护」。

## 二、已定（老板 2026-10-22 亲答）

1. 病根：长视频导进来，系统只切出一两个镜头；拿着手机走一圈拍，切不出「这是房间、这是厕所」。
2. 切法：**自动分镜打底 + 手动加刀**，两个都要。
3. 走**乙方案：视频先进剪辑视图，切好所有段，再统一入库**（更像剪映）。
4. **不自动挑段**：导入后不自动建段，也不按「30 秒以内」分长短。所有段都等人确认。
5. 短视频 / 自己已经拍成一条一个镜头的：视频卡上给一个「整条入库」，点一下就是一段，不用进剪辑视图。
6. 段仍然**不能跨集合搬**。
7. 挑给某篇笔记的段**保持锁定**：不能改边界、不能删。
8. **新增核心：切完自动认内容**——房间 / 厕所这种场景要认出来，体能课「哪个小朋友在做什么运动」也要认出来，并自动写进每段的名字和说明。
9. 案例正文用每段的说明来写；说明来自认内容。没配看图模型时，不写「AI 看懂了画面」，只写「按位置先填」。
10. 看图模型用同一把方舟 Key。账号还没开通看图模型，需要老板去后台点一下开通（见第六节）。

## 三、新流程

### 1. 导入

- 「⬆ 导入原视频」支持**一次选多条**，都归到同一个集合。
- 每条视频卡先标「待切」。
- 短视频 / 单镜头视频卡上直接有「整条入库」；点了就生成一段，名字、标签、说明按画面或模板填。
- 想切也可以点「✂ 切段」进剪辑视图。

### 2. 剪辑视图（新）

- 上方：整条视频的播放器，能播、能拖。
- 中间：时间轴（整条视频的缩略图条）。时间轴上有三种标记：
  - **浅色小旗**：本机按画面变化找出来的建议切点，不花钱，先铺一层。
  - **彩色块**：AI 认出来的段落，块上直接写这段是什么（例：客厅 · 墙面刷白 / 卫生间 · 墙砖铺贴中）。
  - **橙色实线**：你手动加的切点。
- 操作：
  - 「✨ AI 看一遍」：抽帧 → 认场景 / 动作 → 给出分段和每段名字。要花钱，跑之前显示「这条要看 N 帧，大约 X 分钱」。
  - 「＋ 在这里切一刀」：以当前播放位置加一个切点。
  - 点中一个切点：可以「−0.5 秒 / +0.5 秒」微调，或「🗑 删这颗切点」（删了＝相邻两段合并）。
  - 「↺ 重新自动分镜」：把本机建议切点重跑一遍；AI 认出来的段和你手动加的刀保留。
  - 点时间轴任意位置：播放头跳过去；点某一段：跳到它的开头。
- 下方：切好的段列表，每段显示 `起–止 · 几秒 · 名字`。
  - 短于 **1 秒**的段标红，入库时拦下（提示合并或挪切点）。
- 底部：「✓ 切好了，入库并认一遍（N 段）」和「取消」。

### 3. 入库并认内容

- 按最终切点建 N 段；每段从中间截一张小图，交给看图模型认三样：**名字、标签、施工情况说明**。
- 认出来的结果先填进段卡，标「✨ AI 认的」，逐段可改。
- 认不出来 / 没配看图模型 / 调用失败：段照样入库，名字按「视频名 + 位置」填，说明写「还没认，先按位置填」，并标清楚没认过，不假装看懂。
- 视频卡变成「已切 N 段」，段卡列在下面。

### 4. 已经切过、想重切

- **有段正被笔记用着**：不许重切，提示先把那篇撤下来或发掉。
- **都没被用**：点「✂ 重切这条」→ 先确认「这条视频现有的 N 段会删掉，段上写的名字 / 标签 / 说明也会没」→ 删掉后回剪辑视图重新切。

### 5. 案例正文

- 挑完段回大组装时，AI 按「集合背景 + 每段说明」写案例正文初稿，进笔记草稿，可改。
- 每段说明里已经有施工情况 / 动作，正文就能顺着讲，不用再让人从头回忆。

## 四、怎么切、怎么认（白话版）

### 1. 切点分两层找

- **第一层：本机找「画面明显跳」的位置**
  - 不再用「画面差超过一个固定值」这一刀切；改成找画面变化的峰值，阈值跟着整条视频的变化幅度走。
  - 每 0.4～0.6 秒抽一帧比对；手持走动这种「一直在动」的画面也能找出候选切点。
  - 最短镜头 1 秒，一条最多 200 个候选点。
  - 这一层不联网、不花钱、快，负责「宁可多找一点」。
- **第二层：AI 认「内容变了没有」**
  - 把候选点附近的帧、以及每隔 2.5 秒抽的帧，分批给看图模型看。
  - AI 按「场景变了 / 动作变了」给真正的分段：从客厅走到厕所、镜头对准另一个孩子，边界落在变化处。
  - 每段同时给名字、标签、施工情况说明。
  - 这一层花钱，负责「切得准、说得清」。
- **两层怎么合**：本机候选点先铺一层浅色小旗；AI 认完盖一层彩色段。你最后看到的切点＝AI 段落的边界 + 你手动加的刀。AI 没认出来的地方，小旗还在，你可以自己补刀。

### 2. 认什么、不认什么

- **认**：房间 / 区域（客厅、卧室、厨房、卫生间、走廊、门店、操场…）、施工阶段（水电、泥瓦、木工、油漆、安装、保洁、验收、成品）、画面里看得见的人和动作（小朋友跳绳、两人拍球、跨栏）、看得见的成品 / 问题（墙砖、橱柜、保护膜、空鼓、裂缝、水渍）。
- **不认**：不猜人名、不认身份、不认品牌、不判断业主同不同意、不评价好坏。只写画面里看得见的东西。
- **标签**：仍从现有 18 类里挑；施工阶段写进「说明」，不硬塞成标签。

### 3. 抽帧和花钱

- 默认每 2.5 秒抽一帧，一条最多 60 帧；短片少抽。
- 认分段时把帧分批发（一批 8 张），不把整条视频传上去。
- 入库后再给每段中间截 1 张，分批认名字 / 标签 / 说明。
- 具体一张多少钱按方舟账单走；界面上跑之前给一个大概数，不偷偷跑。

## 五、系统碰撞（每条都要老板点头）

1. **操作顺序变了（用大白话说）**
   - 以前：长视频分完镜，下面是一排镜头卡；点哪个镜头，那个镜头就**立刻**变成一段进库。
   - 现在：点「✂ 切段」进剪辑视图，整条视频摆在一张时间轴上；你可以加刀、挪刀、删刀，看着整条切完，再点「切好了，入库」，N 段**一起**进库。
   - 改的是「什么时候进库」：从「点一下进一段」变成「整条切好、你确认后一起进」。
   - 单镜头视频不用进剪辑视图，卡上「整条入库」点一下就行。

2. **不再自动建段**
   - 导入、分镜之后只给建议切点，不自动挑段，也不按视频长短区别对待。
   - 老板已经明确：自动挑 3 段、30 秒以内这些规则**没必要，整条删掉**。

3. **重切会删掉这条视频现有的段**（名字 / 标签 / 说明一起没）；有锁段时不能重切。

4. **分镜算法换新的一套，只给素材库用**；老案例工作台的剪段流程保持原样，避免影响已经能用的地方。

5. **导入从「一次一条」改成「一次多条」**。

6. **新增看图调用，会动到「原视频只在本机」这句话**
   - 原视频仍然不上传。
   - 但认内容时，会把**每段一张压缩后的小图**发到方舟（服务器转一手，Key 不进客户浏览器）。
   - 发的是小图，不是原视频；服务器不存这些小图，认完就丢。
   - 如果业主没同意、或不想让画面出本机：这个集合可以关掉「AI 认内容」，只用手动切 + 手填说明。
   - 这条要老板明确点头，点头才接。

7. **案例正文生成会用每段说明**；说明是 AI 认出来的，所以正文可能带 AI 的判断，生成后仍要人过一眼。

## 六、看图模型怎么配（老板那边要做的一步）

现在这把方舟 Key 能出图（Seedream），但账号**没有开通任何看图模型**。我试了几个都回「未开通」（Key 本身是好的，能列模型）。

要开通的步骤：

1. 登录火山方舟控制台。
2. 左侧「开通管理」。
3. 搜 **Doubao-Seed-2.1-lite**（便宜、够用），点「开通」，按量付费。
4. 开通后不用换 Key、不用再给新 Key；我在服务器配置里写上模型名就能用。

如果不想开通：

- 切段仍能用（本机按画面变化切）。
- 但认不出「房间 / 厕所」「哪个孩子在做什么运动 / 施工到哪一步」，段名和说明只能按位置填。
- 界面上会明确写「没配看图模型，认不了内容」，不装作看懂了。

## 七、明确不做（防范围膨胀）

- 不做自动建段 / 自动挑段。
- 不做段跨集合搬。
- 不做段内部剪辑（剪掉中间一截）——只切，不剪。
- 不做视频转码 / 压缩（仍只收 mp4 / mov / webm）。
- 不动老案例工作台的剪段流程。
- 不认人名、身份、品牌、隐私；不评价好坏。
- 不把原视频传服务器；只传认内容用的压缩小图。
- 不为了让 demo 好看而假装 AI 已经看懂（demo 里会标明哪些是模拟结果）。

## 八、验收口径（做完了怎么算过）

1. 一条 3 分钟、拿手机走一圈的长视频，AI 认完能切出 **≥5 段**，每段名字能说清房间 / 区域（客厅、卫生间、厨房…），不是「镜头 1 / 2 / 3」。
2. 一条体能课视频，AI 认完能切出 **≥5 段**，每段名字能说清「谁在做什么运动」（例：黄衣小朋友跳绳、两人拍球）。
3. 每段入库后自动带名字、标签、说明；说明里有施工阶段 / 动作；标「✨ AI 认的」，可逐段改。
4. 手动加刀、删刀、挪刀有效；删刀后相邻两段合并。
5. 单镜头视频点「整条入库」一步完成，不弹剪辑视图。
6. **不自动建段**：导入后段数是 0，等确认；没有任何「30 秒以内自动挑 3 段」的逻辑。
7. 有锁段的视频重切被拦；无锁段重切先确认再删。
8. 没配看图模型时，AI 按钮不可用并说明原因；段仍能入库（按位置填）。
9. 原视频不离开本机；只有认内容用的压缩小图发到方舟，服务器不存。
10. 全程没有页内报错；挑段 → 大组装 → 出片这条老链路不受影响。
