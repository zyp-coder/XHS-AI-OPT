## 一、这单要解决什么

发布队列每篇行尾现在是颗很小、不写字的 `▶`：

- 不看也知道它说不清自己干什么；
- 点了**不问发哪家**，按行里亮着的小图标（📕🎵🎥）把能发的全发；
- 还受行尾那三档（✋ 备好等您点 / 📦 只备料 / 🚀 全自动）管——想「立刻真发」时经常被拦住。

要的东西：一颗写明的「🚀 发布」——点开先问发哪几家，勾好就立刻真发。

---

## 二、界面（一行长这样）

```
今天 · 周一   10月26日 · 📚 知识   │ 一个人做账号，别从选题开始   视频
                                   │ 📕  🎵  🎥   到点等你过目   🕐 12:00   [🚀 发布]  ✕
```

点「🚀 发布」→ 这一行下面展开一条窄条：

```
这篇发到哪几家？
  [✓ 📕 小红书]   [✓ 🎵 抖音]   [🎥 视频号 · 暂未接]        只这一趟，不改上面的排期
                                                           [取消]  [就发这几家]
```

- 默认预勾：这篇行里亮着的小图标 + 顶上总开关开着的那几家。
- 图文篇只出现小红书、抖音；视频篇才出现视频号（灰着）。
- 某家已经发成过 → 标「已发过」，勾不上（防同一篇发两遍）。
- 一家都不勾 → 「就发这几家」灰着，旁边一句「至少勾一家」。

---

## 三、点「就发这几家」之后发生什么

1. 立刻走现在那条真发链：AI 先按每家口径各改一版（拿掉规避词）→ 本地词表扫 → 发布前风控检查 → 开平台页面真发。
2. **只发勾中的家**；没勾的家这一趟完全不碰，行里的小图标与排期也不变。
3. 进度照旧去「发布台 → 🛠 工作台」看；发完在这行标「✅ 已发」，页底「📜 最近发过」留回执。

## 五、验收标准（怎么算做完）

1. 视频篇点「🚀 发布」→ 小窗三行，视频号灰「暂未接」；勾小红书＋抖音 → 只这两家发。
2. 只勾一家 → 只发一家；另外那家的小图标、时间、排期都原样不动。
3. 某家已发过 → 小窗里标「已发过」勾不上；全被剔除时按钮灰着并说明原因。
4. 图文篇小窗里没有视频号。
5. 草稿 / 缺料 → 不出小窗，提示先去补。
6. 撞静默期 / 单休日 → 点了直接报账号安全那道墙，不下单。
7. 发完 → 行变「✅ 已发」；「📜 最近发过」有这家回执；没勾的家没有回执。
