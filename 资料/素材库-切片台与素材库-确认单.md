## 一、这轮用到的词

- **原片**：导进来的整条视频，还没切的，比如拿着手机从门口走到每个房间拍的那一条。
- **段（素材）**：从原片里切出来、名字 / 标签 / 说明填好、能发案例的一小截。
- **批次**：这次拍的一堆片，或者一个客户的一堆片。一批可以有几条原片。
- **切片台**：干活的地方。导入一批 → 在这批里挑片切 → 打标签 → 整批放进素材文件夹。
- **素材库**：找东西的地方。只放整理好的文件夹和段；按标签 / 名字 / 说明搜，跨文件夹找。
- **素材文件夹**：现在界面上叫「集合」，这轮在素材库里叫文件夹。
- **已整理**：这一批的片切完、段进了文件夹，人点了「这批整理完了」。
- **归档**：暂时不用的文件夹收起来；不删除，里面的段还在。

## 二、已定（老板 2026-10-22 亲答）

1. 左栏分成**两个平级入口**：`✂ 切片台` 和 `📚 素材库`，不再是一个素材库页面里上下两块。
2. **切片台只做生产**：导入、挑片、切段、打名字 / 标签 / 说明、整批放进一个文件夹。
3. **素材库只放成品**：整理好的文件夹和段；支持按标签、名字、说明搜，跨文件夹出结果。
4. **导入不再先选文件夹**：导入时只给这一批起个名（默认日期，可改客户 / 工地），原片先落在这一批里。
5. **一批只定一次文件夹**：这批第一次切段入库时选一个素材文件夹；以后这批里再切，自动进同一个文件夹，不再每条视频弹一次。
6. **新建的空文件夹可以空着**：不再自动把没切的原片塞进去。
7. **切过的原片留在切片台的批次里**，标「已切 N 段 → 文件夹 X」，随时能重切；素材库里不重复放原片。
8. 发案例挑段、被笔记占用的段锁住、重切、归档这些规则都不变，只换入口和摆放。
9. **旧数据不动**：老数据页原样保留；老数据里没切的原片，归到切片台底部的「以前的（没分批次）」一组，标着原属哪个集合，不搬动。
10. 这轮只改素材库这一段；不动执行器、发笔记、发布链、获客。

## 三、新流程

### 1. 导入

- 点「⬆ 导入这一批」：一次选多条，给这批起个名（默认当天日期，可改成客户 / 工地名）。
- 不选文件夹，不自动切，不自动建段。
- 导完落到这一批的页面：上面是这批的原片，下面等着你挑哪条要切。

### 2. 切片台

- 首页按批次列：进行中的批次在上，已整理的在下面，以前的没分批次单独一组。
- 批次卡上写：这批叫什么、哪天、几条原片、总时长、已切几条 / 共几条、切出多少段、去哪个文件夹。
- 点进一批：每条原片一张卡，标「待切」或「已切 N 段」；点「✂ 切段」进剪辑视图，单镜头 / 短视频可以直接「整条入库」。
- 剪辑视图沿用现在的：本机建议切点、AI 看一遍、手动加刀 / 挪刀 / 删刀、短于 1 秒拦下。
- 这批的片可以分几次切；不要求每条都切，切几条算几条。

### 3. 切完入库

- 第一次入库时弹「这批段放哪个文件夹」：
  - 默认新建一个跟这批同名的文件夹；
  - 也可以选一个已有文件夹；
  - 已有同名文件夹时直接放进它，并写明「已有同名文件夹，会放进去」，不悄悄建两个同名的；
  - 已归档的文件夹不能选，先去素材库恢复。
- 选完以后，这批再切别的片，段自动进同一个文件夹，不再问。
- 入库后这批标「已切 N 段 → 文件夹 X」；原片还在，能重切。
- 这一批切得差不多了，点「✓ 这批整理完了」：整批移到「已整理」，素材库里能看到这个文件夹。
- 没切完的批次留在「进行中」，下次接着切。

### 4. 素材库

- 首页是文件夹卡片：名字、状态（在用 / 已归档）、几段备好、来自几条原片、最近更新。
- 点文件夹进去：上面一小条「这批原片」（点一下回切片台那批），下面是切好的段。
- 顶部搜索：一个输入框 + 标签按钮。
  - 输入框搜名字、标签、说明；
  - 标签可以多选，命中任意一个就算（先做「任一命中」，不搞复杂筛选）；
  - 搜出来的段卡上写它属于哪个文件夹，跨文件夹也能找到。
- 段的名字 / 标签 / 说明可以改；被笔记用着的段锁住，照旧不能删。
- 「＋ 新建空文件夹」可以直接建一个空文件夹，不塞任何原片。

### 5. 旧数据

- 「🗄 旧数据」入口原样保留，老集合、老片段照旧能看。
- 旧的没切原片在切片台底部「以前的（没分批次）」里，能切；切的时候同样选文件夹。
- 不做批量搬迁，不改老集合里的内容。

## 四、系统碰撞与处理

1. **原来每条原片必须挂在一个集合下面**
   - 现在切片台里的原片可以先只属于「批次」，不挂文件夹；只有切好的段带文件夹。
   - 老数据不改：老原片仍在原集合里；没切的老原片在「以前的（没分批次）」里也能看到。

2. **切段原来跟着原片所在的集合走**
   - 现在段跟着「这批选的文件夹」走；一批只定一次，后续自动沿用。
   - 重切默认回这批的文件夹；这批没定过文件夹时，重切会再问一次。

3. **「整条入库」也要落文件夹**
   - 跟切段用同一个选择框；一批只定一次。

4. **不传图片给 AI 的开关**
   - 文件夹仍有「不传图片」开关；这批还没定文件夹时，导入时加一个「这批不传图片」勾选，存到这批原片上。
   - 原片和文件夹任一勾了，就不传；不假装看懂了。

5. **导入时的标签**
   - 不选文件夹后，导入只按文件名猜；切进文件夹后，再参考文件夹的名字 / 说明补一层。

6. **发案例挑段**
   - 逻辑不变，挑段弹窗按文件夹分组；显示名改成「文件夹」；
   - 老段万一没有文件夹，归到「未分文件夹」一组。

7. **文件夹删除**
   - 这轮不删；只归档 / 恢复。避免误删里面的段。

8. **案例流自动建的老集合**
   - `剪段入库|篇号` 这类老集合不动，仍在旧数据 / 案例流里工作；新素材库只显示新库文件夹。

## 五、边界例外

1. **一条都没切 / 切到一半取消**：不建文件夹，原片留在批次里，标「待切」。
2. **一批全都没切**：批次留在「进行中」，不会自己变成「已整理」。
3. **一条原片的段全删了**：这条原片回到「待切」；它所属的批次和文件夹不变，重切还进同一个文件夹；文件夹即使空了也留着。
4. **同名文件夹**：入库选择框里直接选已有同名文件夹，并写明；手动「新建空文件夹」时撞名，提示换一个名字，不建两个同名。
5. **归档的文件夹**：在素材库里还能看；不能作为切段目标，先恢复再选。
6. **被笔记占用的段**：不能删、不能重切；沿用现在的锁段规则。
7. **空态**：
   - 切片台没有批次：提示「点右上角导入这一批」；
   - 素材库没有文件夹：提示「可以去切片台切一批，或先建一个空文件夹」；
   - 文件夹没有段：提示「这个文件夹可以空着，去切片台切了再放进来」。
8. **原片读不出时长 / 不是视频**：导入时挑出去并说明，不静默吞掉。
9. **一批里想分给两个文件夹**：这轮不做「移段」；先按一批一个文件夹走，下一轮再加「把这几段移到别的文件夹」。

## 七、验收口径（做完了怎么算过）

1. 左栏两个平级入口「✂ 切片台」「📚 素材库」，各自打开自己的页面。
2. 切片台导入一批时不问文件夹；批次卡能看出这批几条原片、切了几条、切出几段、去哪个文件夹。
3. 一批第一次入库弹出文件夹选择；默认这批同名；选已有文件夹后，这批后续切段自动沿用。
4. 新建空文件夹可以空着；不会自动塞没切的原片。
5. 切好的段只在素材库出现，切片台不重复列段；原片还留在批次里能重切。
6. 素材库按标签 / 名字 / 说明搜索，能跨文件夹出结果，段卡上写清所属文件夹。
7. 文件夹页上面能看到原片入口，下面是段；点原片入口能回切片台对应批次。
8. 段全删后原片回到待切；归档文件夹不能作为入库目标；同名文件夹按选择框提示处理。
9. 旧数据页和「以前的（没分批次）」都在；老数据不被改动。
10. 全程没有页内报错；发案例挑段、锁段规则不受影响。
