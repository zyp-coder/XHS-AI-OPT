## 〇、现状（改之前是什么样）

**执行器现在怎么上岗**：面板填「服务器地址 + 手机号 + 密码」→ 服务器核账本里的密码 → 发一张**挂线凭据**（handId + token）→ 之后服务器下令、执行器 25 秒长轮询拉活、干完回执、中途报进度、取素材、AI 出网，全凭这张凭据。

**「服务器开启动执行、执行器一边执行一边回报」——这条现在就是这么跑的**，不改。要改的只是「拿什么凭证上岗」这一道门。

**/admin 现在**：口令进（x-admin-pass）→ 账号名单（谁领了号 / 用量 / 最近活动）+ 汇总条 + 执行器栏（在岗的手 / 最近命令 / 日志）。档位只显示、不能改。

## 一、✅ 已定

### 1. 配对号（执行器上岗的唯一凭证）

- **一个账号一个固定码**（11A）：**开档位那一刻生成**，之后长期不变。免费档不生成、不显示（15A）。
- **两边都能看**（12C）：老板在发放页能看能换；客户在自己网页账号里也能看到自己的码，抄进执行器即可。
- **和手机号+密码并存**（13A）：**网页侧登录不动**（还是手机号+密码，认人、分账本）；**执行器只用配对号**（认机器）。
- **一码一台**（14A）：沿用现在的「一个号挂一台，再挂＝旧机当场收队」。
- **免费档拿不到码**（15A）：跟现在「没到档位装不了执行器」一个口径；免费档进装机页只看到档位表。
- **换码＝作废重发**：老板在发放页点「换一个码」→ 旧码当场废、已挂的机器掉线转「挂线失效」，客户用新码重挂。
- **客户从哪来**（16A）：**客户自助领号为主**（手机号+密码），老板在发放页给他开档位、看码；后台也能建号（备用）。
- 执行器面板：删掉「手机号 / 密码」两个框，换成**一个「配对号」框**；服务器地址照旧预填。
- 上线切换：现在只有老板自己＋两个测试号在用，**直接切**，不保留老挂线凭据（重挂一律用码）。

### 2. ① admin ＋ 发放管理页

- 入口沿用现在的 **/admin**，还是**口令进**（不新做账号密码）。
- 页内两签：
  - **账号名单**（现有那套照旧：谁领了号 / 用量 / 最近活动 / 全站预算）。
  - **执行器发放**（新）：一行一个号 —— 名字 / 尾号 / 档位 / **配对号** / 包发了没 / **挂没挂上**（哪台机、最后在线、正在做什么）/ 操作（**开档位**、**看码·换码**、**停这一趟**）。
- 「我发给了哪些扩展包」＝这一表的发放列；开档位、发码、换码都在这一页动手。

### 3. ② 主页快速下载入口

- **起始页**（普通用户进门那页）加一个**显眼的下载块**（现在是底下一行小字链接）：一句话说明 + 「下载执行器」按钮。
- **工作台顶栏**加一个「⬇️ 执行器」小按钮，随时能进。

### 4. ③ 新用户引导页

- 新页 **/guide**：讲**这是干啥的工具** → 工作台**四块各是干啥**（诊断&配置 / 发笔记 / 获客 / 线索）＋ 设置 → **哪些要执行器、哪些不要**：

  | 块 | 干什么 | 要不要执行器 |
  |---|---|---|
  | 诊断&配置 | 填基本盘、问卷、人设、卖点、知识库、规划 | 网页就能写，**不用** |
  | 发笔记 | 写稿 / 出图 / 出片 / 档案 / 素材库 / 复盘 | 写稿出图**不用**；**真发到平台要** |
  | 获客 | 搜词、扫评论、找商机、真评论、日常浏览 | **要** |
  | 线索 | 通知、私信往来、AI客服 | **要** |
  | 设置 | 系统级配置 | 不用 |

- **第一次**进工作台/起始页时**自动进一次**（看过就不再弹）；顶栏留一个「❓ 新手引导」常驻入口，随时能再看。

### 5. ④ 「了解更多扩展」按钮

- 最上端一个按钮**「了解更多扩展 →」**，点它进**装机页 /setup**。
- 装机页升级为「**介绍 + 下载**」一页：顶部一段「这扩展是什么、能帮你干什么」（＝了解更多的内容），下面还是下载 + 三步 + 档位表 + 常见坑。
- **②和④合成一处**：入口放几处，**目标都是 /setup 这一页**，不新做第二张介绍页。

## 二、📌 替你按默认定的（扫一眼，不对就说）

1. **admin 还是口令进**，不新做账号密码 —— 默认沿用现状。
2. **引导页只在"第一次"自动弹一次**，不当进门拦路页 —— 默认不拦。
3. **装机页的下载入口不直给 zip，先进 /setup**（那页有下载+三步+档位+常见坑，省得客户拿了 zip 不会装）—— 默认认为"快速"＝点一下就到下载。
4. **换码会踢掉已挂的机器** —— 默认安全优先。
5. **客户网页上自己的码**放在账号那行（顶栏），点一下能展开/复制 —— 默认不单独做一页。
6. **账号资料备份/导入时，配对号跟着账号走**（导入到新机还是同一个码）。
7. **文字口径**：对客户一律说「**配对号**」「**执行器**」「**装执行器**」；不用「token / handId / 绑定 / 注册」这类词。
