# 档位归服务器控制 · 确认单（2026-10-16）

> 这轮只解决一件事：**「这位客户能点哪几格」由公网那台说了算，不再打在包里。**
> 三档边界一个字没改。demo：`tmp/档位归服务器-demo.html`（可点）。

## 一、这轮用到的词（一句白话）

| 词 | 白话 |
|---|---|
| 功能格 | 界面上一个功能开不开、给不给点。全系统八格：整页发送、多产品切换、知识库、获客、线索、发笔记、日常浏览、字效编辑器 |
| 档位表 | 写明每一档开哪几格的那张表。这轮之后**只存在于公网那台一处** |
| 领表 | 客户机开机／每 15 秒对账时，从服务器把这张表拿回来 |
| 进门默认 | 包里的旧表降级后的身份：客户机从没领到过表时才用它 |
| 小灶 | 单个客户额外开（或额外关）某一格，不动全局表 |
| 试用到期 | 服务器上记的一个日期，到期自动从试用档落回他本来的档 |

## 二、口径（你已点头的六条）

1. 档位表只在一处写：公网那台。界面、包都不再自带权限。
2. 断网／没领到过：按「进门默认」显示，顶栏挂一句「未联网核对」。
3. 开小灶：要。可加格，也可给某个客户单独撤一格。
4. **三档边界一字不改**：① 基础版 239＝共有＋发笔记｜② 升级版 399＝①＋获客（日常浏览随获客）｜③ 全功能版 539＝②＋线索。共用的三格（整页发送／多产品切换／知识库）谁都有。
5. 到期、停档、改档都在公网那台点，**不用重打包**。
6. 打包**仍分档打**（包名、包内说明书照旧按档印），选完顺手同步到公网那台；包里那张表从「权限」降级为「进门默认」。

## 三、改哪四步

**① 公网那台加一张表 + 每个账号两张纸**
- 全局新增「档位表」：四档 × 八格，初始值就是把现在打包预设里的八格逐字搬过去（`build.js` 那份矩阵是抄本，搬完打包侧不再当判据）。
- 账号记录补三个字段：`perk`（小灶：加哪几格／撤哪几格）、`trialUntil`（试用到期日）、`trialTier`（试用期内按哪一档开）。
- 服务器三处把结果吐出去：网页登录时、执行器 15 秒对账时、派活时——用的都是同一张合并后的表（**档 ∪ 小灶加 − 小灶撤**）。

**② 公网那台的界面改用领来的表**
现在它读的是包里那张表，对所有账号一模一样——等于网页端根本不分档。改完：免费档、试用期、正式档在网页上看到不同格子。

**③ 执行器的界面改用领来的表**
对账那条线（每 15 秒）本来就有，只需把合并后的八格塞进回话里；客户端存一份，下次开机沿用。派活闸（服务器不够档压根不派、执行器接到活再核一次）**照旧不动**，它仍是最后一道真闸——界面锁只是让他少撞墙，不是安全边界。

**④ 打包侧：档还在，语义降一级**
- 打包时选的档决定三样：包名后缀、包内说明书印的功能清单、进门默认那八格。
- 新增一步：填了这位客户是谁，打完包就调公网那台把他的档设成一样；没填就不动名单（自用包、随便发的试用包）。
- 自用测试包不进这张表，永远全开。

## 五、这几条我先按默认走，不对就圈出来

1. **试用档默认＝全功能③**，到期落回「免费」——对应传单上那句「可以免费试用 1 个月」。
2. **免费档能用什么＝共用三格 ＋ 写稿（不能出图出片、不能发布）**：这样「免费做个测评」有东西可看，又留得住 upgrade 的口子。想给更松（比如免费也开出图）圈这里。
3. **打包机要不要存公网口令**：存了才能一键同步；不想放口令就改成「打完包你自己去名单页点一下档位」。
4. 改档生效速度：客户机 **15 秒内**跟上新格，不用他重开页面。
5. 已经在用的旧包：联网之后自动听服务器的，不用重装。

## 六、怎么算过

| 点 | 看什么 |
|---|---|
| 名单页把某位从「基础」点到「升级」 | 他那台机器 15 秒内获客那一格自己亮起来，无需重开 |
| 给这位勾小灶「线索」 | 只有他多出线索那一格，别的客户没变 |
| 把他的试用到期日改成今天以前 | 界面落回免费档那几格 + 一句「试用到期了，联系开通」 |
| 拔网线开执行器 | 顶栏出现「未联网核对」，格子按包里进门默认显示，不白屏 |
| 打一个 ② 的包、填了这位客户 | 名单页他自动变「升级」；包名与说明书仍是「升级版」字样 |
| 全局表把「日常浏览」挪到 ③ | 所有 ② 客户机自动收掉这一格（不改代码、不重打包） |
