# 门面笔记·第四轮：挑稿与改稿分两站＋正文摊平＋配图换成「封面&字幕」

2026-10-20 老板实测后提的三条，走澄清流程冻下来的需求档案。
**demo 与实现都对着这一份验收**；改口径先改这一份的对应条目，别跟着最后一句话摇。
上一轮（介绍篇版式主导整篇）的档案＝`资料/发笔记-门面笔记设计.md`；三档出口＝`资料/发笔记-口播选出口三档设计.md`。

## 老板原话（2026-10-20）
1. 工作流（出这一版）的作用是挑稿；所以把现在改稿的功能迁移到挑稿件那里去；
2. 改稿，这个功能和知识笔记的改稿的功能类似了。但是正文的那里还是有分段了。
4. 配图的节点先不要了。做一个封面&字幕来替代，这里就是让用户选一下视频的随机一帧作为封面，然后再选一下版式来添加标题；字幕的话，就要看看原本有木有。如果没有，用户可以点"添加字幕"，然后帮影片来添加字幕的。（转工单的部分，默认是跳过了封面&字幕的了。）

## 新站序（两篇都变）
- **介绍篇六站**：补底料 → **挑稿** → **改稿** → 选出口 → **封面&字幕**（顶掉原来的「配图」）→ 收口置顶
- **承接篇四站**：补底料 → **挑稿** → **改稿** → 收口置顶（它不选出口、也没有封面&字幕那站）

## ✅ 已定（老板逐条圈的）
1. 头那一站改名 **「挑稿」**。
2. **挑稿、改稿仍是两站**，不合一。**挑稿＝挑版式**：五张版式卡摆在这一站，点一张就按那一张的分法出一版，出过的几版并排放着比一比，点中一版＝「就用这一版」；**改稿站不再摆版式卡**，只留逐句抠、换标题、全文手改、改回上一版。
   - 承接篇没有版式可选，它的「挑稿」＝照提纲出一版＋「↻ 再出一版」，几版里挑一定；**五段框与 🔒 照旧保留**。
3. **正文摊平到「段」这个概念对介绍篇就没有了**：界面一行一句、不画段卡片、不带 🔒；**存的也按句存**（`fSegs` 介绍篇这份从「段里套句」换成「一句一条」）；提词卡跟着改成**一句一屏**。
4. 封面取帧＝**拖进度条看到哪取哪 ＋ 一颗「🎲 随机给 5 帧」**候选条。
5. 封面版式 **3 套**（大字压中 / 左上竖排 / 底部一条白字），标题**默认就是这篇的标题**（一行，可就地改，改了不回写这篇的标题），**不带副标题**。
6. **不做「这条片有没有字幕」的系统判断**——就让用户自己定：这一站给「➕ 给这条片加字幕」和「不用加」两颗，选了就算定。
7. 加字幕走 **云端补一道烧字幕**（点了排队、给进度，跟串片同一台机器；字就用这篇稿子里那几句，一行一句烧在画面底部）。
8. 加了字幕的片 **顶掉原来那条**（旧片按现在「料与片留 7 天」的口径留几天，给一句「↩ 不要了，回上一版」）。

## 📌 没答、按推荐替你定的（扫一眼，不 OK 就说改哪条）

12. **承接篇跟着一起并成「挑稿＋改稿」两站**（正文仍五段、仍带段名与 🔒，全文手改仍缺段被拦）。

15. 取帧解不出来（个别浏览器播那条片黑屏）：留一颗 **「⬆ 传一张自己的图当封面」** 兜底。
16. 云端加字幕排队中／失败：按现在云端出片那套**排队＋人话一句＋重试一颗**，不崩、不报栈。

18. 三档出口的文案里凡是写「配图」的句子（页头、选出口那张卡、收口摊开那一串、档案提示）全换成「封面&字幕」这套口径。
19. 主页简介那几行、置顶三步指引、90 天翻新提醒**一字不动**。

## 🚫 明确不做（防范围膨胀）
- 不做「识别画面里有没有字幕」，也不做平台字幕轨（只烧进画面，或干脆不加）。
- 不在本机整片重录来加字幕（太慢，跨境下载＋片长时长）；不做「只出字幕文件让用户自己烧」那条兜底（选了 A 就只走 A）。
- 不动 知识线／引流线／IP 线／案例线的挑稿-改稿结构，不动它们的数据。
- 这轮不动 `extension/` 自测副本、不动旧设计稿与 `tmp/门面笔记demo.html`、不动知识库 JSON／功能与界面总表／使用说明（等老板圈）。
- 不清洗老档、不加恢复/清理机制。

## 落地要点（实现对着这份，不用回头翻对话）
- **改动只在公网那台**：`web/popup.js`（门面那条流：`FACADE_STEPS`、`npFacStepDraft`→挑稿、`npFacStepRevise`→改稿、`npFacStepImg`→撤、新 `npFacStepCover`、`npFacadeSave`／`npArchiveCoerce` 加 `fCover` 粘性）、`server/bg/background.js`（介绍篇回稿摊平成句）、字幕那发走服务端口播那支（`server/lip/jobs.mjs` 旁边加一道「给已有片烧字幕」，用现成的 ffmpeg＋libass，已验云端支持 `subtitles` 滤镜）。
- **数据形状**：介绍篇 `f.segs` = 一句一条；承接篇仍「一段一串句」。读的口子统一走一个函数，老档（段里套句）自动摊平，不写迁移脚本。
- **挑稿站**：`f.vers` 记这一趟出过的几版（版式名＋标题＋那几句），当前用的那版进改稿；点卡＝再出一版（跟现在一样一次一发 AI），并排小卡点中＝「就用这一版」。
- **封面&字幕站**：抬头那条片按出口取（自己念／工单＝服务端那条链接，字效片＝本机存的），拖进度条＋随机 5 帧 → 选一帧 → 三套版式其一 ＋ 标题一行 → `✓ 定这张当封面`；底下字幕那一栏两颗钮（加／不加），选了加就走排队、回来顶掉旧片。
- **自检四份按新口径改并跑绿**：批1（入口/档案/数据层）、批2（六站全流程，含挑稿多版、平铺正文、封面站、字幕排队桩）、批3（后台两支回稿形状）、批4（那颗「下一步」与规划页说明）。全走本机小桩，不烧真 Key、绝不碰 `server/data/`。
- **红线照旧**：底料空着不许编数字年限；承接只走「主页简介 / 私信我」；带效果的说法一律带「各家情况不一样，只作参考」；不出现微信/电话/号码/链接/二维码。
