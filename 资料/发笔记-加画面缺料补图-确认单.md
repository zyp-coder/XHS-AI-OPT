# 「加画面」缺料补图 · 确认单（2026-10-30）

需求来源：老板原话（按顺序）——
1. 「如果我有案例库就用案例库，素材库就用素材库的东西；没有素材库的话，你也要 AI 帮我生成」
2. 「我说的是有素材库就用素材库的，没有就用 AI 生成一份素材。不是补静态哦，是补一份视频素材哦」
3. 「补视频确实有点贵，要不还是补图片吧。先做补图片的吧，视频也确实太贵，没必要」

结论：**这一版只补静态图**；AI 生成视频另开一条，成本核过再说。

---

## 一、✅ 按老板圈定的四条

1. **素材库优先**：点「✨ AI 先配一版」照旧先撞素材库，够用的屏一张不动。
2. **只补真配不到的**：只有红字那几屏（撞完素材库还空着）才走 AI 出图，一屏一张。
3. **只补缺的**：已有料的屏不重出、不扣额度。
4. **两种补法都给**：逐屏行尾 `↻ 重出一张`＋`⬆ 传一张`。
5. **本机＋公网一起改**：本机主本 `web/` 与扩展自测副本 `extension/` 对齐，改完推公网那台。

## 二、📌 替老板按默认定的（一句话可改）

1. **出的是静图**，一屏一张，画面有很轻的推近（4%），不是完全定格的幻灯；跟实拍段比会「平」一些。
2. **点了才出，绝不自动**：`AI 先配一版` 撞完素材库后，料栏顶端多一颗 `🖼 还缺 N 屏 · AI 出一版`，点了才扣额度出图。
3. **出的图进素材库**：自动落一个文件夹「AI 补的画面」，别的篇也能挑到；同时本机存一份原图，服务器那边清了照样能出片。
4. **额度同一本账**：跟「🖼 一键出图」共用（正式档每月 150 张），一屏扣一张；出失败自动退回、不扣。
5. **一篇一套风格**：同篇几张用同一套风格词（跟这一篇／账号的出图风格一致），避免拼起来花。
6. **只补「垫满屏」**：实拍那条缺料才补；「垫进卡」继续走「🖼 出图」那张画面表（那一套要整篇统一风格）。
7. **提示词自动写**：按这一屏的字写一句画面描述，明确「画里不要出现文字、脸别糊、竖屏 9:16」。
8. **出过的记住**：篇里已有的 AI 图重开还在，不重扣额度。

## 三、⚠️ 代价与风险

1. **钱**：缺 6 屏＝6 张额度；跟图文出图共用同一本账，密集出图会把本月张数吃掉。
2. **等**：一张几秒到十几秒，6 屏约半分钟到两分钟；出的时候页面要开着、别关。
3. **不如真素材**：AI 编的画面对不上稿子是常事；不满意就 `↻ 重出一张`（再扣一张）或自己 `⬆ 传一张`。
4. **整篇全 AI 图会像 PPT**：建议只补零星几屏，主力还是素材库的实拍。
5. **本机那台要能出图**：出图 Key 只在服务器的 `server/.env` 里（现已配）；本机 server 没配 Key 时点了会照实提示「没接上出图接口」，不假装。

## 四、落地清单（文件级）

- `web/video.js`（主本）：缺料屏 → 调 `genNoteImage` → 回来存本机 `xhsCase` 原图 ＋ 素材库纯图条目 → 当照片屏垫上；逐屏两颗按钮；顶端那颗批量钮；一片一套的提示词拼法；额度回执与失败退回的提示。
- `extension/video.js`：与主本对齐同一批改动（自测副本，禁漂）。
- `server/`：不动——`genNoteImage` 已在动作白名单里，扣张数／失败退回都在服务器侧，已有。
- 样式：优先复用料行现有的 `ghost / addseg` 类，能不新加 CSS 就不加。

## 五、自检要验的点（用现有桩接口跑）

1. 素材库有料 → 点「AI 先配一版」不动任何屏、不出图、不扣额度。
2. 缺 3 屏 → 顶端那颗点一次：出 3 张、扣 3 张、3 屏从红字变照片屏、能真出片。
3. 失败一张 → 额度退回、那屏仍红字并写明原因。
4. `↻ 重出一张`：只换那一屏、只扣一张。
5. `⬆ 传一张`：本机选图立刻覆盖那一屏，不扣额度。
6. 重开这一篇：AI 图还在，不重扣。
7. 全程无页内报错；真出片一条看画面与推近效果。
