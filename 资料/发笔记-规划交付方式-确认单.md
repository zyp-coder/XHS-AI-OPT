# 发笔记规划 · 交付方式（第 2 版）· 确认单

> 2026-10-29。你定的口径：**规划里只放「电脑能全自动把料做齐」的形态**；案例要你补素材、口播要你念、数字人做不了——都不进规划；混剪能做、图文能做、长文能做。
> 状态：**等你点头，代码一行没动**。可点的 demo：`tmp/发笔记规划交付方式-demo.html`。

## 一、要解决什么

现在的「🗓 笔记规划」一天只能勾一个**大类**（知识 / 引流 / 案例）——勾完不知道这篇最后长什么样、要不要你动手。老数据里勾过「案例」的天，凌晨备稿直接跳过，一夜白排。

这一版把一天一颗胶囊，改成**线 + 交付方式**一起定：一天一颗，只留电脑能自己做完的四种。

## 二、定的口径

| # | 事项 | 定的 |
|---|---|---|
| 1 | 一天怎么选 | 一天**一颗**胶囊＝线＋交付方式：`📚 知识·图文` / `📚 知识·长文` / `🔥 引流·图文` / `🔥 引流·长文`。点另一颗＝换成那颗；再点同一颗＝这天休 |
| 2 | 不进规划 | **视频（混剪 / 字体动效）、真人口播、数字人、案例**——全部从规划里拿掉；要发就在「📒 笔记档案 → + 新建」自己做，做好点「🚀 发布」 |
| 3 | 案例怎么办 | 案例照旧能发，只是**不进排期**：你自己补素材、做成片、档案里手动发（你说的「发旧案例」就是这条路） |
| 4 | 凌晨 02:00 写什么 | 图文 → AI 正文（知识走干货线 / 引流走引流线）；长文 → AI 直接排成整篇长文（知识科普腔 600~1200 字 / 引流人设腔 800~1500 字） |
| 5 | 配图什么时候出 | **02:00 不出图**（出图接口在服务器、后台拿不到 Key）。图文篇在**当天第一次打开页面时自动补出 3~4 张**（默认开，可关）；长文不需要图 |
| 6 | 料齐才算数 | 图文料＝正文＋配图；长文料＝整篇长文。**料不齐到点跳过，不顺延、不硬发**；篇留在档案里，工作台挂「去档案补图」 |
| 7 | 额度不够 | 出图张数是按账号扣的（试用 10 张 / 正式每月 150 张）。不够就**只写稿、图留缺**，等你补张数或自己传图——不偷偷扣成一堆空图 |
| 8 | 备好的篇要认得出下一步 | 自动备的篇写进档案时就带上「出口」（图文 / 长文），档案那行「下一步」才不会指错路 |
| 9 | 老数据 | 老值 `知识` → `知识·图文`、`引流` → `引流·图文`；老值 `案例` 的天**清成休**，页面顶上提示一次（说清楚为什么清） |
| 10 | 一天几篇 / 题从哪来 | 不变：一天 1 篇；题按当天方向从知识库挑，账号层排产表（🧬 账号规划）继续当总纲 |

## 三、⚠️ 一条要你拍板的（长文最后一步）

**长文没法到点自动发。** 小红书的「长文模式」入口一直没实锤，执行器的口径是：不管到点不到点，**一律把长文填好、停在页面上等人点发布**（`executor/exec-core.js` 6028 行写死的）。所以长文能自动备稿、自动排版，最后那一下「发布」要人点。

- **A（我先按这个定）**：长文照进规划。到点把这篇顶到「📒 笔记档案」最上面＋工作台提醒，**你点一下就发**——全站唯一要动手的一格，页面上写明白。
- **B**：长文这轮不进规划，只留「图文」两种；等你哪天点头让执行器去试长文入口，再放进来。

> 你回「A」或「B」就行；不回就按 A 走。

## 五、验收（怎么算做完）

1. 规划页一天就四颗胶囊，没有「🎬 案例」；点一下选中、再点同一颗变休。
2. 老数据打开就对上：原来的 知识 / 引流 变成对应「·图文」，原来勾 案例 的那几天是休，顶上有一次提示。
3. 点「🤖 现在备今天的稿」：图文篇进档案是「代发 · 缺图」，长文篇是「代发 · 料齐」。
4. 打开页面几秒后：图文篇的图自己出齐（3~4 张）并铺进代发区，不再需要手点「一键出图」。
5. 额度不够时：稿照进档案，图留缺，工作台挂「去档案补图」，没有半途而废的空篇。
6. 到点：料齐的图文真发出去；料不齐的跳过、不顺延，工作台写着为什么。
7. 长文到点：稿顶到档案最上面＋工作台提醒，点一下能发。
8. 档案里自动备的篇，「下一步」指到对的那条路（图文点开出图，长文点开是长文那一屏）。

## 六、两条硬限制（照旧要说）

- **凌晨 02:00 只写文**：出图接口在服务器，后台拿不到 Key。图在当天第一次打开页面时补出，**同一次打开就补齐，不用另点**。
- **公网那台没有凌晨闹钟**：靠当天第一次打开页面补写；不追补前几天。

## 七、这轮不做

- 混剪 / 视频 / 口播 / 数字人进规划（要等它们能全自动出料）。
- 案例自动找素材、自动剪（案例就是你自己做完手动发）。
- 出齐的图自动挑最好的换（想换照旧在档案里 ↻）。
- `extension/`、`executor/` 两份副本这轮不跟。
