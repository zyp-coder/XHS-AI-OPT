## 三、这一页长什么样（从上到下）

1. **标题行**：📚 素材库 ＋「?」一句话说明 ＋「🏷 18 类怎么并成 8 颗」＋「🗄 旧数据」
2. **搜索行**：搜名字 / 标签 / 说明｜**文件夹下拉**（全部工地 / 某个工地）｜清空筛选
3. **8 颗标签**：每颗带段数，点一下筛，点几颗＝这几类都算（并集），再点取消
4. **统计行**：共 N 段 · N 段备好 · N 张照片 · N 段还没标签（「只看没标签的」可点）
5. **卡片墙**：段和照片混在一堆，按最近改动倒序；每张卡＝勾选框＋缩略图＋名字＋备好/还差＋时长＋标签＋说明＋试看/改一下/删
6. **底栏（勾了才出现）**：已选 N 段（M 段备好）｜清空选择｜**📤 用选中的 M 段发案例**
   - 没备好的段（缺名字/标签/说明）会被点名，发案例时跳过。
