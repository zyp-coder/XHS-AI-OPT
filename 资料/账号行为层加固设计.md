## 〇、一句话

给账号的一天立**三条硬规矩 + 一张体检卡**：不管开多少种自动化，一天加起来就干这么多（总账挡位）；每天 21:00–09:00 一律不跑（静默期）；每周歇 1 天（单休）；收到平台警告记一笔，软件自己把节奏再收紧一级。

## 一、为什么光有「拟人化挡位」不够（缺口）

现有拟人化挡位只管「每一步停多久」（秒级抖动），管不了这五件事：

1. **没有总账**：灌水、浏览、私信、截流各算各的账，加起来一个号一天能动几百下——真人不会有这种量。
2. **节奏太均匀**：一整天均匀地动、从不发呆、没有忙闲——机器特征最大的不是点得准不准，是「24 小时待命」。
3. **动作类型叠得密**：采集、评论、私信连着来，像流水线。
4. **没有日间波动**：每天量都差不多。
5. **没有健康度管理**：警告过、处罚过，账号里没有记录，策略也不会收。

## 二、四个口径（老板已圈）

| # | 口径 | 怎么定 | 老板答复 |
|---|---|---|---|
| ① | 总挡位 | 「保守 / 谨慎 / 正常」一个总旋钮管一天所有自动化的总和；各功能自己的限额保留，但谁也不能超总账。默认落最保守档 | 同意 |
| ② | 每周单休 | 每周随机歇 1 天，当天所有自动化不跑（当周固定、界面显示、可换） | 「单休的吧」 |
| ③ | 静默期 | 每天 21:00–09:00 一律不允许跑（固定窗口） | 「晚上9-凌晨9点不允许跑」 |
| ④ | 账号体检卡 | 手动记平台警告/处罚；记一笔自动把节奏挡降一级 | 要 |

## 三、总挡位：三档参数（草案，请圈「按这套来」）

一天总和，所有功能合计（打开浏览含：获客打开、截流扫描、日常浏览）：

| 动作（账号一天合计） | 保守（默认） | 谨慎 | 正常 |
|---|---|---|---|
| 打开 / 浏览笔记 | ≤ 60 | ≤ 140 | ≤ 240 |
| 点赞 | ≤ 20 | ≤ 45 | ≤ 80 |
| 收藏 | ≤ 8 | ≤ 16 | ≤ 28 |
| 评论 + 回复 | ≤ 12 | ≤ 25 | ≤ 45 |
| 关注 | ≤ 4 | ≤ 9 | ≤ 16 |
| 私信 | ≤ 8 | ≤ 16 | ≤ 30 |
| 发笔记 | ≤ 2 | ≤ 3 | ≤ 5 |

外加**日间波动**：当天总账按 60%~100% 随机打折（凌晨定死，界面显示「今天还剩多少」）。

## 四、三条硬规矩（任何挡都生效）

1. **静默期 21:00–09:00**：所有自动化停。到 21:00 没跑完的顺延；09:00 前不新起（09:00 后再随机等 0~40 分钟才「起床」）。存量配置里跑出窗口的（日常浏览默认晚上时段 20:00–22:30、自动跑时段 08:30–22:30）自动钳进 09:00–21:00。
   - 发布队列到点撞上静默期 / 休息日 → **自动顺延到 09:00 后**跑，工作台回执注明「因静默期顺延」。
2. **每周单休**：每周随机抽 1 天全停（当周固定；界面能看是哪天、能手动换）。
3. **干歇节拍**：每小时最多自动动 30 分钟，其余时间排队等下一小时——干一段就歇，不跑满。

## 五、两条缓冲（动作做减法）

1. **发笔记前后留空**：发布前 15 分钟只浏览不动手；发布后 30 分钟内不跑其他自动化；发笔记当天其他动作按挡位打折（保守 5 折 / 谨慎 7.5 折 / 正常不打折）。
2. **采集收口**：自动「🔁 补开」（每轮跑完回看未打开笔记）默认改为关，开关保留；「打开即登记」照旧（获客/浏览里打开笔记顺手入池，2026-09-21 已落地）——不再为采集反复横跳地开笔记。手动「🔁 补开未打开」按钮保留。

## 六、账号体检卡

- 记一笔：日期 + 类型（警告 / 处罚 / 限流）+ 备注（平台原文贴进来）。
- 记「警告」→ 总挡位降一级（正常→谨慎→保守）；记「处罚」→ 直接落保守；已在保守再记 → 只红字提醒。
- 显示：当前挡位 + 历史记录 + 「恢复挡位」手动按钮。
- 第一笔就是 10-10 这份处罚（落地时由老板确认要不要记进去）。
