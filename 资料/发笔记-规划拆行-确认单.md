## 一、要解决什么

- 现在规划页是「一天一行 + 发到哪三平台多选」：同一天所有平台绑死一个形式，看不出每家到底发什么。
- 抖音、视频号只能发视频，但「发到哪」勾上后，页面上仍然摆着图文、长文——看着像能发，其实是灰的。
- 老板要的是：**哪家、哪天、发什么**，打开一张表就看清。

## 二、改后的样子（一张表）

```
            周一    周二    周三    周四    周五    周六    周日
📕 小红书   [图文]  [休]    [长文]  [视频]  [图文]  [休]    [图文]
🎵 抖音     [视频]  [休]    [视频]  [视频]  [休]    [休]    [视频]
🎥 视频号   [视频]  [休]    [视频]  [休]    [休]    [休]    [视频]
时间       12:00   12:00   12:00   20:00   12:00   12:00   12:00
```

- 每格点开只有这家**真能发**的形式：
  - 📕 小红书：休 / 📚图文 / 📚长文 / 📚视频 / 🔥图文 / 🔥长文 / 🔥视频
  - 🎵 抖音：休 / 📚视频 / 🔥视频
  - 🎥 视频号：休 / 📚视频 / 🔥视频
- 图文、长文在抖音/视频号两行**不出现**（不是灰着）。
- 每格底下带状态：等备稿 / 草稿 / 代发 / 已发；点格可跳到那一篇。
- 时间一天一个点，三行共用；今天那一列高亮。

## 三、定的口径（11 条）

| # | 事项 | 定的 |
|---|---|---|
| 1 | 表怎么摆 | **三行平台 × 七列天**（一周一张表，正好“每周三条”） |
| 2 | 每家能选什么 | 小红书图文/长文/视频；抖音、视频号只有视频；图文长文在那两行不出现 |
| 3 | 同一天不同线 | **可以各选各的线**（小红书知识图文 + 抖音引流视频） |
| 4 | 视频共用 | 同一天视频**只认一条线**，共录一支片；任一家改了视频的线，其余视频格自动跟过去，并 toast 说明。图文/长文不受影响 |
| 5 | 发布时间 | **一天一个点，三行共用**（跟现在一样） |
| 6 | 老数据搬家 | **自动展开，不弹搬家页**：小红书保留原形式；抖音/视频号补成同线视频；历史档案不动 |
| 7 | 档案出几行 | **视频只出一行**（发布时勾抖音+视频号）；小红书图文/长文各一行 |
| 8 | 生成与排产 | 「⚡ 立即生成一篇」仍按今天出（有图文出图文，有视频格出一支片，同一天最多两篇）；排产表配比按**实际篇数**算，同一支片发多家只算一次 |
| 9 | 一家没料连不连累 | **不连累**：视频号没绑/没料只跳过那一家，小红书和抖音照发 |
| 10 | 用不了的行 | 基础档、演示号**不显示**抖音、视频号两行；底下留一句“要发这两家得开全平台版并绑号” |
| 11 | 休怎么算 | 三行都休＝这天整休；只选一家＝只发那家；某格不选＝那家那天不发 |

### 视频格自动跟线（第 4 条的落法）

- 同一天只要有任意一格选了「视频」，其余平台若也选了视频，自动改成同一条线。
- 例子：小红书先选「📚 知识·视频」，抖音原来选着「🔥 引流·视频」→ 抖音自动跟成「📚 知识·视频」，提示一句「同一天视频共用一支片，抖音已跟成知识·视频」。
- 小红书选图文、抖音选视频不算冲突：那是两篇东西，各走各的线。
- 理由：一支片只录一次；要不同线就是两支片，时长和额度都翻倍，这轮不做。

## 四、老数据怎么搬（不做迁移页）

| 老数据 | 搬成 |
|---|---|
| 周一 知识·图文，发到哪＝小红书 | 📕 小红书＝📚图文；抖音、视频号＝休 |
| 周三 知识·图文，发到哪＝全平台 | 📕 小红书＝📚图文；🎵 抖音＝📚视频；🎥 视频号＝📚视频 |
| 周五 引流·视频，发到哪＝抖音＋视频号 | 📕 小红书＝休；🎵 抖音＝🔥视频；🎥 视频号＝🔥视频 |
| 某天＝休 | 三行都休 |

- 只改规划页的显示与存储；**已有档案、已排产表、历史记录一篇不动**。
- 老结构（一天一个形式 + 发到哪）保留只读，第一次打开时按上表展开成新表并存下来，之后不再回读老结构。

## 五、不做

- 抖音图文入口（照 10-29 口径，仍只做视频）。
- 同一天视频平台各写各的（两支片）。
- 档案按平台拆成三行。
- 每格单独设发布时间（先共用一天一个点）。
- `extension`、`executor` 两份副本这轮不跟。

## 六、验收（怎么算做完）

1. 规划页是一张三行平台 × 七列天的表，今天那列高亮。
2. 抖音、视频号两行的格子里**没有**图文、长文选项。
3. 同一天改了视频的线，其余视频格自动跟线并提示；图文/长文不被带着改。
4. 基础档/演示号只看到小红书一行，底下有一句原因；开了全平台版且绑了视频号才出现三行。
5. 时间仍是一天一个点；某格不选＝那家那天不发；三行都不选＝整休。
6. 老账号打开页面：按第四节自动展开，历史档案不乱。
7. 档案里视频仍是一行，发布时勾抖音+视频号；小红书图文/长文各自一行。
8. 「立即生成」和排产表按实际篇数算，同一支片不重复计数。
