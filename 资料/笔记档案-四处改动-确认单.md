## 一、缩略图变成 3:4 小封面

**现状**：一格 42×38；图只从四处取（画面表 / 门面封面 / 门面配图 / 卖点配图），导图长图被漏掉；取不到就显示 📄/📝/🎬 图标。

**改成**
- 尺寸：42×38 → **48×64（3:4）**；列宽 44px → **50px**；圆角、居中裁切不变。
- 找图顺序：
  1. 画面表里这篇排好的图（原样）
  2. **导图/长图工作区出的那张长图**（新）
  3. **素材库里记着「用在这篇」的图**（新）
  4. **成片第一帧**（新，只对出过成片的视频篇）
  5. 门面封面 / 门面配图 / 卖点配图（原样）
  6. 都没有：保持现在的图标
- 成片首帧只在本机内存里算一次，不另存、不改档案。
- 素材库的图删了，缩略图跟着退到下一个来源或图标（跟现在一样「现取」）。
- 没图的篇**不做**默认封面。

## 二、时间列去掉「编过片」

**现状**：进过出片台但没出片 → 「🎬 编过片」；出过片 → 「🎬 已出片 · 多久前」。

**改成**：只保留「已出片」；没出片就空着。

**待确认**：如果你圈的那两篇其实导出过成片，那是出片时间没记上——要单独查出片那边，不能只删标签。

**已定（10-25）**：那两篇确实出过成片，按「已出片」认。根因是案例拼片只记了 `n.asm.film.at`、字效导出才写 `xhsFilmDocs.outAt`，两边没并。现在三处时间合并取最新；连时间都没记上、但本机素材仓存着那条片子的，也标「已出片」（不带时间）。

## 三、内容列去掉「🎬 成片已出」

**现状**：内容格那排小标签里有「🎬 成片已出」，跟时间列「已出片」重复。

**改成**：删掉这一种；没出片的「🎬 剪了 N 段」保留（它讲剪了几段，不重复）。

## 四、玩法格：没招式的篇能补一招

**现状**：门面篇＝介绍/承接；引流篇＝建篇时钉的招式（可点）；老档＝（老档）没记招式；知识/案例/长文＝「—」。

**改成**
- 任何非门面篇、还没记招式 → 玩法格显示「＋补一招」小按钮（老档那句也换成这个按钮）。
- 点开从玩法池现有的招里挑一招，记在这一篇上；记完显示「🎭 招式名」，点它照旧跳复盘看这一招的账。
- 挑的时候能「✕ 清掉这一篇的招式」（可撤）。
- **只改这一篇，不动「本轮钉的那一招」**。
- 复盘玩法账不用改：它按「这一篇记了哪一招」归堆，跟方向无关；知识/案例篇补记后也会进账。
- 玩法列 58px → **88px**（原定 68px，实测只放得下两个字，四个字的招式名会被截成「出题…」；88px 能放下「＋补一招」和「🎭 四字招 ＋ ✕」）。
