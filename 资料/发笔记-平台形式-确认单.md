## 一、要解决什么

- 规划层只会出**图文 / 长文**，且稿子写死 `platform:'xhs'`——抖音、视频号根本没有排期入口。
- 视频出片（「PPT字体动效」）其实**本机就能做**，跑在客户那台机的浏览器里（canvas＋MediaRecorder 实时录），**跟服务器内存无关**（上一轮「压片内存不够」的说法作废）。
- 真正的限制只有一条：**录片是实时的，页面必须开着**。凌晨 02:00 只能写稿＋切分镜。
- 多平台不是「一篇改三版」：**小红书要图文，抖音/视频号要视频，这是两篇东西**（标题、正文、素材各自独立）。

## 三、三条硬限制（照旧要说）

1. **录片必须页面开着**：一条 60 秒的片子要 60 秒以上机器时间；关窗口就断。所以视频篇的流程是：02:00 写稿＋切分镜 → 打开页面时录片 → 料齐到点发。
2. **公网那台没有凌晨闹钟**：靠当天第一次打开页面补写，不追补前几天。全平台那天＝两篇各写一遍。
3. **抖音 / 视频号受档位与绑定限制**：全平台版那一档才给发；没绑号的那家到点跳过。

## 五、验收（怎么算做完）

1. 规划页一天六颗胶囊：📚图文 / 📚长文 / 📚视频 / 🔥图文 / 🔥长文 / 🔥视频。
2. 选了「抖音」：「发到哪」显示抖音，图文/长文两颗灰；正选着图文则自动变成视频并提示。
3. 选了「长文」：「发到哪」锁在小红书，下拉灰，点了有一句原因。
4. 基础档账号：抖音 / 视频号 / 抖音＋视频号 / 全平台在菜单里灰着，写着「没开全平台版」。
5. 点「⚡ 立即生成一篇」：一次列七种组合，选哪个就按那个出。
6. 排了视频的那天：02:00 出稿＋分镜；打开页面开始录片，进度条走「正在录片 x/60 秒」；录完进档案标「代发」。
7. 选「全平台」：那一天显示两篇；02:00 两篇各写一遍；进度条先图文后视频；档案出两行。
8. 到点发：图文那篇只发小红书；视频那篇发抖音＋视频号（同一支片）；视频号没绑/超日限就跳过并记一条；缺成片挂「等您接手」。
9. 图文篇行为跟现在完全一样（小红书），老档案打开不乱。

## 六、这轮不做

- 混剪、数字人进规划（要你选段 / 要照片授权，做不到全自动）。
- 抖音图文入口开放。
- 抖音、视频号各写一版文案（先共用一份，标题差别发布时改）。
- `extension`、`executor` 两份副本这轮不跟（跟主本对齐放到出客户包之前一起做）。
