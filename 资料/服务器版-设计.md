## 一、这是什么

一个**"试用"网址**：客户打开就能用——

- **一部分真跑**（真界面、真服务器、真 AI）：进来填问卷 → 人设 / 卖点 / 知识库 / 规划出来 → 开始写笔记；
- **一部分不能体验**（扩展功能）：界面保留、照配假数据，但整块**置灰、点不动**，留一句话说明「要装扩展才能真跑」；
- **用处**：把网址发出去，客户先试效果，好用再装扩展；
- **原扩展照旧**：demo 是**另做的副本**（界面、后台都是复制一份进来）——真正交付的产品（扩展）一个字不动、打包升级照旧；demo 只当卖的时候拿给人先看的「橱窗」，不是替代品。
- **对外说辞（2026-10-12 定）**：在小红书上公开吆喝 / 卖的就是这个"**帮忙写笔记**的工具"——它不碰平台，是普通软件，可以光明正大；"自动发 / 自动获客 / 做 IP"这些留在把人拉进来之后再说。

## 二、标记法：能体验的 / 不能体验的（客户一眼分明）

**两分法**（2026-10-12 老板定）：

- **能体验的 → 做真的**：正常显示、随便点随便用；导航上带一个绿点。
- **不能体验的 → 界面保留 + 置灰 + 一句话**：页面一个都不删（客户看得到产品全貌），但整块**灰显、点不动**，顶上留一句话说明——
  - 要装扩展的（获客 / 截流 / 线索 / 日常浏览 / 发布台 / 手机看板）：「这块要装到浏览器里（扩展）才能真用——试用版先给你看界面」；
  - 这版没有的（抓主页验证 / 整机备份 / AI 模型配置）：「试用版不提供这一项，装了扩展就有」。

- 落法：不能体验的导航项整体置灰（浅字＋灰点）；打开这类页面，页头一条灰带带那句话；demo 横幅里带一行图例（绿点＝能真用，灰＝不能体验，看说明）。
- 标记用**外挂样式层**做（不改界面本体），以后调整只动这一层。

## 三、页面分两类（2026-10-12 按真实界面逐页核对；同日老板二改：获客 / AI 客服的**配置**也改成能点）

### 🟢 能体验（做真的）

| 块 | 内容 |
|---|---|
| 诊断&配置（六页） | 基础配置（**除"抓本人主页"**）、问卷、人设/说话风格、产品卖点、知识库、规划（AI 出内容规划） |
| 发笔记 | 任务配置（内容基调 / 出图风格）、写稿向导（挑稿 / 改稿 / 多平台改写）、笔记档案、素材库、教程页 |
| 获客·配置 | 任务配置（搜什么词 / 盯谁 / 推广目标）、设置（拟人化与频率）、队列页里「📖 评论策略」「⚙️ 队列配置」两个配置签——能点能改、改了存服务器 |
| 线索·配置（AI 客服） | 任务配置（🎙 渠道基调 / 💰 成交引导）、设置（🤖 Bot 间隔）——能点能改 |
| 设置 | 租户 / 产品、界面主题、日志统计、拟人化与频率、账号安全 |
| 收口 | 写好的稿：复制文案 / 下载料（真能拿走） |

### ⚪ 不能体验（界面保留 · 置灰 · 一句话）

| 块 | 那句话（口径） | 怎么摆 |
|---|---|---|
| **要装扩展**（真干活、离不开扩展的）：获客·工作台（评论分析 / 商机）、获客·笔记池（扫进来的笔记）、队列页的「🤖 开始」那步、线索·通知（平台消息）、线索·消息（私信往来）、发笔记·发布台（发布队列 + 笔记规划）、发笔记·复盘（要看平台数据）；写稿走到"发"那步拦下 | 「要装到浏览器里（扩展）才能真用——试用版先给你看界面」 | 照摆演示数据（看着像真在跑），整块灰显、点不动；"发 / 开始"那步拦下提示 |
| **这版不做**：抓本人主页（在基础配置里）、AI 模型配置、整机备份 / 恢复、（一期）造图片 / 字效编辑器（出片台） | 「试用版不提供这一项，装了扩展就有」 | 按钮 / 入口直接置灰 |

> 大原则：**能体验的做真的、不能体验的界面保留置灰＋一句话**；个别页到实施时按这条原则微调。
> 归属说明（已核实界面）：**截流**没有独立页——它就是获客里评论那套机制（落在笔记池 / 工作台里）；**日常浏览**的设置挂在获客·队列页里；**手机看板**不是界面页（是后台给"手机桥"同步数据的机制），demo 里不出现。造图片 / 出片二期转真（见 §六）。
> 2026-10-12 晚补（老板口径·**销售收口**）：获客 / AI 客服两个模块**保留总菜单**入口；在其页面上（灰带那句旁边）加「**还有更多功能 → 联系我＋价格表**」，把试用的人直接往成交引。价格表列哪个口径待定（三档现价 / "免费试用 1 个月"）；配置页照旧能点（二改口径不变），"只留总菜单空壳"的更收法待老板再确认。

## 四、关键设计

1. **全局 demo 横幅**：一句话讲清「试用版——填问卷/写稿能真用；获客、发布要装扩展」＋两分图例（绿点能真用 / 灰不能体验，看说明）＋引导。
2. **演示数据＝预置一个"正在运营"的演示账号**：假产品、假人设、假档案、假队列进度、假消息往来——用真界面的渲染逻辑画出来，页面不空；但这些页整块灰显、点不动（就是"不能体验"的样子）。
3. **真跑部分零门槛**：AI Key 在服务器上；客户填**简版问卷**（砍到一屏填完的量，问的还是事实）→ 直接出人设 / 卖点 → 开写。
4. **发笔记里"写"的真做、"发"的那步**拦下（服务器拿不到平台登录态，物理上替不了）→ 置灰提示「要自动发？装扩展」。
5. **免费额度＋留人**：写稿花的是真钱（AI 调用），免费先限量——进来先留个联系方式（手机号 / 微信）再开写；额度用完提示往下走（装执行器 / 联系老板）。**额度（2026-10-12 晚老板拍）：每个 IP 50 篇**；落地细则——主账挂在留的联系方式上、IP 兼底防刷（免得同一个 WiFi 下自己人互吃额度）。
6. **收口那句话（升级钩子）**：稿子写好、能复制能下载那一步的旁边，放一句「想直接发出去？想让它自己帮你找客户？装执行器（扩展）」——和第 4 条的拦截提示前后呼应，把免费的人往付费引。
7. **线下来的人怎么接（人工转化）**：从建材城 / 线下扫码进来的不走自助——试用网址当"演示器"，现场写两篇给他看；之后转成"帮你装好 / 帮你运营"。定个简单跟进口径（谁加微信、装好后怎么开机检查），免得人来了没人接。
8. **服务器当遥控器，不当大脑（口径）**：服务器只做三件——下令、记账、看结果；碰平台的动作永远留在客户浏览器里。执行器（扩展）**两种模式**：接上服务器＝能被统一指挥、被看见；不接＝照旧自己全能跑（断网 / 服务器关了都不影响）。本 demo 一期先不做遥控通道（先把免费写稿这条跑通），通道已在 §七"附加验证"实锤、三期 / 正式版直接往上长。**注（10-12 晚拍）：付费客户的"钥匙版"联动是另一件事——一期就动手、先做小试验见 §七。**

## 五、技术路线（沿用）

- **界面：整套复制一份**（扩展 popup 界面文件复制进 demo，原件一字不改）＋ 一层"翻译层"＋一层"颜色/标记层"：
  - 真跑动作 → 请求服务器（真 AI）；不能体验的动作 → 拦下 + 预置假数据 / 提示「要扩展」；
  - 标记层外挂（绿点 / 灰点、灰带与那句话）。
- **后台：只接"发笔记 + 诊断&配置"的动作**；其余动作被翻译层拦成演示。
- **存储**：服务器一个数据目录（结构照扩展的样子来）；演示数据＝一份种子。
- **extension/ 一个字不动**（不删、不改、不挪——打包交付照旧）；demo 的副本与全部新代码进 `server/` + `web/`；demo 是快照，改它不牵动扩展。

### 施工记录

**第 1 步 · 试打开界面 —— ✅ 通过（2026-10-12）**

  1. 首次设置弹窗（"先完成首次设置，才能开干"）因存储为空而弹出——第 4 步种子数据解决，或第 2 步给翻译层预设值；

**附加验证 · 服务器隔空指挥扩展 —— ✅ 实锤（2026-10-12）**
