# 推广物料 · 使用说明

> 一套两件：**A4 双面传单**（210×297mm）+ **名片**（90×54mm，双面）。
> 两个二维码：**视频码**（看打法演示）+ **微信码**（加个人微信）。

---

## 一、现在是什么状态

`输出/` 里是渲染好的成品，但**两个二维码都还是占位状态**：

| 文件 | 说明 |
|---|---|
| `A4传单-黑白.pdf` | 传单**默认版**，白底黑字，自己用黑白打印机打（省钱） |
| `A4传单-彩色.pdf` / `名片-彩色.pdf` | 深色底 + 金色。**名片默认就是这版**（快印店彩印不加钱）；传单这版是彩印 / 留档备选 |
| `A4传单-出血版.pdf` / `名片-出血版.pdf` | 彩色 + 四周各 +3mm 出血（A4 216×303 / 名片 96×60），印刷厂要求出血时用 |
| `A4传单-{黑白,彩色}-{正面,背面}.png` / `名片-彩色-{正面,背面}.png` | 300dpi 预览图，手机上先看效果 |

> 黑白不是彩色转灰度，而是**单独一套白底黑字主题**——深色满版转灰度会糊成一片，还特别费墨。两件物料默认色不同：**A4 传单默认黑白**（自己大批量打，省墨），**名片默认彩色**（拿快印店印，彩印不加钱，黑白的没人用）。名片黑白版 CSS 还留着（`class="bw"`），但默认不出片。

⚠️ **现在还不能拿去印**：视频码是占位链接（码上盖了红叉「待替换·勿印」），微信码是虚线框占位图。先把下面两个码换掉。

## 二、换成你的真实二维码（两步）

### 1. 视频码 —— 换成真实视频链接

打开 `scripts/dev/gen_promo_qr.py`，第 21 行：

```python
VIDEO_URL = 'https://example.com/video'   # ← 真实视频链接填这里
```

改成真实链接（小红书笔记 / B站 / 视频号 / 自建落地页都行），或者不改文件、直接带参数跑：

```bash
python3 scripts/dev/gen_promo_qr.py --video-url "你的视频链接"
```

链接里不再含 `example.com` 时，红叉警示条会自动消失。

### 2. 微信码 —— 把微信的二维码截图放进来

微信 App →「我」→ 右上角二维码 → 保存图片，**重命名成 `qr-wechat.png`**，覆盖到：

```
资料/推广物料/assets/qr-wechat.png
```

（正方形、白底最好；脚本只在文件不存在时才画占位图，文件放了就不会覆盖。）

### 3. 重新出片

```bash
python3 scripts/dev/render_promo.py
```

会自动重出 PDF + PNG，并做**溢出检查**——输出里没有「溢出」字样，且每行都是「2 面, PDF 2 页 OK」，就说明排版没问题。
渲染完在 `输出/` 里，**先看一遍 PNG 预览**，确认两个码都能扫出来（拿手机扫一下 PNG 里的码测试，别等印完才发现）。

## 三、印刷参数（给快印店的话）

| | A4 传单 | 名片 |
|---|---|---|
| 成品尺寸 | 210 × 297 mm | 90 × 54 mm |
| 出血版尺寸 | 216 × 303 mm | 96 × 60 mm |
| 页数 | 正面 + 背面 | 正面 + 背面 |
| 建议纸张 | 157g 铜版纸（双面彩印） | 300g 铜版纸 / 白卡，可选哑膜 |
| 色彩 | CMYK，满版深色底 | 同左 |

### 黑白打印（只给 A4 传单用）

黑白打印机 / 复印机 → 用 `A4传单-黑白.pdf`：

- 白底黑字，**不用满版深色底**，普通 A4 纸（70~80g）直接打就清楚，也不容易卡纸、不费墨。
- 纸张用 80g 复印纸就够（想挺括一点用 100~120g 双胶纸）。
- 占位二维码上的红叉警示条在黑白机上会打成**浅灰色**，不影响识别（反正印前必定换掉）。
- **名片不要打黑白版**——名片是快印店印的，彩印不加钱；黑白版默认不出片，也基本没人用。

### 彩色打印（名片走这里；A4 彩印备选）

- 名片：300g 铜版纸 / 白卡 + **哑膜或过塑**——手上摸得多，不覆膜容易花、容易脏。
- 深色大面积印刷容易看出横纹、掉墨，**选数码快印 + 铜版纸哑膜**效果最稳；印前让店家先打一张样。
- A4 传单要彩印的话：墨量偏大，少量印（几十上百份）没问题；如果要印几千份，先问下店家报价再决定要不要改浅色版（或直接走黑白版）。

## 四、两条合规提醒

1. **这套物料是线下用的**（递名片、贴/放桌面、活动现场发），直接印微信二维码没问题。
2. **别把 A4 的内容原样发成小红书笔记**——小红书站内导流微信是踩红线的。要发站内，把两个二维码换成「看主页简介 / 私信我」，承接只走站内私信（这是咱们一直的规矩）。

## 五、改文案 / 改版式

物料是 HTML，改字直接编辑：

- `资料/推广物料/A4传单.html`
- `资料/推广物料/名片.html`

页面尺寸由 `:root` 里的 `--pw / --ph`（A4）、`--cw / --ch`（名片）控制，改完重跑 `render_promo.py` 即可。
渲染脚本里的 `JOBS` 已经写好出血版的 CSS 覆盖，不用手动调。

**两套配色都在同一个 HTML 里**，`<style>` 末尾各有一个覆盖块：传单是 `body:not(.color)`（不加 class 就是白底黑字，传单默认走这套；给 `<body>` 加 `class="color"` 出彩色）；名片是 `body.bw`（不加 class 就是深色 + 金色，名片默认走这套；加 `class="bw"` 出黑白）。出哪几版由 `render_promo.py` 的 `JOBS` 控制——传单出黑白 / 彩色 / 出血三版，名片出彩色 / 出血两版。所以改字只改一处，两版一起更新——**不用维护两份文件**。如果某个元素在另一套配色下颜色不对，去对应的覆盖块里补一条就行。

**两页开头各有一句过渡行**，共用 `.trans` 这个类：正面「您先别急着答，看完下面这 9 个问题再说。」、背面「接着上面，还有 5 个」。字体字号由 `.trans` 一处控制，改句子时**两句一起改**，别让两页的过渡行长得不一样。里面的 `<em>` 是金色强调（如「9 个问题」「5 个」）。

**版面很满，加字先量**。9 问的分布是 **正面第 1~4 问、背面第 5~9 问**（第 4 问竞品对比最占地方，AI-Skill 列有两格排到两行，该表字号已压到 3.1mm；第 9 问是三档卡片 `.tiers`，卡里正文字号 2.9mm、行距 1.4，已到下限；三张卡等高，高度由内容最多的③卡决定）。当前富余：正面约 9px、背面约 1px，都由 `margin-top:auto` 堆在页尾（翻面提示 / 二维码上方）——背面基本顶死了，任何加字都要先量：

```bash
# 临时量一版：打印每页的 over（>0 就是溢出），改完删掉
python3 - <<'EOF'
import pathlib
from playwright.sync_api import sync_playwright
u = pathlib.Path('资料/推广物料/A4传单.html').resolve().as_uri()
with sync_playwright() as pw:
    b = pw.chromium.launch(); p = b.new_page(); p.goto(u)
    p.emulate_media(media='print'); p.wait_for_timeout(300)
    print(p.evaluate("()=>[...document.querySelectorAll('.page')].map((e,i)=>[i+1,e.scrollHeight-e.clientHeight])"))
    b.close()
EOF
```

嫌挤就减字号/行高（`.qc > p`、`.back .qa-list` 的 `gap`），或者删一句文案；**别动 `--py` 页边距**，那是出血线的安全距离。
