# 功能总览（图＝`assets/功能总览.png`）

**四个模块，一条链**：发内容 → 捞客户 → 跟客户 → 管账号

## ① 发笔记——您要发的，就 3 类，各有各的活

- **知识笔记＝立专业**——拿您的知识库讲一条——怎么选、怎么避坑、多少钱算合理；让搜这类问题的客户先搜到您、先信您。**能出：**思维导图 / 竖版视频 / 口播稿
- **引流笔记＝抓流量**——借大家正在聊的话头——热点、热梗、情绪、感悟，把还不认识您的路人吸引进来。**能出：**图文 / 竖版视频
- **案例笔记＝加信度**——实拍、完工现场、真实结果丢进去——快速切片、每段配一句讲解、拼成成片；一条案例拆成多条视频讲。**能出：**竖版视频
- **AI 出稿，您把关**——一次出 18 版，挑一版改顺就发。
- **发布台**——AI 排期 · 排队到点自己发 · 素材自动归位 · 每篇留档；一篇定稿，各平台各出各的版本（小红书 / 抖音 / 视频号）。

## ② 评论区获客——去客户正在看的地方接，就干 3 件事

- **找对地方**——AI 找词 · 刷笔记采词 · 自己维护，都进一个词池。

**接对话**（5 种笔记，5 种聊法）

- **正在上涨的笔记＝抢前排**——流量正在往上走的笔记——露脸的话抢先评一条，占住前排。
- **搜索老帖＝占深度**——长期有人搜得到——写一条够专业的深度解答，长期排前面。
- **同城帖＝拉近乎**——用本地口吻聊一句——让同城客户觉得「是自己人」。
- **求助帖＝给方案**——主动求助的就是最准的客户——一个个给解答、给方案。
- **大V帖＝补干货**——大博主流量大——去评论区补一条内行干货，借流量露个脸。

- **说对话**——12 种评论打法，看菜下饭；只跟主动问「哪家好」的人聊，不该评的自动跳过。

## ③ AI 客服——捞到的人，不漏

- **AI 主动私信**（图上标红·重点）——评论区捞到的人找上去——按对方情况拟好，您点头才发。
- **客户名单**——谁走到哪一步、谈没谈成，一眼看清。
- **通知回访**——有人回您了，替您盯着；该接的话一个不落。
- **自动接待**——来问的按您话术库先聊上；新消息有角标提醒。

## ④ 账号诊断与配置——先把您的号照一遍

- **账号诊断**——6 个维度把您的号照一遍：定位 · 人群 · 频率 · 选题 · 内容硬伤 · 历史归因——交您一张「这个号该怎么做」的施工图。**交您四样：**人设方向 / 笔记结构 / 选题清单 / 发布节奏
- **再配置**——人设（说话风格）· 卖点库（卖什么、凭什么）· 知识库（只引您的真资料）· 内容规划（一周几篇怎么搭）。

**所有档位都带：**多产品切换 · 数据只存本机 · 发送间隔与停留时间自己设

# 功能全图（图＝`assets/功能架构图.png`）

**四个模块，一条链**：发内容 → 捞客户 → 跟客户 → 管账号

## ① 发笔记——您要发的，就 3 类，各有各的活

**笔记类型**

1. **知识笔记＝立专业**——拿您的知识库讲一条——怎么选、怎么避坑、多少钱算合理，让搜这类问题的客户先搜到您、先信您。**能出：**思维导图 / 竖版视频 / 口播稿
2. **引流笔记＝抓流量**——借大家正在聊的话头——热点、热梗、情绪、感悟，把还不认识您的路人吸引进来。一次出 18 版，挑一版改顺就发。**能出：**图文 / 竖版视频
3. **案例笔记＝加信度**——实拍、完工现场、真实结果丢进去——快速切片、每段配一句讲解、拼成成片；一条案例拆成多条视频讲。**能出：**竖版视频

**发布台**（一篇笔记从备料到留档，都在这儿）

- **笔记规划**——按账号阶段排——一周哪天发知识、哪天发引流、哪天发案例；AI 先排一版，您能改。
- **发布队列**——写好的笔记自动排进最早的空位——到点自己发，不用人守。
- **素材库**——每篇要配的料，AI 先列清单——要有几张、缺几张、用在哪，一眼看清；传上来的图、剪好的段，自动按集合归好。
- **笔记档案**——写过的都留档——每篇走到哪一步，一眼看清。
- **发布支持**——小红书 / 抖音 / 视频号（视频三家都能发，图文只发小红书和抖音）。

**AI 出稿，您把关**——一篇定稿，各平台各出各的版本。

## ② 评论区获客——去客户正在看的地方接——就干 3 件事

**第 1 件 · 找对地方**（三个来源，都进同一个词池）

- **AI 找词**——AI 按您的人设、卖点、知识库推荐关键词，勾选入池。
- **刷笔记采词**——平时刷到的笔记，#话题自动采下来——读得越多越准。
- **自己维护**——想搜什么词自己加、随时改。

**第 2 件 · 接对话**（5 种笔记，5 种聊法）

- **正在上涨的笔记＝抢前排**——流量正在往上走的笔记——露脸的话抢先评一条，占住前排。
- **搜索老帖＝占深度**——这类帖子长期有人搜得到——写一条够专业的深度解答，长期排前面给您露脸。
- **同城帖＝拉近乎**——用本地人的口吻聊一句——同城客户刷到一看是「自己人」，信任先立住。
- **求助帖＝给方案**——主动求助的就是最准的客户——评论里求助的、同问的，一个个给解答、给方案。
- **大V帖＝补干货**——大博主的笔记流量大——去评论区补一条内行干货，借他的流量露个脸。

**第 3 件 · 说对话**（12 种评论打法，看菜下饭）

教程 · 避坑 · 对比 · 数据 · 反驳 · 补充 · 反向共情 · 共情 · 热点 · 带赞 · 提问 · 求教

要教程给教程、要共情给共情；纯捧场、不带货也照发——不刷屏、不招黑。

**守着两条线：**

- 一是只跟主动问「哪家好」的人聊——求助的、疑问的、被坑过的，不该评的自动跳过；
- 二是节奏是真人节奏——逐字打字 · 间隔随机 · 每天有量上限，看着像您本人在回。

评论区里感兴趣的人，**顺手记进客户名单**。

## ③ AI 客服——捞到的人，不漏

**跟客户**（捞到的人，一个个跟到底）

- **私信触达**——评论区捞到的人，**AI 主动私信**找上去——按对方情况拟好，您点头才发。
- **客户名单**——谁走到哪一步、谈没谈成，打开一眼看清。
- **通知回访**——有人回您了，替您盯着；该接的话，一个不落。

**接住来问的**（客服的活，也接过来）

- **自动接待**——有人私信来问、评论里搭话——它按您的话术库先聊上、该跟的自动跟；新消息有角标提醒。
- **客服话术库**——接话的话术，您自己定。

## ④ 账号诊断与配置——先把您的号照一遍

**先诊断**

- **账号诊断**——6 个维度把您的号照一遍：定位（卖什么、卖给谁）· 人群（写给谁看）· 频率（发多发少）· 选题（踩不踩痛点）· 内容硬伤（标题、封面、开头）· 历史归因（哪篇爆了、哪篇沉了）。不是一句「挺好」，是一张「你这个号该怎么做」的施工图。**交您四样：**人设方向 / 笔记结构 / 选题清单 / 发布节奏

**再配置**（AI 开口前，先把您的料配齐）

- **人设**——把说话风格定下来——AI 从头到尾照您的口吻说话。
- **卖点库**——卖什么、凭什么——AI 说话都从这儿取。
- **知识库**——AI 只引您的真资料——数字、功能、经历都从这来，编不出来。
- **内容规划**——一周发几篇、几类怎么搭，按账号阶段排好。

## 跑起来之后——越跑越准

- **复盘**——今天发了多少、回了谁、用了什么话术——AI 一条条记账，随时回看、一键复制；这些又喂回诊断，下一轮选题、话术越调越准。
