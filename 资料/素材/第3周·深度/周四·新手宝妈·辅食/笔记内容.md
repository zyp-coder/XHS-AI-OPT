# 宝宝辅食什么时候加？每月解锁什么？

我家宝宝5个月的时候，我老婆就开始研究辅食。
第一次做南瓜泥，蒸了半小时、打成泥，
宝宝吃了一口，表情像吃了柠檬。

后来才知道，辅食添加是有节奏的，急不来。

4-6月：高铁米粉、南瓜泥、胡萝卜泥（单一食材逐一试）
6-7月：西兰花泥、蛋黄、牛油果（增加品种）
7-8月：猪肉泥、鸡肉泥、豆腐（开始加肉）
8-9月：手指食物，BLW自主进食
12月+：基本跟大人吃，少盐少油

每新增一种食材，连续吃3天观察过敏反应。
我家试蛋黄的时候起了红疹，停了3个月再试就好了。
