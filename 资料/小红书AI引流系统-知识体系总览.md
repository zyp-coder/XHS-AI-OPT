## 一、一句话定位与目标用户

**一句话定位：**
> 小红书全自动获客系统——断症找方向、练剑产内容、截流捞客户。AI 替你在目标笔记评论区找到真需求的人、写像真人随口聊的评论、按自然节奏发出去，把小红书流量引到你的主页简介/私信承接。不雇运营、不刷手机，一个人管多个产品。

**系统形态 = 运营后台（Web）+ 小红书评论助手（浏览器扩展）。**

**目标用户：**
- 想在小红书获客，但没时间 / 没团队 / 没运营经验的个人创业者（小程序 / App / 公众号 / 私域）
- 微商、实体店、知识付费卖家
- 代运营团队
- 一个人跑多个产品的多品类玩家

**"你只做 3 件事"：**
1. 填产品信息
2. 录知识库（产品资料 + 真实数据 + 个人经历，AI 回评时自动引用，越细越专业）
3. 设引流关键词点开始

## 二、核心运营方法论：断症→练剑→截流→跟进 闭环

系统把这套小红书获客当成一条**完整漏斗**跑。这是对外一切说辞的骨架，口播讲产品时最好按这个顺序讲。

| 环节 | 解决什么 | 靠什么落地 | 一句话 |
|------|---------|-----------|--------|
| ① 断症 | 方向错 = 白努力 | 后台数据看板 / 笔记统计 / 回复日志 / 引流任务复盘 + 账号诊断（频率建议/选题清单/分阶段笔记规划/笔记架构/结构诊断，可导出 PDF） | 让你不白忙 |
| ② 练剑 | 写了没人看 | 4 周日历 28 篇选题 + 素材库 + 话术库 + 操作手册 + 自营笔记冷启动 + 发笔记向导（可定时发布） | 让你会生产 |
| ③ 截流 | 涨粉不成交 | 一键灌水 / AI 商机发现 / 12 类心理话术随机 / 拟人化节奏 / 商机快筛 | 让你直接见钱 |
| ④ 跟进 | 流量不沉淀 | 获客清单（CRM）+ AI 人群画像 + AI 一对一私信 + 评论跟进（通知页回评） | 把客户跟到底 |

**一句话点破：** 方向 → 内容 → 捞客 → 成交，四层一条漏斗，市面上工具只做其中一环，我们打通了「诊断—生产—转化—跟进」的闭环。

## 三、三大支柱的底层设计逻辑

| 支柱 | 核心问题 | 底层人性 | 设计巧思 |
|------|---------|----------|---------|
| ① 断症 | 努力错方向 = 白努力 | 人对自我带滤镜、爱自嗨 | 用数据当"客观第三方"复盘，先诊断再下药 |
| ② 练剑 | 凭灵感不稳定 | 灵感不可复制 | 把灵感降维成"流水线"，28 篇选题全现成，可批量生产 |
| ③ 截流 | 流量 ≠ 客户 | 人的购买是一条心理链 | 12 类心理画像 + 随机话术，分层打、帮客户"下决心" |

> **别家给军火（火力量变）；我们给兵法（方向、对象、时机）。** 这是区分竞品的核心表达。

## 四、功能体系总览

### ① 断症（数据复盘 + 账号诊断）
- 后台数据看板：笔记数据统计、AI 调用量/成功率、引流执行数据
- 账号管理（多号 cookies 集中管）、笔记管理、回复日志（每次灌水：笔记/目标/内容/截图全留痕）
- **账号诊断（断症核心）**：输入账号阶段（起步/成长/成熟）+ 当前频率 + 想服务的人群（也可粘他人主页/笔记链接分析）→ 输出：
  1. 发笔记频率建议（几篇 / 时段 / 为什么）
  2. 选题清单（引流探饵 / 信任干货 / 转化成交）
  3. 一份短期→中期→后期的分阶段笔记规划（每篇给品类 + 页数结构 + 目的）
  4. 笔记架构建议（强制引用最新导入的知识库）
  5. 笔记结构符合度诊断（逐篇可点开检查）
  6. 一键导出 PDF
- 引流任务 3 种：自营笔记自动回复 / 关键词截流（定时跑）/ 账号追踪（盯目标号动态）
- 防失控：任务级每日上限 / 时段 / 随机间隔

### ② 练剑（内容生产）
- 4 周发布日历：冷启动→放量→深度→收割，28 篇现成选题 + 封面 + 正文 + 当天话术脚本
- 素材库、话术库、操作手册 SOP
- 自营笔记冷启动技巧（发完前 30-60 分钟先互动喂流量池）
- 三个现成行业案例（房贷计算器 / 情感测试 / 宝妈工具）知识库 JSON 一键导入
- 发笔记向导（AI 四层选题：卖点→人群→话题→成稿）+ 定时发布

### ③ 截流（自动获客）
- **一键灌水**（核心，自动跑量）：
  - 关键词搜索 → 逐篇打开目标笔记 → AI 扫评论区 → 商机判断（宁漏勿蹭，只撩真需求）→ 生成话术 → 按自然节奏发布 → 每篇标记 ✅成功 / ⚠️无商机 / ❌失败
  - 防重复 / 自动跳过自家号 / 上限保护（上下午各一轮、每轮 ≤20 篇、间隔 ≥3 小时）
  - 自动跑位：「🤖 自动」启动，🧊冷启动沿关键词列表逐篇灌（灌过的跳过）；🔄循环计划每隔 N 分钟扫一轮、只挑点赞增长中的热门笔记（受度控制约束）；两模式互斥
- **AI 评论助手**（手动精准）：一键扫评论区 → 情感/话题/商机分析 → Top3 商机 + 回复建议 → 逐条手动发
- **商机快筛**（省 AI 钱）：先轻量判断哪些评论值得深挖 + 预选知识库条目，只有值得的才走完整商机分析；还能自检抓取异常
- **商机心理画像**（核心巧思）：12 类心理标签自动匹配话术，分层打
- **话术随机引擎**：心理匹配 + 三版风格（朋友唠嗑型 / 顾问讲数据型 / 产品教用法）随机 + 拟人微调，不像群发的模板。默认 100-300 字（小红书评论上限 300）

### ④ 跟进（截流→成交的关键一环，很多工具止步于此）
- **获客清单（私域 CRM）**：AI 商机或命中收录关键词的人一键入清单 → AI 人群画像（tags/identity/needs/painPoints/intentLevel 高中低/dmAngle 私信切入角度）→ AI 一对一私信（第一句引用对方原话、先给价值、第一封绝不放链接）→ 批量画像/批量私信 → 状态漏斗全程可追踪
- **评论跟进（通知页回评）**：把纯时间戳通知流按用户整理成对话，AI 判断该不该回、何时闲聊、何时时机成熟做一次销售
- **客户跟进铁律**：自动话术只用第一次触达；对方回复后一律真人手写跟进

## 五、12 类买前心理话术体系（截流核心）

**原则：** 商机 = 用户主动露出需求/痛点/纠结/求助。宁可漏过也不牵强（宁漏勿蹭），只撩真需求——评论自然不招黑、不耗 AI。

AI 逐条读评论 + 上下文，给每个商机打**心理标签**，再按这位用户买前最容易被说动的心理匹配话术：

| # | 心理类型 | 一句话"对味"开场白（先接住再留钩） |
|---|---------|----------------------------------|
| ① | 直接问价 | "价格我先给你算算值不值，顺便说清它好在哪" |
| ② | 冲动种草 | "你既然想要，我把怎么用给你讲明白，别买错" |
| ③ | 求测评 | "我直接给你横向对比，哪个适合你一目了然" |
| ④ | 被坑替代 | "你先别气，我给你说个避坑的，省得再被坑" |
| ⑤ | 求助场景 | "你这个问题我熟，先把方法给你" |
| ⑥ | 好辩纠错 | "你这个角度有点道理，不过我再补一点" |
| ⑦ | 拖延观望 | "你拖是因为还没算清它对你值多少，我帮你算" |
| ⑧ | 白嫖/观望 | "别急着买，我先给你数据，你自己判断" |
| ⑨ | 高价值犹豫 | "这个更适合你这种，我给你细讲下" |
| ⑩ | 货比三家 | "我给你个横向对比，你就知道为啥选我" |
| ⑪ | 想学不会 | "不会没关系，我给你一步一步拆" |
| ⑫ | 沉默收藏 | "你收藏了？那我把重点给你圈出来" |

**铁律**：开口别推销、别群发；第一句一定要贴对方原话/情景，像真人"路过搭一句"；对方回你了就手写跟，别让 AI 回第二遍。

## 六、账号人设与口吻统一规范

**我是谁：** 一个自己做号、踩过一堆坑的普通人/码农。工具是我自己先用来验证过、顺手做出来的——不装、不吹、句句有出处。

**口吻规范（AI 写话术和笔记统一用它）：**
- 用第一人称"我"，像朋友聊天，不端不装；多说自己踩过的坑和真实数字（"我之前也…""我翻了100篇才有感觉"）
- 短句、大白话、适度口语（说白了/真话/别瞎使劲），少用书面语和堆形容词
- 想卖东西别硬广——先给价值/方法，再自然带一句"我把它做成工具了"，让人好奇主动问
- 不说"亲/宝子/欢迎咨询/加V"；不把话说满，讲效果加"因人而异"

## 七、知识库体系（系统核心燃料）

**作用：** AI 生成话术时自动检索匹配、**强制引用**——必须从里面抽具体的数字/事实/案例来撑观点。产品数据用于分析型回复，个人经历用于情感型回复。知识库越细 → AI 越专业 → 每条话术都有干货支撑。

**条目结构：** 标题 + 分类（个人经历/数据资料/政策法规/话术模板/通用）+ 内容 + 标签 + 可选角色 + 可选配图。

**配图能力：** 知识库条目可配图，AI 引用该条时图片随评论一起发（如计算器截图、疫苗表截图），可信度直接拉满。

**导入导出：** JSON 导入导出，多产品独立。`小红书AI引流工具知识库.json`（42 条）一键导入就能跑自己的行业。

**已收录的知识条目分类（本系统自带）：**
- 产品介绍：产品定位、三大支柱、玩法（你只做 3 件事）、一键灌水链路、商机判断标准、12 类心理话术、知识库驱动、多租户隔离、拟人化节奏、数据复盘断症、练剑 SOP、多模型切换、费用透明、账号诊断、笔记规划排序、运营体系总览、获客清单全家桶、评论跟进、发笔记向导、定时发布、商机快筛、自动灌水模式（冷启动/循环）、拟人挡位与内容红线、多产品体系、冷启动 SOP、笔记架构矩阵、种草稿与话术、12 类开场白、人设口吻、产品定位与卖点总述、核心卖点速配
- 个人经历：从手动评论到自动化、避坑（关键词太泛）、避坑（别让 AI 回第二遍）、避坑（笔记冷启动）、是否被判商机
- 数据资料：AI 费用透明、12 类商机心理画像、随机话术原理（更自然、防厌、不群发）

## 八、小红书笔记架构·品类页数匹配矩阵

**核心规则：发图文笔记前，先判断这条内容的品类，就按该品类"页数 + 每页功能(P1..Pn)"排版，选图/构图按每页功能来定。** 图文想进量，**首篇最好 ≥3 张图**（封面 + 2 内容图）。

| 品类 | 决策痛点 | 推荐结构 | 页数/功能 |
|------|---------|---------|-----------|
| 虚拟资料/知识付费 | 决策成本低，看重直观价值感+真实感 | 极简 1-3 页（大字报/目录） | P1 封面（痛点+结果+实拍）→ P2 价值（目录/内页拼图）→ P3 引导（购买指令） |
| 实物测评/红黑榜 | 选择困难，看重真实对比+客观中立 | 4-5 页（测评对比型） | P1 封面（对比图/红黑榜大字报）→ P2 避坑指南 → P3 核心维度横评+真实数据 → P4 购买建议 |
| 场景种草/生活方式 | 需要代入感，看重情绪价值+氛围感 | 4-6 页（场景种草型） | P1 封面（高颜值场景/痛点发问）→ P2 还原痛点场景 → P3 产品融入使用 → P4 真实体验+推荐理由 |
| 干货教程/技能教学 | 需要实操性，看重步骤清晰+易学 | 5-7 页（教程步骤型） | P1 封面（目标+效果对比）→ P2 准备清单 → P3 分步拆解 → P4 新手避坑 → P5 要点回顾+引导收藏 |
| 合集盘点/资源整理 | 怕麻烦，看重信息密度+收藏价值 | 4-6 页（合集清单型） | P1 封面（数字+人群）→ P2 清单概览 → P3 逐一介绍 → P4 优先级 → P5 引导收藏 |
| 个人经历/情感共鸣 | 寻求认同，看重真实人设+情绪共鸣 | 4-6 页（经验复盘型） | P1 封面（反差/情绪标签）→ P2 真实故事冲突 → P3 核心感悟金句 → P4 升华价值 → P5 抛问题引导分享 |

## 九、发笔记工作流（AI 四层选题向导）

老版的 8 节点向导 → 已升级为更顺的 4 层流水线。二者共用同一套产出形态。

**4 层流水线（全程点选，不填词，每层可"换一批"）：**
1. **定卖点**：AI 读产品 + 知识库，判断是工具型/情绪型/混合型，提炼可单独推广的卖点候选
2. **选人群**：为选中的卖点推导可覆盖的目标人群（含痛点/场景/发布时机）
3. **挑话题**：基于人群真实痛点 + 小红书生态给候选话题（含"为什么选它"、避开已发过的）
4. **写成稿**：AI 基于卖点+人群+知识库出完整笔记

**成稿产出：**
- 3 个候选标题（强钩/悬念/干货 A/B/C）
- 正文（钩子开场 → 共情 → 干货 → 价值 → CTA，7 段式）
- 5-8 个精准标签
- 配图占位 2-3 张（封面 + 内容图，每张含大字主文案、版式/构图、配色/风格、素材怎么准备）
- 建议发布时间段 + 一句"置顶自评"（发完 1 小时内贴）
- 支持导出成稿手动发 / 或定时自动发

**产出落盘结构：**
```
素材/第N周·阶段/周几·产品·选题/
├── 笔记内容.md      <- 标题 + 正文(7段式) + 标签
├── 封面.png         <- 首图
├── func1.png(2).png <- 内容图（图文≥3张利于推流）
├── 话术脚本.md      <- 当天灌水关键词 + A/B/C 话术
└── meta.json        <- title/tags/配图清单/发布时间段
```

## 十一、冷启动与发布 SOP

**冷启动真相：** 小红书新笔记有 **30-60 分钟冷启动**——平台按初期互动（点赞/评论/收藏）决定要不要继续推。发完 1 小时内别干等。

**冷启动动作：**
- 用自己号评论互动，或直接灌水自己笔记评论区引导互动
- **抢贴置顶自评**：发完 1 小时内自己抢一楼，贴一句半开放问题引导互动（别问"好不好"这种封口的）

**日常 SOP（操作手册内置）：**
```
9:00  发笔记
9:30  第一轮灌水（可含自己笔记）
12:00 查回复
15:00 第二轮灌水
20:00 复盘（看历史、调关键词）
```

**笔记规划排序逻辑（说服阶梯）：** 先破冰立人设 → 点痛示警 → 给实证建信任 → 教方法给价值 → 展示产品 → 收割促转化。频率建议"跳一跳够得着"（起步期跑通节奏、成长期稳定放量、成熟期提转化）。

## 十二、拟人化节奏与内容红线

**总原则一句话：** 动作全部收在平台规则内——内容不直导站外、节奏自然、量有上限；工具只做提效，账号状态以平台判定为准，不承诺结果。

**① 内容层红线**
- 评论/私信**绝不直发微信/链接/二维码**，导流一律「主页简介 / 私信我 / 置顶笔记」
- 话术走个人经历 + 真数据，一条不像复制粘贴
- 讲效果带"因人而异"

**② 行为层（拟人化节奏）**
- 9 项停留参数：浏览停留 / 逐字打字延迟 / 点赞间隔 / 评论懒加载等待 / 返回停顿 / 重开笔记等待 / 就绪缓冲 / 关注前停顿 / 批量发送间隔
- 一键「填入拟人推荐值」：浏览 2s/段、逐字 30ms/字、点赞间隔 500ms、批量发送间隔 8s；实际停留随机上浮最多 50%，节奏更自然
- 互动单独控制：自动关注开关 / 批量每隔几条关注一次
- 量控：一个号一天 ≤10 条封顶；新号先按低频起步；一个账号固定一台设备使用
- **一律用拟人档，不用最快档**（最快档只适合小批量测试）

**③ 资产层**
- 主号只做内容，截流账号与主号分开，互不影响
- 关键客户第一时间引到微信沉淀

**高危动作（绝对不做）：** 直发微信 / 最快档狂发 / 新号开灌 / 同设备多号。

## 十三、技术系统逻辑（架构/引擎/Prompt）

### 整体架构
```
小红书AI引流工具
├─ 运营后台（Web / FastAPI + SQLite）
│   ├─ 账号管理、笔记管理、评论互动、引流任务、数据分析
│   ├─ AI 配置、知识库、素材库、回复日志、话术库、定时发布
│   └─ 账号诊断、客户（邮箱）管理
├─ 小红书评论助手（浏览器扩展）
│   └─ 一键灌水 / 评论助手 / 评论跟进 / 获客清单 / 发笔记 / 账号诊断
└─ 能力底座
    ├─ AI 引擎（主备模型自动切换 + Prompt 管理 + 知识库/话术库注入）
    ├─ 引流引擎（3 种任务调度 + 拟人化节奏）
    ├─ 浏览器引擎（CDP 控制 + 拟人化节奏）
    └─ Android 模拟器（Google AVD + ADB 控制）
```

### AI 引擎（ai_engine.py）
- **主备模型自动切换**：优先用主模型（可配免费模型），失败时按关键词判断（额度不足/rate_limit/401/429/超时/连接错误等）自动切到备用模型（如 DeepSeek），并对每次调用记录日志（场景/提示词/响应/Token/耗时/是否成功/用哪个模型）
- **Prompt 管理**：场景化模板（system + user 模板），支持重置为默认、按租户自定义
- **双注入增强**：
  - 知识库注入：从上下文（标题/评论/正文）提取关键词搜知识库，始终载入"个人经历+产品介绍"，注入 system 并要求强制引用具体数字/事实
  - 话术库注入：从上下文检测用户角色（恋爱博主/趣味测试博主/世界杯博主/普通用户），匹配同角色高活跃话术模板注入
- **模型提供商**：DeepSeek、OpenAI、通义千问（阿里云）、硅基流动 SiliconFlow + 任意 OpenAI 兼容接口，Base URL + 模型自动匹配，支持"测试连接"

### 引流引擎（drain_engine.py）
- 3 种任务模式：**关键词截流**（定时搜词 → AI 评论）、**账号追踪**（盯目标号最新笔记 → AI 评论）、**自营笔记自动回复**（检查自己笔记新评论 → AI 回复）
- 任务生命周期：start / stop / pause，状态机 RUNNING/STOPPED/PAUSED
- **拟人化间隔**：基础随机间隔 + 额外 30-180s 随机"思考时间" + 10% 概率加 120-600s 随机长停顿（"摸鱼时间"）
- 时段窗口 + 每日上限双重控制

### AI客服场景A 体系
分为 **4 个 AI 动态分支**（按"谁的线索、有没有留邮箱"现场判断）+ **2 个固定模板**：
- AI 分支：评论回应（目标=留 QQ 邮箱）、私信首触（按来源二选一：来源A已互动自曝+留邮箱 / 来源B AI挖掘先破冰）、消息跟单、通知回访（续讲知识库）
- 固定模板：评论首评、成交维护
- 承接一律走 **QQ 邮箱 / 私信我**，不直发微信/链接/二维码

## 十四、多产品多租户隔离

**一个租户 = 一个产品**，财产完全隔离：产品信息、AI 配置、知识库、话术、获客清单、评论跟进、已灌水已回复记录整套独立。顶部下拉 / popup 顶部租户下拉一键秒切。新租户是干净白纸（空知识库 + 默认提示词），不会串数据。

**适用**：代运营团队、多品类创业者。房贷 + 情感测试 + 宝妈工具同时跑，每个产品都是一套完整的断症→练剑→截流→跟进闭环，互不干扰。

## 十五、口播稿体系（视频生态 / 分镜 / 数字人）

### 主口播稿（约 58 秒，8 段）
风格：1 分钟沉浸讲解 · 爽感种草 · 强情绪钩子。目标：一个人想低成本获客的个人创业者。人设主视觉：真人头像 → AI 漫画化（写实 Q 版 · 3D 皮克斯风）→ 套上视频。

**逐字稿骨架（8 段对话流）：**
- ① 钩子（0:00-0:05 怼镜头/皱眉）：扎心发问——一个人做小红书凌晨还在发笔记，三个月没有一个咨询客户？
- ② 停顿共情（0:05-0:11）：不是你不行，是你一直拿"军火"硬打，没用"兵法"布局——方向、对象、时机没踩对
- ③ 亮产品（0:11-0:17）：公开一套叫"AI雕兄"的小红书全自动获客系统，一人能管好几号、不用雇人不用刷手机
- ④ 断症（0:17-0:24）：先诊断账号——该发什么、一天几篇、发哪几类，全用数据告诉你方向对不对，方向对了才不白干
- ⑤ 练剑（0:24-0:32）：最怕写了没人看——直接给 4 周 28 篇现成选题，封面/正文/话术排好，复制改改就能发
- ⑥ 截流（0:32-0:43 强调/加快）：这才是见钱的地方——替你去目标笔记评论区蹲着，AI 只挑真想买/在纠结/在求助的人，自动生成不像广告的自然话术一条条发出去，不刷屏、不招黑、不显生硬
- ⑦ 跟进（0:43-0:50 平静推荐）：很多人发完评论就不管了，它不会——把捞到的客户沉淀进清单，自动私信、抢占画像、推进到成交
- ⑧ CTA 收尾（0:50-0:58 微笑轻快）：不是让你当甩手掌柜，是把精力花在真正值钱的事上。怎么配怎么用整理好了放主页简介，自己点进去拿。觉得有用关注我

### 120 字精简版（数字人/单独成片用）
> 台词 4 段 + 对应动作：① 一个人做小红书发了三月没客户——不是你不行，是没踩对方向（皱眉凑近语带心疼）；② 今天公开一套系统，AI雕兄，全自动获客，不用雇人（退后摊手）；③ 断症定方向、练剑产内容、截流只捞真客户，按自然节奏发出去、不硬广（掰手指逐条点出）；④ 还会自己跟进到成交，具体怎么配放主页简介了，关注自取（微笑指屏幕）。

### 视频生成技术路径
- **头像漫画化（角色卡）**：上传真人正面照 + 提示词 → 写实 Q 版/3D 皮克斯角色参考图（保留五官辨识度、微调圆润可爱、干净浅色纯背景、棚拍打光、居中半身）
- **路线 A 数字人/对口型（推荐，最省事）**：即梦「数字人/对口型」上传角色图 + 贴整段口播文案 → 一次生成连续讲话/对口型的整片（不受时长限制）
- **路线 B 图/文生视频（可控感强，6 个分镜拼接）**：豆包/即梦单次只出 5-10s 短片，把口播稿拆 6 个分镜（钩子+破题 → 亮产品 → 断症+练剑 → 截流 → 跟进 → CTA），每镜用同一张角色图 + 短提示词，分别在剪映拼接 + TTS 旁白 + 叠 UI 卡片
- **剪映叠加层**：字幕 + 「断症/练剑/截流」UI 卡片在剪映叠，别让 AI 在画面里嵌字（图生视频嵌字易出错）；导出 1080p 竖屏 9:16

## 十七、数据与隐私（对外说明口径）

讲客户资料怎么存时，只说下面这三条，别的都别延伸：

**① 只存本机**
- 插件的数据存在浏览器本地存储，运营后台是本机 `127.0.0.1` 服务，数据库文件就在本机，不上传任何云端服务器
- 只有生成内容时才调 AI，且只把生成所必需的文本发给你在「AI 配置」里自己选的服务商

**② 敏感字段加密落盘**
- AI 密钥、昵称、邮箱、会话与评论正文等敏感字段在本机加密存储
- 导出的备份 / 知识库 / AI 客服配置文件都是**口令加密文件**，换机器导入时输入同一口令还原；口令无法找回，自己要留存好

**③ 到期自动清除**
- **客户数据**（获客清单 / 私信往来 / 评论）自最后一次互动起静默满 **90 天**自动清除
- **运行数据**（灌水历史 / AI 日志 / 回复流水）满 **30 天**自动清除
- 到期即删、不可恢复（成交客户同样按此规则处理）；要长期留存的内容，及时用「备份/恢复」加密导出

> 别说成"绝对安全""永不泄露""数据永远不会丢"——这些是承诺，不是事实。
