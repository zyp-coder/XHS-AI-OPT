## 一、一句话定位与目标用户

**一句话定位：**
> 小红书全自动获客系统——断症找方向、练剑产内容、截流捞客户。AI 替你在目标笔记评论区找到真需求的人、写像真人随口聊的评论、按自然节奏发出去，把小红书流量引到你的主页简介/私信承接。不雇运营、不刷手机，一个人管多个产品。

**系统形态 = 小红书评论助手（浏览器扩展）——装在你自己的浏览器里、用你自己的号干活，数据只存本机。**（原「运营后台（Web）」自 2026-09-20 起已整体删除作废，对外一律不要再提后台/控制台/本机服务。）

**目标用户：**
- 想在小红书获客，但没时间 / 没团队 / 没运营经验的个人创业者（小程序 / App / 公众号 / 私域）
- 微商、实体店、知识付费卖家
- 代运营团队
- 一个人跑多个产品的多品类玩家

**"你只做 3 件事"：**
1. 填产品信息
2. 录知识库（产品资料 + 真实数据 + 个人经历，AI 回评时自动引用，越细越专业）
3. 设引流关键词点开始

## 二、核心运营方法论：断症→练剑→截流→跟进 闭环

系统把这套小红书获客当成一条**完整漏斗**跑。这是对外一切说辞的骨架，口播讲产品时最好按这个顺序讲。

| 环节 | 解决什么 | 靠什么落地 | 一句话 |
|------|---------|-----------|--------|
| ① 断症 | 方向错 = 白努力 | 账号诊断（抓主页+问卷定人设/卖点/知识库 → 频率建议 / 内容排产表（五条线 × 写法，按成长阶段演进）/ ⚖️ 配比条 / 📅 栏目表 / 带优先级的深度评估报告，规划与评估一次生成）+ 评论记录（获客→笔记池→页尾点开）、回复记录做复盘 | 让你不白忙 |
| ② 练剑 | 写了没人看 | 4 周日历 28 篇选题 + 素材库 + 话术库 + 操作手册 + 自营笔记冷启动 + 写文案向导（六步：卖点→人群→话题→挑稿→改稿→发稿；写稿按 📕 小红书口径；改满意了勾「这条发到哪些平台」可多选——📕 原稿 + 其余平台各自动改写一版）+ 造图片（图文＝画面表按画面号各出一条提示词、图传回素材库；视频＝口播稿 + 五种成片形式先定这一档做成什么片）+ 教程，发帖自己去发 | 让你会生产 |
| ③ 截流 | 涨粉不成交 | 一键灌水 / AI 商机发现 / 12 种评论打法随机 / 拟人化节奏 / 商机快筛 | 让你直接见钱 |
| ④ 跟进 | 流量不沉淀 | 获客清单（CRM）+ AI 人群画像 + AI 一对一私信 + 通知回访（通知页回评） | 把客户跟到底 |

**一句话点破：** 方向 → 内容 → 捞客 → 成交，四层一条漏斗，市面上工具只做其中一环，我们打通了「诊断—生产—转化—跟进」的闭环。

## 三、三大支柱的底层设计逻辑

| 支柱 | 核心问题 | 底层人性 | 设计巧思 |
|------|---------|----------|---------|
| ① 断症 | 努力错方向 = 白努力 | 人对自我带滤镜、爱自嗨 | 用数据当"客观第三方"复盘，先诊断再下药 |
| ② 练剑 | 凭灵感不稳定 | 灵感不可复制 | 把灵感降维成"流水线"，28 篇选题全现成，可批量生产 |
| ③ 截流 | 流量 ≠ 客户 | 每条评论背后想要的都不一样 | 评论目的（6）× 12 种打法随机，看菜下饭、帮客户"下决心" |

> **别家给军火（火力量变）；我们给兵法（方向、对象、时机）。** 这是区分竞品的核心表达。

- **一键灌水**（核心，自动跑量）：

  - 防重复 / 自动跳过自家号 / 上限保护（每轮最多处理篇数、每篇最多总评论、冷却时间，在「🤖 拟人化与频率 → ⚙️ 高级配置」里自己调）

- **商机快筛**（省 AI 钱）：先轻量判断哪些评论值得深挖 + 预选知识库条目，只有值得的才走完整商机分析；还能自检抓取异常
- **12 种评论打法**（核心巧思）：每条评论按它自己适合的打法写——教程 / 避坑 / 对比 / 数据 / 反驳 / 补充 / 反向共情 / 共情 / 热点 / 带赞 / 提问 / 求教，看菜下饭不分层硬套
- **话术随机引擎**：评论目的（6 选一）定整批倾向 + 每条挑最合适的打法 + 拟人微调语气，不像群发的模板。长度随打法走（10~220 字，小红书评论上限 300）

## 五、12 种评论打法与评论目的（截流核心）

**原则：** 商机 = 用户主动露出需求/痛点/纠结/求助。宁可漏过也不牵强（宁漏勿蹭），只撩真需求——评论自然不招黑、不耗 AI。

**两层决策：** 先定这批商机**整体**要什么（评论目的，六选一）；再按**每条评论本身**适合什么，从 12 种打法里挑一招。

### 评论目的（找商机时选，决定整批的倾向）

| 目的 | 想要什么 | 优先打法 |
|------|---------|---------|
| 🛍️ 卖产品（获客转化） | 能自然带产品就带，别每条都硬卖 | 教程 → 避坑 → 对比 → 数据 → 反向共情 → 反驳 → 补充 |
| 🏷️ 品牌种草（信任/口碑） | 让人记住并信任品牌，不急着成交 | 对比 → 补充 → 数据 → 反向共情 → 反驳 → 共情 |
| 👤 主页涨粉（引流主页） | 把关注和信任沉淀到主页 | 教程 → 避坑 → 数据 → 共情 → 补充 → 提问 |
| 👍 互动涨赞（提升活跃） | 这条自身能涨赞、撬动互动 | 带赞 → 提问 → 求教 → 共情 → 热点 |
| 🔥 蹭热点（借话题/大V） | 借正火的话题与流量拉曝光 | 热点 → 反驳 → 补充 → 数据 → 带赞 |
| 🧩 综合自动（看菜下饭） | 不做整体偏向 | 每条按它自己适合的来 |

### 12 种打法（每条评论挑一招，长度随打法走）

| 打法 | 带产品程度 | 什么时候用 | 字数 |
|------|-----------|-----------|------|
| 实用教程流 | 重点带 | 对方问"怎么弄"，直接口语分步教（写"先…再…"，不许写序号） | 70~200 |
| 避雷防坑流 | 可带可不带 | 以"过来人"身份讲这事最容易踩的坑 | 60~180 |
| 对比测评流 | 可带可不带 | 两个方案/做法客观放一起，列各自取舍、不拉踩 | 60~180 |
| 数据科普流 | 可带可不带 | 用硬数字/政策/案例把话题讲透，立"懂行"人设 | 70~220 |
| 钩子反驳流 | 可带可不带 | 捞出站不住的说法点破，再用亲身经历佐证 | 50~160 |
| 评价补充流 | 可带可不带 | 先认同或存疑一句，再补对方没说的数据细节 | 50~160 |
| 反向共情流 | 可带可不带 | 先接住对方的怀疑，再讲自己是怎么弄明白的 | 50~160 |
| 共情共鸣流 | 可带可不带 | 用自己的经历接住情绪，说得像自己人 | 40~140 |
| 借势热点流 | 可带可不带 | 顺着正火的话题/反转点往外延伸，借热度 | 40~140 |
| 情绪带赞流 | 不谈产品 | 短金句戳中共同情绪，纯为涨赞（允许玩梗自嘲） | 10~40 |
| 提问互动流 | 不谈产品 | 抛个有讨论度、评论区接得上的问题撬回复 | 15~60 |
| 求教自嘲流 | 不谈产品 | "我好像也踩进去了，蹲个懂的人"（纯闲聊场景用） | 30~120 |

**每条商机的产出：** 1 条话术（确有第二种极好角度才给 2 条）+ 一个打法标签（`copy_labels`，如"获客·实用教程流"）+ 一段前置分析（这条评论的情绪/诉求 + 为什么用这个打法）。给了 2 条的会再跑一次轻量调用挑出最适合发的一版。

**铁律**：开口别推销、别群发；第一句一定要贴对方原话/情景，像真人"路过搭一句"；对方回你了就手写跟，别让 AI 回第二遍。

## 六、账号人设与口吻统一规范

**我是谁：** 一个自己做号、踩过一堆坑的普通人/码农。工具是我自己先用来验证过、顺手做出来的——不装、不吹、句句有出处。

**口吻规范（AI 写话术和笔记统一用它）：**
- 用第一人称"我"，像朋友聊天，不端不装；多说自己踩过的坑和真实数字（"我之前也…""我翻了100篇才有感觉"）
- 短句、大白话、适度口语（说白了/真话/别瞎使劲），少用书面语和堆形容词
- 想卖东西别硬广——先给价值/方法，再自然带一句"我把它做成工具了"，让人好奇主动问
- 不说"亲/宝子/欢迎咨询/加V"；不把话说满，讲效果加"因人而异"

## 七、知识库体系（系统核心燃料）

**作用：** AI 生成话术时自动检索匹配、**强制引用**——必须从里面抽具体的数字/事实/案例来撑观点。产品数据用于分析型回复，个人经历用于情感型回复。知识库越细 → AI 越专业 → 每条话术都有干货支撑。

**条目结构：** 标题 + 分类 + 内容 + 标签 + 可选角色 + 可选配图。

**分类口径（3 个知识库 + 扩展录入/导入共用同一套 8 类）：**

| 分类 | 装什么 |
|------|--------|
| 产品介绍 | 产品是什么、定位、卖点 |
| 玩法与机制 | 功能怎么用、怎么跑、SOP |
| 数据·成本 | 数字、价格、政策、比例 |
| 顾客痛点 | 顾客最担心、最常问的 |
| 避坑经验 | 踩过的坑和纠正 |
| 个人经历 | 真实故事、人设素材 |
| 使用技巧 | 操作方法、路径 |
| 笔记架构 | 内容与笔记结构的搭配 |

**新增/维护知识的走法：** 有新材料先丢粗料（一段聊天记录、一条经验、一个数字都行），整理成上面的条目格式后追加进 `资料/*知识库.json`（固定文件名即源头，git 留底），再在设置页导入一次；过时条目用「停用」代替删除，留着回看。改完知识库要发客户时，重跑知识包脚本 `scripts/dev/_refresh_knowledge_pack.py`。

**配图能力：** 知识库条目可配图，AI 引用该条时图片随评论一起发（如计算器截图、疫苗表截图），可信度直接拉满。

**导入导出：** JSON 导入导出，多产品独立。`小红书AI引流工具知识库.json`（42 条）一键导入就能跑自己的行业。

**已收录的知识条目（本系统自带 42 条）：** 产品介绍 31 条、数据·成本 5 条、个人经历 5 条、笔记架构 1 条。
- 产品介绍：产品定位、三大支柱、玩法（你只做 3 件事）、一键灌水链路、商机判断标准、12 种评论打法、知识库驱动、多租户隔离、拟人化节奏、数据复盘断症、练剑 SOP、多模型切换、费用透明、账号诊断、笔记规划排序、运营体系总览、获客清单全家桶、通知回访、发笔记（笔记档案 / 写文案 / 造图片 / 出片台）、商机快筛、自动灌水怎么跑（口径 × 节奏）、拟人挡位与内容红线、多产品体系、冷启动 SOP、笔记架构矩阵、种草稿与话术、12 种打法开场白、人设口吻、产品定位与卖点总述、核心卖点速配（另有「发笔记·定时发布」1 条已停用，仅留档）

**向导 6 步 + 发稿后两条做料出口（全程点选，不填词，每步可"换一批"）：**
1. **定卖点 + 选素材**：两张表格——「全部产品卖点」＋「📚 这篇用哪些知识库素材」（AI 读产品 + 知识库，判断是工具型/情绪型/混合型，提炼可单独推广的卖点候选；素材清单逐条列出，勾这篇要引用哪几条，不选＝按选定的卖点自动挑最相关的几条）；两张表各带一列 **写过没有**（🖊 写过 N 次 / 没写过），哪条卖点、哪条素材还没被写过一眼看到
2. **选人群**：为选中的卖点推导可覆盖的目标人群，做成**列表**——一行一个，只有勾 + 粗体人群名（这一页就看粗体字是什么人）；痛点 / 场景 / 发布时机收进那一行末尾的 `？` 气泡，点开才看到
3. **挑话题**：基于人群真实痛点 + 📕 小红书生态给候选话题，做成**表格**——一列选（勾一个题）＋话题＋一句真事＋**状态**（🖊 写过 / ⚠ 撞已发 / ✅ 没重复；写过的老题排在同一张表的分隔线下面）；**这一屏不出现内容类型**（五条线是 ④ 挑稿才定的事）；**题按「抽象」出（四十六改）：每一行两栏，话题域（不带结论 / 反转 / 清单 / 产品名）+ `📌` 一句真事（这个域底下一件具体的小事，不许编）**；三道硬门槛＝①遮住产品还立得住 ②撑得起多种讲法（这题底下能不能想出三个不同的场景 / 三件不同的小事）③别把剧情写进题。含"为什么选它"、避开已发过的；**这句真事是成稿打底的凭据**——跟着进 ④ 挑稿 / ⑤ 改稿的提示词（"几篇都从它出发、但不许几篇都讲成同一场戏"），条件指纹里也有它（换掉＝这批自动重出）；排产表那条自带题面的不用它
4. **挑稿（④）**：先挑内容类型——顶部 `🔀 内容类型（五条线）· 这条讲哪一类`（故事线 / 共鸣线 / 热梗线 / 热点线 / 干货线，默认取排产表那一篇 / ③ 里 AI 判的那条线，换过标「这条换过」，可 `↺ 回默认`；五十三改起只有这一排，线底下的写法与「当前哪条线出几篇」「📐🖋」都不在这里铺）；定了线**这一页就自动发一发 AI，把这条线底下的几种写法同一个题材各写一篇**摆出来（共鸣线 / 干货线 / 故事线 5 篇、热梗线 / 热点线 4 篇，一种写法一台手机（几部并排摆着挑），屏上写明这种写法换的是哪一样；**按这条线的字数档分批出**——长档 2 篇、中档 3 篇、短档一次到底，页上有「第 N/M 批」进度）；**点中哪台手机＝这条定成「这条线 · 那种写法」，那篇正文直接当 ⑤ 的底稿**（不用让 AI 从零再写一篇），换一条线＝上一批作废、按那条线重出一批，上一批不满意或刚改过口径**只点底部导航条那颗 `🔀 重写这批`**（常驻的 `🔁 重新 AI 生成这批（N 种写法各一篇）` 与「先不挑 · 让 AI 写一篇 →」已于 2026-10-01 五十三改撤掉——**④ 唯一前进路＝点中某台样稿上的 `就用这篇 →`，这一屏没有「下一步」**）；这一页只留一行「🎚 这一条」摘要（`配比 a/b/c · 卖货话术 X · 字数 range`）+ 折起的「就改这一条」——里面只剩 **🎚 卖货话术比例**（不提产品 / 轻带一句 / 自然安利 / 主打推荐）与 **🖋 字数**（短 / 中 / 长三档）两个旋钮，📐 配比在这里只读预览，改了只影响这一条、不写账号默认；**账号默认在「发笔记 → 任务配置」那张 📄 五条线 × 写法表上定**（那里逐线逐写法给出 📐 篇幅配比与 🖋 字数，④ 挑稿就照它走）。这批的「条件」（线 / 平台 / 选题 / 卖点 / 人群 / 素材 / 热点）变了自动重烧，「比例·字数」变了只提示「🔀 按现在的重写这批」不自动烧；某种写法确实缺料（它要的来路 / 工艺 / 老规矩这类素材都没有）时那台手机（虚线空屏）标「🕳 缺料 · 补一条素材再来」（写明缺什么料 + 回 ① 补一条素材、再点底部 `🔀 重写这批` 重出）——**不给「就用这篇」、不硬编年代 / 人名 / 典故**，其余篇照常

## 十一、冷启动与发布 SOP

**冷启动真相：** 小红书新笔记有 **30-60 分钟冷启动**——平台按初期互动（点赞/评论/收藏）决定要不要继续推。发完 1 小时内别干等。

**冷启动动作：**
- 用自己号评论互动，或直接灌水自己笔记评论区引导互动
- **抢贴置顶自评**：发完 1 小时内自己抢一楼，贴一句半开放问题引导互动（别问"好不好"这种封口的）

**日常 SOP（操作手册内置）：**
```
发笔记前   照当天话术脚本把关键词配进「🎯 获客 → ⚙️ 任务配置」
发完笔记   1 小时内自己先喂一轮互动（可含自己笔记）+ 贴置顶自评
当天内     到「🔁 队列」点开始，让队列按计划把该跑的跑完（跑量上限自己设）
跑完后     看「获客 → 笔记池 → 页尾 💧 评论记录」逐条复盘，调关键词 / 打法
有人回你   一律真人手写跟进，别让 AI 回第二遍
```

**笔记排产逻辑：** 按成长阶段（冷启动 / 成长 / 成熟）与 ⚖️ 配比（五条线权重）排篇数——冷启动先让人信你是干什么的（干货线与故事线为主）、成长把常被问的做成专栏、成熟讲品类来路与品牌立场；写每一篇时按这一类（这条线 · 这种写法）的节拍走、📐 篇幅配比与 🖋 字数跟着它与账号默认走。频率建议"跳一跳够得着"（起步期跑通节奏、成长期稳定放量、成熟期提转化）。

## 十二、拟人化节奏与内容红线

**总原则一句话：** 动作全部收在平台规则内——内容不直导站外、节奏自然、量有上限；工具只做提效，账号状态以平台判定为准，不承诺结果。

**① 内容层红线**
- 评论/私信**绝不直发微信/链接/二维码**，导流一律「主页简介 / 私信我 / 置顶笔记」
- 话术走个人经历 + 真数据，一条不像复制粘贴
- 讲效果带"因人而异"

**② 行为层（拟人化节奏）**
- 9 项停留参数：浏览停留 / 逐字打字延迟 / 点赞间隔 / 评论懒加载等待 / 返回停顿 / 重开笔记等待 / 就绪缓冲 / 关注前停顿 / 批量发送间隔——**都是区间**，跑的时候在区间内随机
- 六档拟人化挡位（一键套用整套停留/间隔，越高越慢越稳）：挡位 0 极速·裸跑（不限·只建议单篇测试）→ 1 轻装·单篇/少量（≤20）→ **2 标准拟人·推荐默认（≤10）** → 3 保守拟人（≤8）→ 4 重度拟人·新号起步（≤5）→ 5 极致从容（≤3）；设置页上每档标的就是"每日建议 x 篇"
- 挡位 2 的数值＝一键「填入拟人推荐值」：浏览停留 1.2~2 秒/段、逐字输入 15~30ms/字、点赞间隔 300~600ms、条间间隔 4~8 秒
- 互动单独控制：自动关注开关 / 批量每隔几条关注一次
- 量控：日常挂挡位 2（一天 ≤10 篇封顶）；新号从挡位 4 起步；一个账号固定一台设备使用
- **别用挡位 0 狂发**（极速·裸跑只适合单篇小批量测试）

**③ 资产层**
- 主号只做内容，截流账号与主号分开，互不影响
- 关键客户第一时间引到微信沉淀

**高危动作（绝对不做）：** 直发微信 / 挡位 0 狂发 / 新号开灌 / 同设备多号。

### AI 引擎（lib/ai-client.js）
- **主备模型自动切换**：优先用主模型，遇到鉴权/额度/限流/网络/超时/服务端错误时自动切到备用模型；另有可选的多模态识图模型（点图/OCR/截图分析）单独配置
- **Prompt 管理**：场景化模板（system + user 模板）内置在 `lib/default-prompts.js`，按租户分别保存；扩展里不开放编辑页——口径跟着版本走，避免改坏默认模板
- **双注入增强**：
  - 知识库注入：从上下文（标题/评论/正文）提取关键词搜知识库，始终载入"个人经历+产品介绍"，注入 system 并要求强制引用具体数字/事实
  - 话术库注入：从上下文检测用户角色（恋爱博主/趣味测试博主/世界杯博主/普通用户），匹配同角色高活跃话术模板注入
- **模型提供商**：DeepSeek、OpenAI、通义千问（阿里云）、硅基流动 SiliconFlow、百度千帆、Gemini、Groq + 任意 OpenAI 兼容接口，Base URL + 模型自动匹配，支持"测试连接"
- 只在生成内容时才调 AI，且只把生成所必需的文本发给你在「AI 模型配置」里自己选的服务商

### 灌水引擎（扩展侧：content script + background）
- 跑位两个参数：**口径**（全部未灌过 / 只追涨势）× **节奏**（一遍跑完 / 定时轮），在「获客 → 队列」页选——**全部未灌过＋一遍跑完**＝原来的一路灌到底（灌过的跳过）；**只追涨势＋定时轮**＝原来的每隔 N 分钟跑一项、只挑点赞增长中的热门笔记

## 十七、数据与隐私（对外说明口径）

讲客户资料怎么存时，只说下面这三条，别的都别延伸：

**① 只存本机**
- 所有数据（配置、知识库、爬回来的客户/评论、灌水与回复记录）都存在你自己电脑的浏览器本地存储里，不上传任何云端服务器
- 没有任何服务端：自动化全部发生在你自己的浏览器里，外部网站既打不开也读不到你的数据
- 只有生成内容时才调 AI，且只把生成所必需的文本发给你在「AI 模型配置」里自己选的服务商

**② 敏感字段加密落盘**
- AI 密钥、昵称、邮箱、会话与评论正文等敏感字段在本机加密存储
- 导出的备份 / 知识库 / AI 客服配置文件都是**口令加密文件**，换机器导入时输入同一口令还原；口令无法找回，自己要留存好

**③ 到期自动清除**
- **客户数据**（获客清单 / 私信往来 / 评论）自最后一次互动起静默满 **90 天**自动清除
- **运行数据**（评论记录 / 回复记录 / AI 调用日志）满 **30 天**自动清除
- 到期即删、不可恢复（成交客户同样按此规则处理）；要长期留存的内容，及时用「备份/恢复」加密导出
- 自己录入的名单（目标账号、话术库、知识库）属自有内容，不自动清除，不想要了自己在页面里删

> 别说成"绝对安全""永不泄露""数据永远不会丢"——这些是承诺，不是事实。
