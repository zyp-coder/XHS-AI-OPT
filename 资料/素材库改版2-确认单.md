## 一、这轮用到的词

- **原视频**：导进来的整条视频。
- **切点**：视频上的一条竖线，两条切点之间就是一段。
- **段（素材）**：从视频里切出来、进了库的一小截，带名字、标签、一句说明。
- **剪辑视图**：新加的一屏——整条视频 + 一条时间轴，专门用来定切点。
- **集合**：一个工地 / 一次外出，装多条原视频和它们的段。

## 二、已定（老板 2026-10-22 亲答）

1. 切不动的病根：**长视频导进来，系统只切出一两个镜头**（画面变化小，没切出来）。
2. 切法：**自动分镜打底 + 手动加刀**，两个都要。
3. 走**乙方案：视频先进「剪辑视图」，切好所有段再统一入库**（更像剪映）。
4. 自动挑段保留，但**只在短视频、镜头很少时才自动建段**。
5. 段仍然**不能跨集合搬**。
6. 挑给某篇笔记的段**保持锁定**，不能改边界、不能删。
7. 案例正文两步走：**先用「每段说明」写**，等看图 Key 配好再按关键帧识别升级。
8. 老板同意配看图 Key（具体 Key 另行提供）。

## 三、新流程（乙方案）

### 1. 导入
- 「⬆ 导入原视频」支持**一次选多条**，都归到同一个集合。
- 导入后先在本机分镜。
- **短视频（≤30 秒）**：照旧自动分镜 → 自动挑 2～3 段建段 → 直接能挑。
- **长视频（>30 秒）**：只分镜，**不建段**；视频卡标「待切」，提示「点『✂ 切段』把这条切成素材」。

### 2. 剪辑视图（新）
- 上方：整条视频的播放器。
- 中间：时间轴（缩略图条）。
  - 自动分镜给的切点＝浅色小旗，作为建议。
  - 手动加的切点＝橙色实线。
- 操作：
  - 「＋ 在这里切一刀」：以当前播放位置加一个切点。
  - 点中一个切点 → 「−0.1 秒 / +0.1 秒」微调、或「🗑 删这颗切点」（删了＝相邻两段合并）。
  - 「↺ 重新自动分镜」：按更灵敏的新算法重跑一遍建议切点（手动加的切点保留）。
  - 拖动进度条时，时间轴跟着走；点某一段可跳到它的开头。
- 下方：切好的段列表，每段显示 `起–止 · 几秒`。
  - 短于 **0.8 秒**的段标红，入库时拦下（提示合并或调切点）。
- 底部：「✓ 切好了，入库（N 段）」和「取消」。

### 3. 入库
- 按切点生成 N 段，名字/标签/说明先按模板填好，可逐段改。
- 视频卡变成「已切 N 段」，段卡列在下面。

### 4. 已经切过、想重切
- **有段正被笔记用着**：不许重切，提示先把那篇撤下来或发掉。
- **都没被用**：点「✂ 重切这条」→ 先确认「这条视频现有的 N 段会删掉，段上写的名字/标签/说明也会没」→ 删掉后回剪辑视图重新切。

### 5. 分镜算法（只给素材库用）
- 不再用「绝对差超过一个固定值」判切点，改成**找画面变化的峰值 + 自适应阈值**：
  - 每 0.4～0.6 秒抽一帧比对；
  - 一个点明显比前后都跳，才记切点；
  - 阈值跟着整条视频的变化幅度走，手持走动这种「一直在动」的画面也能切出来；
  - 最短镜头 0.8 秒，一条最多 200 个切点。
- **老案例工作台的分镜不动**，只给素材库单独一套，避免影响已经能用的剪段流程。

## 四、系统碰撞（每条都要老板点头）

1. **长视频不再「点镜头直接建段」**：改成先切后入库。短视频保持点镜头/自动建段不变。
2. **导入后自动挑 3 段只对 ≤30 秒的视频**；长视频导入后停在「待切」。
3. **重切会删掉这条视频现有的段**（名字/标签/说明一起没）；有锁段时不能重切。
4. **分镜算法换新的一套，只给素材库**；老案例的分镜保持原样。
5. **导入从「一次一条」改成「一次多条」**。

## 五、案例正文（第二块，排在这轮后面）

- 第一步（本轮做）：挑完段回大组装时，**AI 按「集合背景 + 每段说明」写案例正文初稿**，进笔记草稿，可改。
- 第二步（等看图 Key）：每段自动截一张关键帧 → 识别画面内容 → 用识别结果重写说明和正文。

## 六、明确不做（防范围膨胀）

- 不做段跨集合搬。
- 不做段内部剪辑（剪掉中间一截）——只切，不剪。
- 不做视频转码／压缩（仍只收 mp4 / mov / webm）。
- 不动老案例工作台的剪段流程。
- 不接看图 Key 前不做画面识别。

## 七、验收口径（做完了怎么算过）

1. 一条 3 分钟、画面变化不大的长视频，自动分镜能切出 **≥8 个切点**（现在只出一两个）。
2. 能手动加刀、删刀、微调；删刀后两段合并。
3. 切好入库后，段数＝切点数−1；短于 0.8 秒的段被拦下。
4. 有锁段的视频重切被拦；无锁段重切先确认再删。
5. 短视频导入仍自动建段，行为不变。
6. 一次能选多条视频导入同一集合。
7. 挑段 → 大组装 → 出片这条老链路不受影响。
8. 全程没有页内报错。
