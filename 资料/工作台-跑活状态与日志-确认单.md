# 工作台：现在跑到哪 ＋ 操作日志放大（确认单）

日期：2026-10-28　｜　范围：获客 → 工作台（那一页）　｜　你的答复：第 6 条选 B、两台机器按号分开、日志保留并放大

## 一、已定（你的答复）

1. **位置**：获客二级里的「🧐 工作台」那一页，不动别的页。
2. **要什么**：① 一句话说「现在跑到哪」；② 把执行器那边的日志返回到这里；③ 日志要放大，能看清在打开哪篇笔记、做什么操作、发了什么评论。
3. **执行器那半**：走 B 档（要逐项/逐动作的进度，不只开工和收尾两句）。
4. **多号**：按号各看各的；现在只有演示号，先用演示号验。

## 二、替你按默认定的（不喜欢就说，改起来都是一两行）

| 项 | 定成 | 理由 |
|---|---|---|
| 状态行位置 | 工作台页最顶上，一根横条，最多两行 | 点进工作台第一眼就看见，不占地方 |
| 名字 | 「现在在干」 | 直白 |
| 显示细度 | 第几项 ＋ 正在跑哪个词×哪类 ＋ 最近一个动作 ＋ 几点 | 日志里本来就有这些句子，不用改执行器 |
| 「共几项」 | **先不显示** | 执行器的日志里只有「第 X 项」，没有总数；硬要显示就得让它多报一个字＝换包 |
| 出错/停手 | 红条保留，状态行再写一行「为什么停 ＋ 几点」 | 两处都能看到原因 |
| 日志面板 | 留在原地，改成默认展开、放大约 2.5 倍、显示时间＋来源标记 | 你要看的就是它 |
| 日志保留 | 服务器从最近 80 条加到最近 400 条 | 一趟活动辄几十句，80 条只够看最后几分钟 |
| 没挂执行器 / 今天没跑 | 灰字说明 ＋ 一个「去装／去开」的入口 | 别让人对着空白猜 |
| 同号两台机器 | 显示正在干活那台的名字 | 只在真出现两台时才用得上 |

## 三、方案（怎么做到）

### 1. 数据从哪来 —— 不用给客户机换包

已经确认：执行器干活时**本来就在往服务器报日志**，每 1.5 秒凑一句发一次，内容就是你要的那些：

- `▶ 第 3 项：💬 最新 × 「美白」`
- `📄 打开笔记 "标题…" (3/20)`
- `✅ 第 3 项跑完：搜到 12 篇 · 评论 5 条`
- `⏳ 第 3 项跑完。队列里的下一项将于 14:40 自动开始`
- 点赞／收藏／评论／关注 各几条、跳过哪篇（已灌过）、为什么停

这些现在**已经到服务器了**，只是网页这边把带 🤖 的句子过滤掉了、而且每 5 秒只画最新一条。所以这次主要改网页，**服务器只加一个保留条数**。

> 唯一要现场确认的：你现在装的那版执行器是不是已经在传。验法很简单——跑一项，工作台上看日志有没有冒出来；有就不用换包，没有才要更新一次。

### 2. 状态行（工作台最顶上）

```
🟢 正在跑 · 第 3 项 × 美白 × 最新 · 下一个约 14:40      [演示机 · 在线]
最近：📄 打开笔记「……」 · 14:32:07
```

五种状态：

| 状态 | 显示 |
|---|---|
| 今天还没跑 | ⚪ 今天还没开跑 · 上次：昨天 18:20（或「从没跑过」） |
| 已派下去、还没接 | 🟡 已派给执行器，等它接（已等 0:42） |
| 在跑 | 🟢 正在跑 · 第 3 项 × 词 × 类 · 最近动作＋几点 · 下一个约几点 |
| 跑完 | ✅ 这一趟跑完（14:52）· 搜到 N 篇 · 评论 M 条 |
| 停了 | 🔴 为什么停 ＋ 几点（没回话 / 要重新登录 / 安全挡位顺延） |
| 没挂执行器 | ⚪ 这台号的执行器没在线，队列跑不起来 · 去装／去开 |

### 3. 日志面板（同一页下半截）

- 默认展开，高度约页面 40%，字号放大，一行一条，不折行挤成一团（长标题自动截断，鼠标停上去看全）。
- 每条前面：`14:32:07` ＋ 来源标记（🤖 机器人自己干 / 🖐 服务器与执行器之间的喊话）。
- 有新日志自动滚到底；你往上翻着看的时候不抢。
- 右上角「⏸ 不跟着滚」和「🗑 清屏」（清屏只清显示，服务器那本账不动）。

## 四、明确不做

- 不重做工作台界面、不加新页签、不动队列页。
- 不显示「共几项」（除非以后换包时顺手加）。
- 不把日志存成可导出的报表。
- 不动发布台、素材、发笔记那些页的日志。

## 五、怎么算做完了

1. 用演示号点「队列 → 开始」，工作台顶上出现「正在跑 · 第 X 项 × 词 × 类」。
2. 日志面板自动冒句子，能看清在打开哪篇笔记、评论了几条。
3. 跑完后状态行变「✅ 这一趟跑完」并带数字。
4. 把执行器那台关掉，状态行变灰字＋去开入口。
5. 中途平台让重新登录／安全挡位顺延时，状态行写清原因，红条照旧弹。

## 六、碰撞与解法

| 碰撞 | 解法 |
|---|---|
| 网页每 5 秒只画最新一条，中间几十句全丢 | 改成按条补画，按「时间＋内容」去重 |
| 带 🤖 的日志被网页过滤掉（怕是本机杂音） | 只过滤「⏸ 不跟着滚」这类纯杂音，正经动作全留 |
| 服务器只留 80 条，活跑久了只剩尾巴 | 加到 400 条（多占不到 1MB，要重启一次才生效） |
| 日志都在服务器上了，客户机却把同一份也存在本机 | 两边各存各的，网页端只读服务器那份；本机那份不动 |
| 一趟活里同一个号有两台机器 | 只显示最近心跳那台的名字；两台的日志混在一起时在行首带名字 |
