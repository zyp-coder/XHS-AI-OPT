# 绿茶渣男鉴别器 产品简述（可直接复制到扩展设置→基本配置→产品简介）

## 一句话定位
微信小程序「绿茶渣男鉴别器」（也叫慧眼识人助手）：7套爆款情感测试题库 + AI拍照/拍手掌分析，测出身边人的真实属性，结果带全国排名，趣味性拉满，极易引发社交传播。

## 玩法说明
打开小程序 → 选一套题库（鉴渣/海王/绿茶/PUA感情/PUA职场/中央空调/世界杯球星）→ 答题7-10道 → 生成专属报告：等级称号+得分+全国百分位排名+每题解析。也可以上传照片让AI分析性格，测完还能生成表情包分享到朋友圈。全程免费、无需注册、用完即走。

## 核心功能详解

### 1. 七套情感测试题库（核心）
每套7题（世界杯10题），每题3-4个选项，选项分值0-5分，答完按总分评级，评级名称全是网络热梗：
- 鉴渣鉴定（7题）：测TA的渣属性——回消息频率、吵架处理、前任态度、公开关系、付出态度、异性边界、未来规划。评级：0-3纯爱战士（全国18%）→4-10潜力股渣（45%）→11-18渣得明显（28%）→19-35顶级渣王（9%）
- 海王鉴定（7题）：测养鱼行为——社交账号异性互动、约会频率、回复特点、关系定义、礼物付出、可疑行为解释、朋友圈认知。评级：0-3陆地生物（25%）→4-10池塘管理员（40%）→11-18职业海王（25%）→19-35海洋霸主（10%）
- 绿茶鉴定（7题）：测绿茶属性——男闺蜜、表里不一、付出态度、讨好型社交、犯错态度、社交动态、前任话题。评级：0-3纯天然无添加（30%）→4-10微糖绿茶（38%）→11-18半糖绿茶（22%）→19-35绝版龙井（10%）
- PUA鉴定·感情（7题）：测情感操控——否定打压、煤气灯话术、控制规则、打压成就、愧疚感制造、自信变化、言行不一。评级：0-3健康关系（15%）→4-10轻度操控（42%）→11-18明显PUA（30%）→19-35精神控制（13%）
- PUA鉴定·职场（7题）：测职场PUA——评价方式、任务分配、离职威胁、加班文化、发展承诺、团队氛围、心理影响。评级：0-3良心职场（12%）→4-10轻微毒性（38%）→11-18明显有毒（35%）→19-35 Toxic王（15%）
- 中央空调鉴定（7题）：测暧昧行为——异性关心度、暧昧不行动、关系描述、个人空间、表白态度、付出模式、朋友评价。评级：0-3专属空调（22%）→4-10双温空调（40%）→11-18多联机空调（28%）→19-35集中供暖站（10%）
- 世界杯球星测试（10题）：4选项情景题，测出你是14个球星中的谁（梅西/C罗/内马尔/姆巴佩/哈兰德/本泽马/博格巴/苏亚雷斯/伊涅斯塔/坎特/巴洛特利/普约尔/登贝莱/凯恩），每个球星有人设分析+梗语录

### 2. AI拍照测性格
上传正脸照 → AI分析面部特征 → 输出性格分析报告。趣味性强，适合闺蜜/情侣互相测。

### 3. AI手掌分析
上传手掌照片 → AI解读性格密码。玄学+趣味，话题度高。

### 4. 全国对比数据（社交传播利器）
每个测试结果都带正态分布曲线图，显示你在全国用户中的百分位排名——"我的鉴渣指数超过90%的人"，天然适合截图发朋友圈/小红书。

### 5. 表情包生成器
测试结果自动生成专属表情包，可自定义文案、选背景图、调文字大小位置，直接保存分享，自带裂变属性。

### 6. 双视角模式
支持「测自己」和「测别人」两种模式，把TA的选项代答，看TA是什么属性，闺蜜聚会必玩项目。
