## 二、五条默认口径（全部按默认走）

### ① 前三档客户（只做小红书）的抖音 / 视频号怎么显示

**默认：灰着写「这一档不带」，位置留着。**

- 三盏灯的位置固定成 小红书 · 抖音 · 视频号，一眼知道有这三家，升级后知道去哪看。
- 灰 ≠ 没绑：灰写"这一档不带"，不会让人以为"我是不是漏绑了"。

### ② 全平台版里，视频号没绑算不算事

**默认：灰·可选，不算欠账。**

- 小红书、抖音没绑 → **黄灯**，写"还没绑"。
- 视频号没绑 → **灰灯**，写"没绑也能只发抖音"（跟发笔记那页的说法一致：抖音＋视频号那档照选，先只发抖音）。

### ③ 还没登录的人（没有账号）

**默认：胶囊位置留一颗「🔒 登录」，跳法跟现在一样（去新手引导看档位）。**

- **演示号：不写「未绑定 / 还没绑」。** 三盏灯全灰；**三行平台一律写「演示号用不了」**；「怎么绑 · 认一下 →」不摆（演示号没有执行器，也没有号可绑）；窄窗那颗小标写「演示号」，不去数 0/1。
- 演示号真正的入口只有一个：菜单里的「开一个自己的号 →」。
- 只有"完全没登录"才出现「🔒 登录」这颗，登上了就换成胶囊。

### ④ 认号时间写在哪

**默认：顶栏三盏灯只带颜色，不写时间；时间写在点开的菜单里。**

- 菜单里每行写"今天 09:12 认的 / 昨天 21:40 认的"。
- 顶栏多写字会挤，且容易让人以为它是实时的。

### ⑤ 窄窗（默认 640 弹窗）放不下三盏灯

**默认：三盏灯缩成一个「已绑 N/M」小标（演示号时写「演示号」），点开菜单里三行照常写全。**

```
窄窗：[头像] [已绑 2/3]        ← 名字、档位、三盏灯都收起
大窗：[头像 张宇鹏 全平台版 📕🟢 🎵🟢 🎥⚪]
```

## 三、点开胶囊后是什么样

```
┌ 当前账号 ──────────────────────────┐
│ 👤 张宇鹏 全平台版·尾号8821 XHS-8821│  ← 配对号在右边，点一下复制
│                                    │
│ 平台账号                           │
│ 📕 小红书   张宇鹏 · 今天 09:12  ✅ 已登录│
│ 🎵 抖音     宇鹏穿搭 · 昨天 21:40 ✅ 已登录│
│ 🎥 视频号   —                   ⚪ 没绑（可选）│
│ 怎么绑 · 认一下 →                  │
├────────────────────────────────────┤
│ ⚙️ 执行器：在线                    │
├────────────────────────────────────┤
│ ↩ 退出 / 换账号                    │
└────────────────────────────────────┘
```

- 「怎么绑 · 认一下 →」点开的就是现在那个**账号绑定弹层**（三张平台卡 ＋ 三步 ＋ 三条常见问题），内容不重写，只是入口从顶栏挪进胶囊。
- **为了 640×420 小窗一屏放下「退出 / 换账号」，菜单压紧**：配对号并到第一行右侧、三行平台**只写结论不铺第二行小字**、执行器只写「在线 / 没连上」；万一内容再多，菜单自己能滚，不会把「退出」顶出屏幕。
- 三行平台各自只写结论：已登录 / 掉登录了 / 号不对 / 还没认过 / 还没绑 / 没绑（可选）/ 这一档不带。
- **怎么办写在弹层开头**（点「怎么绑 · 认一下 →」第一眼就看到）：
  - 掉登录 → 「在浏览器里登回原来的号，再点「认一下」就行」
  - 登错号 → 「这台电脑登的是「另一个号」· 换回原来的号再点「认一下」」
  - 还没认过 → 「点「认一下」去浏览器里看一眼」

## 四、三盏灯怎么判（写死的规则）

| 服务器回来的状态 | 灯色 | 顶栏提示 | 菜单里写 |
|---|---|---|---|
| 这一档不需要这家 | 灰 | 这一档不带 | 这一档不带 |
| 要绑、没绑 | 黄 | 还没绑 | 还没绑 ＋ 怎么绑 |
| 绑了，但浏览器里退登了 | 黄 | 掉登录了 | 浏览器里退登了 · 重新登一次 |
| 绑了，但登的是别的号 | 黄 | 号不对 | 这台电脑登的是「xxx」 |
| 绑了，上次认号对上了 | 绿 | 已登录 | 绑的号 ＋ 上次认的时间 |
| 绑了，还没认过 | 灰 | 还没认过 | 点「认一下」去看一眼 |
| **演示号** | 灰 | 演示号用不了 | 演示号不用绑号（没有执行器） |

- **灯色只看"要不要补"**：绿＝没事，黄＝要你动手，灰＝不用管。
- 判定只读服务器已经回来的那份绑定和认号结论（`server/exec-channel.mjs` 三家的都在一起返回），**不新增接口、不改执行器**。

## 六、三条要提前说清的限制

1. **不是实时。** 三盏灯反映的是"执行器上一次开窗认号时看到的"。你在浏览器里刚退登，灯不会立刻变黄——得等下一次跑活或点「认一下」。
2. **视频号可能"还没认过"。** 视频号只在发视频那趟才会被认一遍；一直没发过视频，它就是「还没认过」的灰灯，不是坏了。点「认一下」才准。
3. **档位决定几家。** 前三档只有小红书这一盏是"真灯"，另外两家一律灰着写"这一档不带"；只有全平台版三家才都算数。
