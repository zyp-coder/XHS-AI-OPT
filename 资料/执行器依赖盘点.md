# 执行器依赖盘点（2026-10-21）

对着确认单第 6A 条做的一次实测盘点：机器人跑一轮到底碰了哪些文件、哪些页面元素、哪些后台动作。
结论先说：**最小工作台不能只留一块空壳**——获客/日常浏览/整页发送都靠 popup.html 那套前台
（搜索入口、结果面板、笔记列表、日志）才跑得起来；能先砍的是"产品页"和"大脑资料"，
popup.js 里那套写稿/设置界面得整段抽，不能一刀切。

## 三、必须留、但要做"手包化"改造的

| 文件 | 改什么 |
|---|---|
| `manifest.json` | 版本升 1.3.0；加 `system.display`（窗口居中要读屏幕工作区） |
| `exec-boot.js` | 先装外壳（窗口/通行证），再装内核、再装动作外壳 |
| `exec-shell.js` | 派单开专用窗口；回执带窗口被碰次数；版本/能力上报；关窗立即收队 |
| `hand-mode.js` | 从认 `?aw=1` 改成认一次性票据；手工改网址一律挡页 |
| `work-boot.js` | 认票据；工作台整页盖"机器人干活中 · 请勿操作"；只把日志/结果留给机器人 |
| `popup.js` | 执行器里跳过新手引导门；写稿/设置页不主动加载（最小工作台抽离前先加手包判断） |
| `video.js` | 认票据（不再认 `?aw=1`）；字体下载失败把"用了系统字体"带进回执 |
| `lib/video/fonts.js` | 第一次出片从服务器下载字体，缓存到 Cache Storage；失败回退系统字体 |
| `pack.js` | 白名单打包＋脏文件/提示词特征扫描，命中即中止；发版前留快照 |

## 四、执行器里绝不能有的

- AI Key（现在就没有：AI 一律走 `/api/exec/ai`）。
- 默认提示词、写稿、排产、平台改稿规则（按上表分两步删）。
- 设置页、向导页、引导页（第一步就删）。
- 可点的产品界面：客户只能点配对/状态面板。
- 可复用的内部入口：工作台/出片页用一次性票据，`?aw=1` 手工进不去。

## 五、这轮先落什么（按老板点头后的施工顺序）

1. **干活专用窗口＋整页锁＋一次性票据**（老板 10-21 补的那条）——先落，独立自测。
2. **版本/能力握手＋服务器拒活**——手报会哪些活，服务器不硬派。
3. **打包白名单**——先拦"产品页、字体、备份件"；提示词类等第 4 段能随单下发后再纳入硬拦。
4. **出片字体按需下载**——第一次联网下载，之后走缓存；失败用系统字体并在回执说明。
5. **最小工作台抽离**（第 3 段）——把 popup.js 里机器人要的那几段抽成小手包页面，再删写稿/设置/诊断。
6. **服务器话术/规则随单下发**（第 4 段）——之后才能删默认提示词、知识检索、提示词渲染。
