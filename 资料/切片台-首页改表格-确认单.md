# 切片台首页改表格 确认单（2026-10-24）

需求来源：老板在公网页切片台提的原话——「现在的切片台的设计是偏向面板的嘛。。我想你设计成类似笔记档案那种的表格形式的。然后可以点进去每一个文件夹，点进去之后左上角，要保留一个返回按钮」。

样子稿：`tmp/切片台-表格首页-demo.html`（可点：表行 → 批次页 → 左上角「← 切片台」返回）。

---

## 一、✅ 已定（老板圈的三问）

1. **一行＝一个批次**（就是现在“进行中 / 已整理”里的那一个个批次）；点进去＝现在那一页（原片 + 已切好的段）。
2. **顶部四张数字卡收成一行小字**：进行中 N 批 · 待切 N 条原片 · 素材文件夹 N 个 · 已备好 N 段。
3. **还没定素材文件夹的批次照常列表**，文件夹那列写「还没定」。

## 二、📌 按默认定的（样子稿里看得见，不对就划掉）

1. **列**：缩略图 / 批次名（带进行中·已整理标记）/ 日期 / 原片与进度（N 条 · 共 mm:ss · 已切 x/y）/ 切出段（N 段 · M 段备好）/ 文件夹 / 状态 / 操作。
2. **排序**：进行中的在上、已整理的在下；同一组里最近导入的在最上面。
3. **怎么点进去**：点整行、或点行末「打开 / 接着切」，都进这一批；行末另有「📚 段」（有文件夹时）和「改名」。
4. **返回按钮**：批次页左上角保留「← 切片台」，位置和现在一样，只把样式跟表格统一。
5. **以前的（没分批次）**：表格下面单列一小块，仍是一行一条原片，不做进批次表。
6. **空的时候**：沿用现在那句「还没有批次 → 点右上角导入这一批」，不再摆卡片。
7. **窗口拖窄**：从右往左依次收起 日期 → 切出段 → 文件夹，批次名和「打开」始终留着。

## 三、🚫 不动

- 数据、切片、AI 切片、重切、入库、素材库、剪辑视图的代码一行不动；只换切片台首页的画法。
- 不加批次删除、不加批量操作、不改整理完的规则。
- 顶部「⬆ 导入这一批」位置和名字不变。

### 五·补：返回按钮被滚动位置顶出屏幕（2026-10-24 已修·本机）

- 老板报：「点了接着切之后没有返回的按钮」。复现：列表很长，滚下去点某一行的「接着切」，新页沿用上一屏的滚动位置（实测 `#noteBenchContent.scrollTop=515`），左上角「← 切片台」被顶到 `y=-209`，看不见但 DOM 里在。
- 修法：`npLibRender()` 收尾按「面 / 视图 / 批次 / 原片 / 集合 / 文件夹」组一个 key，key 变（列表→批次页、批次页→剪辑页）就把 `scrollTop` 归 0；同一页里的局部刷新（标签、说明、展开收起）不动滚动位置。
- 验证：滚到底点「接着切」→ 批次页 `scrollTop=0`、「← 切片台」在屏幕里；批次页滚到底点原片 → 剪辑页 `scrollTop=0`、左上角「← 第 N 批」在屏幕里。回归新增一条断言（`check_material_bench_lib_web.py`），全过。
