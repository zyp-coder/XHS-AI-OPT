# 获客：笔记类型＋评论场景表合并（确认单 · 2026-11-12）

一句话：**去哪儿找（渠道）和找到之后怎么评（笔记类型＋场景卡）做成一张表；老的「值不值得评 / 跳过」并进笔记类型，不再单独判断。每一项配置只留一个家。**

状态：确认单定稿（含 11-12「怎么评收成一处」修订），demo 已按此改完待过目；真系统等「就这么做」再动。没推公网、没重启、没动客户包/母版。

---

## 1. 层怎么分：各管一段，不重复

| 层 | 管什么 | 不管什么 |
|---|---|---|
| **渠道**（原「关键词组」，6 个） | 只干找人之前的事：**每组有哪些词、哪天跑、每天挑几个、盯哪些号、AI 按哪句抽词**；同城只作为 **Top搜 的搜索范围**（不筛/优先/全收） | 不管评不评、评论动作、提店、收不收人、具体说什么 |
| **笔记类型**（7 类） | 打开的这篇是什么帖：**评不评（评 / 不评·只收人 / 完全不碰）、评论动作、提店到哪一步、收不收人** | 不管去哪儿找、不管具体句子 |
| **场景卡** | 这条评论对谁说、怎么说：**对方是谁（吸收老「捞谁」）、往哪带（吸收老「引导」）、2~3 句说法（吸收老「开口/话术」）、不能说** | 不管评不评/动作/提店/收不收人 |
| **队列 → 设置** | 跑活节奏：间隙、条数上限 | 不管找人和怎么评 |

**为什么这么分**：同一个词搜出来的帖子什么类型都有（搜「儿童体能」能搜到求助帖，也能搜到同行招生帖），所以不能拿渠道当配置键；打开帖子先判类型，再按类型挑卡。同一个场景只写一次，勾多个类型就能复用。关键词配置页只回答「今天搜哪些词、搜几个」，不掺评论策略。

## 2. 七个笔记类型（已定）

| id | 名称 | 一眼怎么认 | 评不评 | 默认评论动作 | 提店到哪一步 | 收不收人 |
|---|---|---|---|---|---|---|
| bigv | 👑 大V帖 | 博主是头部/万粉以上，笔记本身有热度 | ✅ 评 | **评一句·只回接我话的人** | 讲案例（可说自己干这行、讲做过的案例；**不报店名、不提产品**） | 收 |
| help | 🎯 求助咨询帖 | 楼主在求助、避雷、问哪家靠谱 | ✅ 评 | 评笔记＋回评论区 | 可报店名 | 收 |
| localbiz | 📍 同城本业 | 同城、本行的笔记，人在挑在比 | ✅ 评 | 评笔记＋回评论区 | 只提身份 | 收 |
| localcross | 🧩 同城异业 | 同城、别家行业（舞蹈/游泳/轮滑…） | ✅ 评 | 评笔记＋回评论区 | 讲案例（不报店名、不提自己卖什么） | 收 |
| normal | 🔥 普通帖 | 热帖/日常/闲聊，没有明确求助 | ✅ 评 | 只评笔记 | 只提身份 | 收 |
| ad | 🚫 广告招生帖 | 同行招生、卖课、招生简章、优惠团购 | ❌ 不评·只收人（锁死） | 公开区一个字不发 | — | 收（静默） |
| sad | 🕯 悲伤纠纷帖 | 生病、事故、纠纷、投诉、维权、招聘 | ❌ 完全不碰（锁死） | — | — | 不收 |

- **可多选，标一个主类型**：一篇帖可以同时是「求助咨询帖＋同城本业」，主类型只影响排序和记录；任一所选类型命中即可用这张卡。
- **三档不是两档**：老规矩「广告招生帖不回也不收人」和「竞对评论区只蹲人」是冲突的，11-12 拆成——广告招生帖＝**不评·只收人**（不出声，只把评论区里露出真需求的人收进清单）；悲伤纠纷帖＝**完全不碰**（不回不收，只记一条日志）。两档都锁死，不能改成可评。
- **评论动作、提店、收不收人都在这张表里定**：只评笔记 / 评一句·只回接我话的人 / 评笔记＋回评论区 / 只回评论区 / 只收人；提店 不提 → 只提身份 → 讲案例 → 可报店名。渠道页不再有这几项。
- **大V 的动作要写实**：是「评一句，之后只回接了你这句的人」，不是谁都不回，也不是回整个评论区。
- **同时命中多个类型**：动作按主类型；提店**取最严的那个**（比如大V＋求助同时命中，按大V 只到案例），场景卡写得更狠也不越过。
- 线上口径照旧：不报价、不留联系方式/站外链接、不贬低同行、不承诺效果；同行/自己跳过；没设城市不提店。

## 3. 一项配置只有一个家（11-12 修订）

| 决策 | 唯一的家 |
|---|---|
| 词、哪天跑、每天几个、盯哪些号、AI 抽词策略 | 渠道 |
| 同城搜索范围（只对 Top搜 生效） | 渠道 |
| 评不评（评/不评·只收人/完全不碰）、评论动作、提店到哪一步、收不收人 | 笔记类型 |
| 对方是谁（老「捞谁」）、往哪带（老「引导」）、2~3 句说法（老「开口/话术」）、不能说 | 场景卡 |
| 看提示词（只读） | 怎么评 页头 |
| 跑活节奏（间隙、条数上限） | 队列 → 设置 |

**改法**：
- 渠道表只留「渠道 / 周几跑 / 每天挑几个 / 同城搜索 / 词 / AI 抽词」；老「找谁 / 引导 / 收不收人」三列整列删掉——找谁并进卡的「对方是谁」，引导并进卡的「往哪带」，收不收人归类型表。
- 老 12 列里的「开口 / 话术」删掉，不搬家——卡里的 2~3 句就是说法；「提示词」是只读窗口，搬到怎么评页头；「同城」不是评论设置，是 Top搜 的搜索范围，留在渠道。
- 真系统那张 12 列的配置表（队列 → ⚙️）剪成 3 列（哪组 / 周几跑 / 每天挑几个），评论相关列**整列删掉**，不搬家、不复制；节奏留在【设置】。
- 「看提示词」按新家拼：渠道段（搜的词 / 同城搜索范围）＋类型段（评不评/动作/提店/收不收人）＋场景卡段（对方是谁/往哪带/说法）＋硬规矩。

## 4. 一张表怎么摆

「获客规划」拆成两个页内横签，一屏不用滚到底：

**🧭 去哪儿找**
1. **渠道表**：6 个渠道一行一组（渠道 / 周几跑 / 每天挑几个 / 同城搜索 / 词 / AI 抽词）。周几和每天挑几个**只显示、点不了**，改在队列规划；点一行或「词 N」就在这一行下面加减词。
2. **同城搜索**：只有 Top搜 这一格能改（不筛/优先/全收）；其余组的搜索词本身就带城市，显示「词里带城市」；大V 显示「—」。
3. **AI 抽词**：每组一个「✨ 抽词」。点开＝一行初始策略（默认内置那句，可改）＋「抽一次」；抽出来的词先当候选摆在下面，点「加入」/「全部加入」才进这组。大V 不出词，没有这个钮。

**🧩 怎么评**
4. **笔记类型表**：5 列——笔记类型｜评不评·怎么评｜提店到哪一步｜收不收人｜怎么认。「为什么这么配」缩成提店格里一行灰字；评不评是三档下拉（评 / 不评·只收人 / 完全不碰），广告招生帖锁「不评·只收人」，悲伤纠纷帖锁「完全不碰」。表上方不再摆 7 个类型横签（只是筛卡、不改设置，11-12 已删）。页头一颗「🤖 让 AI 补卡」跳去复盘。
5. **评论场景卡**：一张卡勾多个适用笔记类型；卡头直接标出所勾类型。遇到表里没有的评论＝未收录，只共情或给一句判断，不硬套、不编案例。卡上不出现评论动作、提店、收不收人。
6. **看提示词**：页头一个只读入口，按渠道切换；拼出来的内容＝搜什么词＋怎么评＋说什么，改不了任何设置。
7. **试一条**（demo 里给）：贴一段笔记正文/评论 → 判类型 → 广告招生走「只收人不留言」、悲伤纠纷走「完全不碰」；其余按主类型给动作、按类型给提店和收不收人 → 给候选或「不回」。

**📥 复盘（新卡从这儿来）**

8. **新卡不手填**：撤掉「＋新增场景卡」那张要填十来个格的表单。新卡统一从复盘页的「🤖 AI 复盘」来。
9. **AI 复盘做什么**：读最近 3 天的复盘日志（发了哪句、谁接了、哪条没归上卡、原话是什么），把**同一场景至少 2 条**的评论归成一张候选卡——场景名、真实例子、对方是谁、往哪带、2~3 句说法、不能说、适用类型，全部由 AI 填好。只有 1 条的先攒着，不出卡。
10. **加入才进表**：候选卡先摆出来，点「加入场景表」才真进【怎么评】；点「忽略」就当没看见；可「全部加入」。编不出真实例子的场景不硬造，宁可不出卡。
11. **日志**：复盘页下面摆最近 3 天的关键日志（时间 / 来自哪篇 / 判成什么类型 / 用的哪张卡 / 结果 / 没归上的原话），AI 读的就是这张表。

**队列规划页**下面直接摆「⚙️ 配置表剪完的样子」：只剩 哪一组 / 周几跑 / 每天挑几个 三列；间隙和条数上限在【设置】。

## 5. 老逻辑怎么并进来

| 老东西 | 现在怎么处理 |
|---|---|
| 帖型 ask/solicit/opinion/daily/ad/sad | 并进 7 类：ask+solicit→求助咨询帖，opinion+daily→普通帖，ad→广告招生帖（不评·只收人），sad→悲伤纠纷帖（完全不碰）；同城本业/同城异业/大V帖是新增的 |
| verdict = grab / worth / none / blocked | 删掉。只剩「评 / 不评·只收人 / 完全不碰」，由笔记类型定 |
| 上层按 strategy 重跑 | 删掉。一篇笔记只判一次类型，直接按卡出候选 |
| 老「值不值得评」的 AI 判断 | 不单独跑，并在同一个判类型调用里（不多花一次 AI） |
| 渠道（玩法）里的评论动作 / 提店 / 开口 / 每组话术 | 删掉。动作、提店归类型表；开口并进场景卡的 2~3 句；渠道不再有这几项 |
| 渠道（玩法）里的「捞谁·为了什么」 | 删掉整列；并进场景卡的「对方是谁」（卡更细，避免两处说谁） |
| 渠道（玩法）里的「引导」 | 删掉整列；并进场景卡的「往哪带」；「评论里永不写店名地址」并进红线 |
| 12 列配置表里的评论相关列 | 整列删掉，不搬家、不复制 |
| 12 列里的「收进清单」 | 改叫「收不收人」，进类型表（每类一档） |
| 12 列里的「提示词」 | 不是设置，是只读窗口；搬到怎么评页头 |
| 12 列里的「同城」 | 不是评论设置，是 Top搜 的搜索范围；留在渠道 |
| 大V 帖原来看「玩法里的提店」 | 现在只看类型表的「讲案例」；渠道里没有提店可设 |

## 6. 默认值

- 7 类：5 个可评、1 个「不评·只收人」（广告招生）、1 个「完全不碰」（悲伤纠纷）；后两档锁死，不可改「评」。
- 评论动作默认：大V＝评一句·只回接我话的人；普通帖＝只评笔记；求助咨询 / 同城本业 / 同城异业＝评笔记＋回评论区（可在表里改）。
- 收不收人默认：5 个可评类型都「收」；广告招生帖「收（静默）」；悲伤纠纷帖「不收」。
- 提店默认照第 2 节那张表；只在这张类型表里改，别处不重复设。
- 新卡由 AI 复盘出候选，适用类型由 AI 按评论来源填（默认给「求助咨询帖＋普通帖」），加入后还能改。
- 抽词：内置策略打底；自己写过就用自己那句；抽出来的词不自动进组，要点「加入」。
- 同一场景卡可以被多篇帖复用；7 天账本、同批同角度最多 2 条、开头 6 字/连续 8 字查重，全部照旧。

## 7. 明确不做（这轮）

- 不改客户装的那份包、母版；不推公网、不重启。
- 不做「一个类型一张表」；不做自动改卡。
- 工作台 / 设置界面不动；复盘只加「AI 复盘」这一块，收过的笔记、最近 3 天评论照旧。
- 不把评论动作/提店搬回渠道或配置表；不做「两处都留着，先同步着」。
- 不做跨号去重；不做「AI 自己把卡写进表」——AI 只出候选，加入必须人点。
