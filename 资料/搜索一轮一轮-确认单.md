# 搜索一轮一轮（2026-10-23 老板圈定）

## 要解决的事

老板在自己的 Edge 上点了一次「搜索」（词：瓷砖怎么选），机器人把「最新 / TOP / 本地 / 求助」连着全跑了，一口气刷了很多次搜索、收了一堆笔记。这不是他要的：

> 「应该是一轮一轮跑的，而不是一次一次搜索你就跑所有……先跑最新，跑完最新再跑后面的……要一个个的来。」

根子一句话：`extension/lib/auto-water.js` 的 `searchNotes()` 把「这个词到点的所有类」拼成一张清单，`_doSearchNotes()` 一口气从头跑到尾，中间只歇 0.9 秒。

## 这轮用到的词

- **一类**：配置表里的「最新 / TOP / 本地 / 求助 / 竞对」中的一列。
- **一轮**：就是一类。TOP 的 3 种排序（点赞 / 评论 / 收藏）、求助的 4 个词（求推荐 / 听劝 / 怎么办 / 求建议）算同一轮里的几搜，连着一口气跑完。
- **后面几类**：这个词还剩没跑的类型。服务器记住这一串，到点自己往下派。

## ✅ 已定（老板 2026-10-23：「按推荐来」，另答 4 条）

1. **点一次「搜索」＝只跑当前词的「最新」一类**，这一单里绝不捎带别的类。
2. **最新跑完，自动接着跑这个词剩下的类**：一次一类，约 10 分钟一类；不用人再点。老板原话：「接着用就好了」指干活窗。
3. **一类＝一轮**：TOP 的 3 搜、求助的 4 搜在各自己那一轮里连着跑完；跑完这一轮才歇，跑下一类。
4. **只认词标签上的这一个词**：当前词所有类都没到点 → 提示去「任务配置」改，不偷偷顺延到别的词。
5. **最新关着 / 没到点**：就跑第一个到点的类，并在面板/日志说一声「最新这一轮没到点，先跑 TOP」。
6. **队列页「开始」和后台自动跑默认「定时轮」**：一项（词 × 类）一项地跑，仍可手选「一遍跑完」。
7. **类型标签手点不变**：点某一类的标签，还是立刻只跑这一类，不排队。
8. **停手条件（登录过期 / 账号安全 / 搜索没跑起来）**：立刻停手，后面几类先不跑；网页顶上弹醒目提示，写清原因和怎么接着来。老板原话：「肯定要停手啊，并且要在服务端弹提示告诉用户啊」。
9. **干活窗**：一串活从头到尾复用同一扇窗；每一轮跑完把页面交回来，下一轮再锁上；全跑完停在最后一页，不关窗。
10. **工作台列表顶上那一行**（老板原话「要」）：
    ```
    这一轮：最新 · 收 12 篇 · 今天共 48 篇
    后面还有：TOP · 本地 · 求助（约 10 分钟一类）
    ```
    只剩最后一类时不写下面那行；跑完这串活也不写。

## 📌 替你按默认定的

- **间隔约 10 分钟**：最新当场跑；后面每类跑完歇约 10 分钟再跑下一类（服务器一分钟看一次表，实际 10～11 分钟）。这一版不给搜索链加旋钮，要调再说。
- **队列「定时轮」的间隔默认 2 分钟 → 10 分钟**：没自己调过这个数的人按 10 分钟；自己调过的保持原值。「获客 → 设置 → 高级配置」里仍可改。
- **再点搜索时**：这个词后面还有类在排队 → 先撤掉旧的那串，按这次点的重新起一轮，不叠两条；点队列页「开始」也先撤旧的。
- **电脑不在线 / 别的人在干活**：等着，等它空下来再派；超过 24 小时没上线，这串活作废并弹提示，回来再点搜索。
- **到了静默期（21:00–09:00）还没轮到**：按停手处理，弹橙条，明早再点；不会半夜偷偷跑。
- **普通「收 0 篇」不算失败**：继续下一类；页面打不开 / 一篇都没拿到，才算「没跑起来」，停手弹提示。
- **提示条样式**：登录过期沿用红条；其它停手用橙条；都点「知道了」收起。手动「停这一趟」不弹横幅，日志留一行。
- **「今天共 M 篇」**＝今天收进获客池的笔记总数（去重，含别的词和截流扫描收的），不是这一串活自己数的。
- **干活窗被你自己关了**：下一轮会再开一扇；没关就接着用同一扇（沿用刚做的「收尾不关窗」）。
- **队列一条单的等待上限**：定时轮会在项与项之间歇，原来 15 分钟的上限放宽到 2 小时；超长队列没跑完的记欠账，下一次开始接着跑。

## 🚫 明确不做

- 不把 TOP 的 3 搜、求助的 4 搜拆成一轮一轮——一类就是一轮。
- 不改类型标签手点的入口和口径。
- 不改别的词自己的节奏；不改发笔记 / 出片 / 截流扫描 / 日常浏览的跑法。
- 不做自动重试、不偷偷替人接着跑；停了就等人回来点。
- 不补跑已经停掉的轮次；下次搜索先跑最新（它每轮都跑），然后按到点情况接着跑上次没跑成的类。
- 不加「搜索链间隔」的设置项；队列的「扫描间隔」仍保留。
- 这轮不动 `executor/exec-core.js`（红线），不整份盖 `web/popup.js`。
- 这轮先只在本地改、本地验；推公网、重启服务器、重打执行器包各等一句正文，不夹带。

## 实现落点

| 文件 | 动什么 |
| --- | --- |
| `extension/lib/auto-water.js`（主本，随后 `node sync-executor.js` 搬进 `executor/lib/`） | `searchNotes()` 把到点清单按「类」切开：这一轮只把第一类放进 `searchState.plan` 去跑；本轮类名、后面还剩哪几类、今天共多少篇，一并交回给外壳。`_doSearchNotes()` 的逐搜循环不动（拿到的已经是这一类的几搜） |
| `executor/exec-shell.js` | `runSearch()` 只跑一轮；开工前过账号安全的几道闸（静默/单休/起床/额度）；回执 `detail` 里带 `round`（类名）/`remain`（后面几类）/`dayTotal`（今天共 M）；页面打不开且 0 篇 → 报失败带原因；`runAcquire()` 的等待上限按节奏放宽（定时轮 2 小时，一遍跑完仍 15 分钟） |
| `extension/lib/note-trend.js`＋`executor/lib/note-trend.js`＋`web/lib/note-trend.js` | 「定时轮」间隔默认 2 → 10 分钟（只改默认值，不动已存过的配置） |
| `extension/auto-bot.js`＋`executor/auto-bot.js`（同步） | 队列节奏没传时默认「定时轮」 |
| `web/auto-water-app.js` | 「搜索」带上当前词（`kw`），不再让后台顺延；结果列表顶行写「这一轮：X · 收 N 篇 · 今天共 M 篇」，下面灰字写后面几类/下一类约几分钟后 |
| `web/exec-bridge.js` | 队列页「开始」默认 pace `interval`；接服务器那串活的进度：每完成一轮把结果挂给工作台刷新；停手横幅（红条登录过期 / 橙条其它原因）；不弹手动停 |
| `web/popup.html`＋`web/lib/scenario-drain.js` | 队列页节奏下拉默认选中「定时轮」 |
| `server/exec-channel.mjs` | 回执时记下「这个词后面还有哪几类」这串活（`store.exec_chains`）；`/api/exec/orders` 带出这串活的状态/下一类时间/停手原因；停这一趟、解绑、踢下线、新的搜索/队列开始时把这串活作废 |
| `server/exec-sched.mjs` | 每 60 秒看一次：到点派下一类（带 `scenario` + `force`，执行器只跑这一类）；静默/熔断/失败/断线超 24h → 停手留原因，不再派；旧账清掉 |

## 验收条

### 本机自检（不碰平台或只碰静态页）

- [ ] 桩测试：给一个词的到点清单（最新 + TOP 3 搜 + 本地 + 求助 4 搜），`searchNotes` 只把「最新」那一搜交给逐搜循环；回执里 `remain` 是 TOP / 本地 / 求助。
- [ ] 桩测试：服务器收到回执 → 记下后面三类 → 到点派下一类 → 再回执 → 再派；全跑完后不再派。
- [ ] 桩测试：中途登录过期 / 账号安全 / 搜索失败 → 不再派下一类，网页读到停手原因；手动停 → 不弹横幅。
- [ ] 桩测试：新的搜索或队列开始 → 旧的那串被撤掉，不叠两条。
- [ ] 真浏览器（Edge，静态页）：点一次搜索只发生 1 次搜索导航；结果顶行文案正确；干活窗跑完不关。
- [ ] 真浏览器（Edge，静态页）：把服务器间隔临时调短，看第二类自动接上、用同一扇窗、页面跑完交回。
- [ ] 队列页：默认「定时轮」，一项跑完歇约 10 分钟再跑下一项；手选「一遍跑完」仍能连跑；类型标签手点仍只跑一类。

### 老板真机（你自己的 Edge、真小红书号）

- [ ] 点一次「搜索」：只看到「最新」这一搜在跑；跑完列表顶上出现「这一轮：最新 · 收 N 篇 · 今天共 M 篇」。
- [ ] 约 10 分钟后 TOP 自己接上（3 搜）；再约 10 分钟本地；再约 10 分钟求助（4 搜）；每一轮结果都刷到工作台，窗是同一扇。
- [ ] 中途扫码 / 账号安全挡下：当下停手，网页顶上红条/橙条写清原因；后面几类不跑。扫码后重新点搜索：最新照常先跑，后面接着上次没跑成的类。
- [ ] 手点「停这一趟」：停手、不弹横幅、日志一行；后面不再派。
- [ ] 全跑完：窗停在最后一页不关；「这一轮」那行写最后一类，不再写后面还有。

## 生效要做什么（先把口径定死，动静另等点头）

- 本机：改完先跑桩测试＋静态页真浏览器测试；执行器在 Edge 扩展页「重新加载」即吃到。
