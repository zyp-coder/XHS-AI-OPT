# 长文成站 + 各线补预览 · 确认单（2026-10-19 冻结）

一句话：长文从「改稿页底下那一小块」升成独立一站；每条线收口前统一补一站「👀 预览」，且这一站与档案里那颗预览用的是同一个界面。

## ✅ 已定

1. **长文独立成站**（知识线、引流线两条都改）：挑知识／📄 出几版 → 改稿 → **📝 出长文** → **👀 预览** → ✓ 收好回档案。改稿页底下那块长文面板撤掉，改稿页不再管长文。
2. **出长文那站进去不自动开写**：一屏里一颗大字「✨ 出长文」，点了才写（老板答"不用了"＝不要自动写）。
3. **预览＝宽屏**，不做手机那么宽的竖框。
4. **预览不拦**：出长文那站底栏保留一颗「✓ 存好，回档案」，可以跳过预览直接收；正常往下走会经过预览站。
5. **口播稿线补预览**：原来改完稿直接「✓ 完成，回档案」，改成进 👀 预览（正文＋提词卡，能复制）再收。
6. **导图线补预览**：出完导图长图进 👀 预览（左边长图、右边正文）再收。
7. **走图那条线不另加站**：现有的「👀 预览」那一站升级成总览——上面那一排合成卡图照旧，底下补上正文，主钮「✓ 存好回档案」。一站两用。
8. **门面笔记**（主页顶上那两篇）也收进同一个预览界面。
9. **案例流、成片那条本轮不动**（档案里已有「🎬 成片预览」，算有了）。
10. **抬头按线分家**：知识线长文＝科普口吻（现有那句）；引流线长文＝人设腔、带钩子。抬头文案与 AI 的说话规矩各改两处（你电脑这份 + 公网那台）。
11. **引流长文结尾带承接句**，只走「主页简介 / 私信我」这种合规说法。
12. **档案行「📝 改出长文」这颗铺出来**（代码早有、按钮一直没画）：已定稿但没出过长文的篇，点了直接进新的出长文站。
13. **档案「✏️ 编辑」回落点跟着改**：长文已出的篇，点它落**出长文站**；要回改稿点步骤条上一格。
14. **本轮只落两处**：你电脑这份的主本 + 公网那台。自测用的那份、资料侧随下一条线一起扫。
15. **上云只推本轮动到的那一小块**：本机这份文件里夹着"口播工单"那条未推的改动（另一个会话在做），不一起带上。

## 📌 替你按默认定的

- **空态**：料没齐也让你进预览站，显示已有的那部分＋一行"还缺什么"，不拦。（第 7 问没答，按推荐）
- **不新增档位/权限**：长文与预览都走现有「发笔记」那把开关。
- **站号安排由实现错开**：不改动走图那条线现有「分镜确认 / 预览」两站的含义与编号。

## 🚫 明确不做

- 案例流、成片线的预览改造
- 手机端竖屏预览
- 把预览做成硬关卡（非点不可）
- 长文进站自动开写
- 新档位、新权限闸门
- 自测那份与资料侧的同步清扫

## 实现落点

- 你电脑这份主本：`web\popup.js`（站点表、改稿页底栏、新的出长文站、预览站、档案行两颗钮）、`web\lib\platforms.js`（长文抬头按线分家＋承接句）
- 公网那台：`server\bg\popup.js`（如公网有对应件）、`server\bg\lib\platforms.js`（同源同步）——只推本轮动到的块，不整件覆盖
- demo：`tmp\长文成站与预览-demo.html`（本确认单的镜像，过了才写码）
