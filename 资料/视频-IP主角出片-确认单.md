# 视频线「用 IP 主角出片」确认单（2026-11-01）

> 一句话：视频那条（口播稿 → 分镜出词 → 复制去豆包 → 传回来拼片）现在只有分镜 AI「知道」有这个人；
> 这一单把它变成**你看得见、改得了、复制出去一定带人**的一条：出镜人一条、每段带【谁出场】、按段能加配角、定妆照一起下载。

## 一、这一单只补四样

### 1）分镜页顶上多一条「这条片出镜」
- 位置：⑤ 分镜出词页，音色那一行上面（跟图文 ⑤ 顶上「🎭 这篇用」同一手感）。
- 内容：`🎭 这条片出镜：` 下拉选人（IP 角色池，默认整篇主角）＋视觉锤小胶囊（卷尺 / 老花镜…）＋定妆照状态。
- 换人＝整片换人，下面每段的【谁出场】当场重写；「🔁 再排一次」也按新的人排。
- 没建 IP 角色时：这一条照样显示，写「还没建 IP 角色——先按稿子写，建了再回来换」，不挡出片。

### 2）每一段提示词开头都带【谁出场】
- 由系统逐段写死，不靠 AI 自觉（跟图文 10-31 那次同一个道理：组头说了，每段就得有）。
- 写法（整片一个人）：
  `【谁出场】老王，装修工长，38 岁，短发，偏瘦，穿深蓝工装；固定不变：卷尺、老花镜——整片同一个人，从开场到收尾同一张脸、同一身衣服，动作变、人不变。`
- 位置：贴在每段提示词最前面，后面才是 AI 写的「竖屏 9:16 实拍短片……」。
- 老片：打开就按整篇主角补上这一行；手改过的提示词别乱动别的内容，只补/换这一行。

### 3）按段加配角（不点＝整片主角）
- 每条「生成条」上加一颗小按钮 `＋ 加人`，点开列出 IP 角色，可多选。
- 选中的人写进**这一段**的【谁出场】，写明主次：
  `主角老王（…）；配角小林（…）——老王在画面中间动手，小林在旁递尺子，两个人不是同一个人，大小主次分得清。`
- 只影响这一段；别的段还是整片主角。跟图文「按张点人」一个逻辑，但视频默认整片一个人。

### 4）定妆照一起发（双保险）
- 选人那条上多一颗 `⬇ 下载定妆照`：把这个人的定妆照（最多 3 张）下到本机。
- 用途：豆包生成时把这张当参考图传上去（脸、发型、衣服以它为准）；提示词里的外形也照旧带着，两样一起才稳。
- 没定妆照：按钮置灰，旁边写「这个角色还没定妆照——去「账号规划 → 🎭 IP 角色」出一张」。

## 二、不改的

- 分镜条、时间轴、15 秒切条、音色、⬆ 传回来、拼片、字幕——全不动。
- 不新增菜单、不新增向导步骤：就长在现有 ⑤ 分镜出词页上。
- 不支持 AI 直接出视频（贵），仍然是复制提示词去豆包生成、片段传回来拼片。
- 不碰执行器、不碰客户机行为。

## 三、老片兼容

- 老篇的 `dgen` 里没有「出镜人 / 每段点人」这两格：一律读整篇主角，提示词打开时补【谁出场】，别的内容一字不动。
- 手改过的提示词：只补/替换行首那一行【谁出场】，不覆盖你改的画面描述。
- 没建 IP 角色的号：行为跟现在一样，不报错、不挡路。

## 五、怎么验（改完我自己先跑）

1. 静态自检 + 运行时自检全过。
2. 演示号选一篇视频篇：顶上能看到「这条片出镜：××」；每段提示词开头有【谁出场】。
3. 换一个人：每段那行跟着换；「🔁 再排一次」出来的分镜也按新人写。
4. 某段加一个配角：只有那一段多出配角、写明主次；别的段不变。
5. 老篇打开：那一行补上，AI 原来写的画面描述没被改。
6. 复制第 1 条 → 贴到记事本，开头就是【谁出场】；「⬇ 下载定妆照」能下到本机。

## 六、边界（提前说清）

- 定妆照下载多张时是**逐张**下（浏览器不能一次打包成 zip，不引额外库）；最多 3 张。
- 视频模型认不认这张脸，取决于豆包那边；我们的活是「人写清楚、图给到位、说明怎么用」，不承诺每条都长一样。
- 每段提示词会变长一点点（多一行外形），豆包对话框有长度上限的话按现在的量还够用；真遇到截断再单独减。
