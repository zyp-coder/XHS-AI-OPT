# 玩法排班改成「一张大表格」· 确认单

- 日期：2026-11-03
- 状态：**已推公网**（2026-11-03 11:53 上传，静态立刻生效、没重启；自检 92 项、无头界面 46 项全过）
- 一句话：「🎯 玩法排班」改成一张六列表格——**玩法 / 周几跑 / 话术（提店口径并进话术）/ 每天挑几个 / 词 / 今天**，一行一个玩法，不再一项一项分开设置。

## 一、老板原话（需求）

> 获客队列里面的玩法排列，能不能做成一个大表格？我不想你分开一个一个去设置，就是一个表格，一行就是一个玩法。然后前面可以有几周跑，都可以选。后面话术说明就直接跟在后面就好了，提店口径其实就是话术，也放到里面去，就不要提店口径这一列了。每天挑几个放最后面，跟有多少个词放一起，视觉感官也比较统一，还带一个今天跑的意思，也不用过分去做这个。

> （第二轮）今天跑应该单独一列；每天挑几个词、一共多少个词也分开，每个都分开列就好。

## 二、定稿长什么样

```
┌──────────┬──────────────────────┬────────────────────────────────┬──────────┬──────────────┬──────────┐
│ 玩法      │ 周几跑（点一下切换）    │ 话术（什么算商机/怎么评论/提不提店名）│ 每天挑几个 │ 词            │ 今天      │
├──────────┼──────────────────────┼────────────────────────────────┼──────────┼──────────────┼──────────┤
│ 👑 大V    │ 一 二 三 四 五 六 日   │ 大V评论区里接话的本地家长，就是商机…  [改]│ —        │ 不出词        │ 今天跑    │
│          │ 不出词 · 盯 3 个号     │                                │          │              │          │
├──────────┼──────────────────────┼────────────────────────────────┼──────────┼──────────────┼──────────┤
│ 🔝 TOP   │ 一 二 三 四 五 六 日   │ 评论区里家长问方法、问有没有用…      [改]│ 每天 [3] 个│ 8 个词 ▸      │ 今天跑    │
└──────────┴──────────────────────┴────────────────────────────────┴──────────┴──────────────┴──────────┘
```

点「改」→ **在这一行下面展开一整行**（跨满 6 列）：文本框 +「评论里提店：不提 / 只提身份 / 可报店名」+「让 AI 改」+ [恢复默认][保存][收起]。收起后表格恢复原高度。

## 三、逐列口径

| 列 | 内容 |
|---|---|
| 玩法 | 图标＋名字；大V 那行下面小字「不出词 · 盯 N 个号」 |
| 周几跑 | 一~日 七个按钮，点一下切换；今天那个加黄框；没排任何一天＝这行灰着 |
| 话术 | 这个玩法存的那段话（默认短话已铺好）；行末「改」→ 就地展开 |
| 每天挑几个 | 数字框＋「个」；大V 这格写「—」 |
| 词 | 「X 个词 ▸」（停用的补「· Y 停用」），点了跳到下面词池那行；大V 写「不出词」；同城本业有竞对号时下面补一行「盯 N 个竞对号」 |
| 今天 | 徽标：`今天跑`（绿）/ `今天不跑`（灰）/ `这周不跑`（橙） |

**提店口径**不再单列：三档收进「改」展开块，点一下直接存、不关编辑器，正在改的草稿不丢。
