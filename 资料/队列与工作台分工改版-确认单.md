## 🗄 「服务器存一份今日队列」怎么落（碰撞 1B）

**存在哪**：公网那台本来就按租户存着 `drain_queue`（现在存的是 正在跑 / 欠账 / 手插 / 已完成）。不新开表，往里加一块：

```
todayPlan: {
  day: '2026-10-29',        // 跨天自动作废
  at: 1761700000000,        // 什么时候算的
  items: [                  // 顺序就是今天要跑的顺序
    { k:'瓷砖怎么选', scenario:'top', plat:'xhs', at:'' },   // at＝计划到点（没有就空）
    …
  ]
}
```

**谁写、什么时候写**：
1. 打开队列页 / 工作台、或改完配置 → 算一遍，整份写进 `todayPlan`；
2. 点「开始」前再写一次（保证开跑的就是这份）；
3. 跑的过程中只更新 `drain_queue` 原来的 `running` / `done` / `kwRuns`，**不往 todayPlan 里写状态**——避免两处各记一份、对不上。

**谁读**：工作台优先读 `todayPlan` 定顺序；`day` 不是今天或没有这份 → 现算一份顺手补上。

**开跑后就冻住**（2026-10-29 补）：点「开始」那一刻的清单＝今天这一份。跑的过程中改配置只影响明天，不挪今天的顺序；队列条上标一句「配置改过了：今天这趟照原样跑，明天按新的排（N 项）」。清单里的 ⤴ / ✕ 只动今天这一份，不回写配置。

**已知限制**（接受）：
- 浏览器全关着的时候没有定时器，todayPlan 不会自己刷新；下次打开会立刻重算。
- 执行器实际跑到哪，仍以它回传的 `running` / `done` 为准；todayPlan 只负责"今天该跑哪些、什么顺序"，颜色对不上时以执行器为准。
- 换平台（抖音）各存各的：`items` 里带 `plat`，工作台按页签过滤。

## 验收口径

1. 队列页从上到下只有：配置表（含列头节奏、行末周几下拉）＋ 投放平台（两个标签）＋ 🗣 获客话术（未配时＝人设＋「还没配」＋配置按钮；配好后＝四步摘要＋示范评论）＋ 盯的账号/日常浏览两颗入口；**没有任何"正在跑/待跑"字样，没有开始按钮**。
2. 表头改一次节奏 → 整列生效；行内点勾 → 这个词这一类开/关；改周几 → 下面"今天跑 N 项"当场变；找词加入的新词自动落在最空的一天。
3. 一个词一个周几（可多天，下拉选）；不再出现"批次"两个字（除迁移提示外）。
4. 工作台顶上是队列条：默认收成一行「今天 6 个词 · 14 项 · 正在跑第 3 个「瓷砖怎么选」· 已完成 2 个词」；点开展成清单①。
5. 清单①一行一个关键词：类型小标 + 状态四种颜色（正在跑 / 待跑 / 计划（几点到点）/ 已完成）+ 进度第 x/y 项 + 战果；⤴ 能拎到最前、✕ 直接从今天清单撤掉这个词的项（不回写配置）。
6. 开始 / 暂停 / 这次跑N条 / 口径 / 节奏 全在队列条上，点了立刻影响执行器。
7. 清单②「这个词的笔记」：标题旁写「第 x/y 篇」，下面接原记录表五列，再下面是收起的操作日志。
8. 五个空/异常态：今天没配置 / 这些词今天不排 / 没装执行器 / 执行器掉线 / 今天跑完了，文案都对得上。
9. 开跑后改配置：今天的队列不挪，队列条标「配置改过了：今天这趟照原样跑，明天按新的排」；明天才按新配置。
10. 话术未配时卡面写「还没配」，卡上没有现成句子；弹窗第一屏是人设（读自账号设置），点「按这个人设生成一版」后才出四步＋示范；示范里能看出城市 / 身份 / 口吻，换人设重配才会变。
