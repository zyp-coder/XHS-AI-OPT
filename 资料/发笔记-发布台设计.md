## 〇、这一页干什么（一句话）

**发布台一页管到底：排＋发**——页内两签：**📅 发布队列**（排期列表里每位子定好「几点发」，到点自己把这发去小红书＋抖音（**视频篇还发视频号**，三家同发）；发前 AI 按每家口径各改一版（重点拿掉规避词），发完回档案标「已发」、存各家发布链接，回执落在页底「📜 最近发过」）＋ **🧬 笔记规划**（怎么用发笔记＋每周排法＋阶段计划，原在「任务配置」整块搬来）。**篇写好标「代发」那一刻自动找最早的未来同类空位排进去**（没空位 / 没定方向就先待在页顶「🆕 写好等排期」，点「🎯 排进空位」再排）。人只在缺东西（没定稿 / 缺料 / 没登录）时被叫来补。

## 一、老板圈定的 9 条（2026-10-09）

| # | 问题 | 老板定 |
|---|---|---|

## 二、AI 适配改稿（发布前必走）

- 到点后、发出去前，**AI 对每家各出一份适配稿**：标题 / 正文 / 话题按这家平台口径改——重点规避词（绝对化说法、结果承诺、站外引流词），不改意思。口径：小红书按笔记口径、抖音按短视频口径、**视频号按微信生态口径**（不出现别家平台名，承接走主页/私信；只给视频篇出这版）。
- 篇子**齐了（定稿 + 有料）后可以先预跑一遍摆着看**（demo ?v=45 就是「今天 19:00 发、适配稿已出」的状态）；改了稿或换了目标平台会重出。
- 改完**本地再扫一遍词表**：还有雷就不发、列表里标红（宁可不发，别带雷发出去）。
- 改稿跑不成（没 key / 断网）→ 不硬发，标红等重试。
- 适配稿**长期可见**：队列行里 / 档案点「👁 适配稿」看各家版本对照（视频篇三版、图文篇两版），**改过的地方标出来**（发出去的就是这一版）。
- 词源：`lib/platforms.js` 的 COMPLIANCE 红线（note / short 各一套，**实现时加一套 channels**）× 系统内置违禁词小结（实现时落一张可维护的小表）。

## 三、文件代发区

- 图文 ≤4 张 / 视频 1 条（沿用档案「图4视频2」口径）；队列行里「📁 交文件」。
- 收的是**副本**（原件留在你自己电脑）——文件挪窝/改名不影响发；发布完成**自动清掉**，不长期占地方、不进加密备份。
- 出片台出的片（排了队列那篇）自动进代发区，不用再指。
- 缺料 → 不发、标红「缺料 图 N/4」。

## 四、页面结构（demo ?v=47 二十八改展示）

「📅 发布台」一页（原发布队列 ＋ 原发布台 ＋ 原任务配置「🧬 笔记规划」签）：

- 页头：标题 + ? 说明 + 授权章（`📕 小红书 · 🎵 抖音 · 🎥 视频号`，哪家没登录会提示到点跳过）。**二十八改：页头不再挂 `🗓 改每周排法` 按钮**——每周排法就在页内「🧬 笔记规划」签里。
- **页内两签**：`📅 发布队列` / `🧬 笔记规划`（运行期变量 `_nqTab`，默认 `queue`）。
- **📅 发布队列签**：
  - 页顶「🆕 写好等排期」区（二十八改）：标了「代发」还没进位子的篇一行一条（篇名 ＋ 方向标 ＋ `🎯 排进空位`）——自动排位子没排上（没空位 / 没定方向）的兜底落点；空则不显示。
  - 顶条：`今天要发 N 篇 · 卡住 K 篇 · 最近发过 M 篇`。
  - **三周排期列表**（从今天往后滚，一行一篇；空位一条细行 `＋ 排一篇`）：日期格（`今天 / 明天 / 第 N 周 · 周几` ｜ `月日 · 基调`）| 篇名（点开去档案）| 平台章（**视频篇 📕🎵🎥、图文篇 📕🎵**；点亮=发这家，点暗=先不发）| 状态章 | 救援钮 | 🕐 时间 | ▶ | ✕。
    - 状态章：`到点自动发`（绿）/ `到点等你过目`（蓝）/ `还没定稿`（红）/ `缺料 图 N/4`（红）/ `✅ 已发`（绿）。
    - 救援钮按状态出：`✍ 去定稿`（草稿）/ `📁 交文件`（缺料）/ `👁 适配稿`（有适配稿时）+ `✋ 过目`（开关，开着蓝底）。
    - 🕐 点开＝行内时间条（快捷 08:00/12:00/19:00/21:00 + 自定 + 清掉）；▶＝不等了现在就发；✕＝从这个位子拿下来。
  - **页底「📜 最近发过」**：时间 · 篇名 · 各家成没成（视频篇三格、图文篇两格；含「补发成功」）· 🔗 打开链接；没上成的有 `🔁 重试`；视频号登录过期没发上的标 `🎥 没登录` + `去扫码`（扫完码点一下即补发）。
- **🧬 笔记规划签**（二十八改从「任务配置」整块搬来）：怎么用发笔记 ＋ 每周排法 ＋ 阶段计划 ＋ AI 规划，整块渲染（`_diagPersonaTableHtml()`，切到该签时 `diagStyleRestore()` 恢复样式）。

## 五、时间与兜底

- 到点浏览器开着才能发；当天补发标「补发」，过当天标「错过」。
- **视频号登录会过期**（微信扫码）——到点没登录：跳过视频号、另两家照发，视频号留「没登录 · 去扫码」，扫完就补；不影响别家。
- 到点时刻前后小随机（±10 分钟内），不整点机器感；全程拟人节奏，不猛点连发。
- 首次使用：授权创作者平台三个域名（视频号＝`channels.weixin.qq.com`）+ 查登录态；没登录标红提醒。
- 同一篇发送中锁住；失败不标已发，「📜 最近发过」里「🔁 重试」。

## 六、数据落点（拟，实现时按此对齐）

- 发布时间：队列键旁挂一张 `np_queue_times`（键＝`w周:day:基调|篇id` → `'HH:MM'`）。
- **自动排位子（二十八改已落地）**：`npAutoPlaceNote`（popup.js）——篇标「代发」那一刻，按方向码查 `NP_DIR_KIND`（k→知识 / d→引流 / c→案例）找最早的**未来**同类空位（位子时刻＝日期 ts ＋ `np_queue_times[key]||'12:00'`，`> now`）；幂等（已在队列任何位子＝不动）；没空位 / 没方向 → toast 提示 + 落「🆕 写好等排期」区，点「🎯 排进空位」再排。五个触发点：保存档案 / 导图出图 / 成片组装 / 案例入档 / 档案状态改「代发」。
- 发布结果：`np_notes` 每篇加 `pub` 字段：`{ targets:['xhs','douyin','channels'], watch:bool, staged:{...}, xhs:{url,at}, douyin:{url,at}, channels:{url,at}, adapted:{xhs:{title,body,tags,at}, douyin:{...}, channels:{...}} }`（`targets` 按篇形式算：视频篇三家、图文篇两家；字段名实现时可微调，语义不变）。
- 代发区原件：扩展现有素材仓（IndexedDB），**不进** `storage.local`、不进加密备份；发布完成即清。

## 七、第一版不做（边界）

- 平台侧的位置 / 合集 / @ / 定时发布 / 多账号——不碰。
- **视频号只收视频**：图文篇不上视频号（要上得先出成视频）；视频号不做「找回放过期内容」之类特殊能力。
- 快手 / 闲鱼不做自动发；对外物料「自己去发」口径先不动（回头单说）。
- 归「发笔记」档（③）功能面，不另开卖点。
