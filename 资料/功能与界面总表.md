### 2.12 手机看板（加购项 · 另装一套，不在三档里）

**一句话**：电脑照常跑，手机上扫个码，随时看「队列还剩几格 · 正在跑第几项 · 今天刷了几篇 · ⏰ 自动跑还正常吗」。**只读**——手机页上一个能点的按钮都没有，发不了任何指令。

| 位置 | 控件 | 点下去发生什么 |
|---|---|---|
| 桥扩展弹窗 | 状态三行（中转 / 主扩展 / 最近上报） | 中转通不通 · 主扩展找到没 · 上次上报成不成 |
| 桥扩展弹窗 | `生成配对二维码`（出过码后变 `重新生成`） | 出 8 位配对码 + 二维码；**码 10 分钟有效、手机一认领即作废**；已配过的手机不作废 |
| 桥扩展弹窗 | 电脑名 / 中转地址 / 主扩展 ID（兜底） + `保存` | 电脑名显示在手机页顶部；中转地址默认本机版，上线填云地址（**换非本机地址时会弹一次浏览器授权确认**，点了拒绝就只提示不保存）；ID 只在「主扩展」那行是红的时手填（32 位 a–p） |
| 桥扩展弹窗 | `立即上报一次` / `解绑这台手机` | 不等下一分钟马上推一份 / 手机立刻失效并清掉配对 |
| 手机页 | 状态卡 | 电脑在线/离线（快照 24 小时没推＝离线）· 电脑名 · 主包版本 · 最近上报时间 |
| 手机页 | 队列卡 | 待跑 / 还没到点 / 今天完成 / 正在跑哪一项 + 这一项进度（第几篇 · 已发几条） |
| 手机页 | 日常与自动跑卡 | 今日刷 N 篇（各方向 used/配额）· 评论/回复/关注；⏰ 自动跑实况（正在跑 / 被停按住 / 连续没跑起来 / 等时段） |
| （口径） | — | 手机端只带**运行状态**：不含获客清单、私信/消息、客户昵称、笔记标题、AI Key、知识库、话术库、评论原文 |

**跑起来四步**（本机自测口径）：
1. 起中转：`node relay/local/server.mjs` —— 手机连同一个 Wi-Fi，开它打印出来的地址
2. 浏览器加载两个扩展：主包 `extension/` + 手机桥 `bridge/`
3. 桥弹窗 `生成配对二维码` → 手机扫码（或手输 8 位码）认领
4. 之后每分钟自动上报一次；电脑关机或扩展停了，手机上显示离线

**上线（云端 · Cloudflare Workers，2026-09-26 定）**：中转与手机页都由一个 Worker 托管（`relay/worker/`，和本机版共用 `relay/core.mjs`），电脑只出网、不开端口。
1. `npm i -g wrangler` → `wrangler login`（浏览器里登 Cloudflare 账号）
2. `wrangler kv namespace create RELAY_KV` → 把打出来的 id 填进 `relay/worker/wrangler.toml`
3. 在 `relay/worker/` 下 `wrangler deploy` → 得到 `https://<name>.<账号>.workers.dev`
4. 把这个 https 地址填进桥弹窗「中转地址」→ `保存`（会自动要一次该网址的访问权）→ 重新出码配对；手机页就是同一个域名加 `/#p=码`

- **国内可达**：`*.workers.dev` 在大陆常被 DNS 污染，手机可能打不开。要稳就在 Cloudflare 绑一个自己的域名（`wrangler.toml` 里有注释掉的 `[[routes]]` 段，填上域名再 deploy）。
- **免费额度**：KV 免费版按「一天 1000 次写」算。桥那边已按最小必要频率推（内容在变最快 100 秒一次、没变 5 分钟一次心跳，见 `bridge/background.js` 的两个常量），最坏一天 ~900 次；手机页 12 分钟没动静才显示离线。要改频率先算这笔账。

**隔离口径**：加购项——不装它，客户机一切照旧、升级不受影响；主包改动只有 externally_connectable 白名单一句，权限、存储、代码都不掺和。
