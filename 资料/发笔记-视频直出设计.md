## 〇、这一块干什么（一句话）

引流视频稿改完，**原地**进「🎬 拆段出词」：AI 先标出稿子里的重点、按重点个数拆成 3~5 段，**每段配好一段能直接贴进豆包的提示词**——一段段复制去生成小片存到本机，回来打勾；全勾了就「🎬 拼片配音」：片段按稿子顺序接起来、字幕＋配音（音色可选，默认晓晓），标「代发」自动排位子。全程不离开写稿向导，**不再先出关键画面图**。

## 二、新流程（已落地；demo ?v=50 三十一改同口径）

写稿向导（引流视频线）步条变为：**挑稿 → 改稿 → 🎬 拆段出词 → 拼片配音 → 发布**。

### 第 3 步 · 🎬 拆段出词

- **进页即拆好**（不需点按钮、无破坏性）：AI **先标重点**（哪几句是要讲的，落 `points:[{t,why}]`，表上方一排小 chip 摆出来）→ 按重点个数定段数 → 拆段、每段配一段提示词；已有段且 `src` 与当前稿一致的就**接着用**（不重拆）；稿子改过（`src` 对不上）＝自动重拆（免得摆一版对不上稿子的旧段）。
- **段落表（3 列）**：

  | 段 | 这一段讲什么（稿子原话） | 给豆包的提示词 · 复制 · 打勾 |
  |---|---|---|
  | 段号 ＋ 角色（开场钩子 / 转折到你这行 / 收束引主页，料多时加「把料讲完 / 讲透专业那句」）＋ 状态章（⏳待生成 / ✓生成好了） | 稿子原话，**只读**；下面一行小字：这一段生好短片后，配音就用这段话（当前选的音色念） | 自动拼好的整句提示词（**可改**）＋ 📋 复制提示词 ＋ ✅ 这段生成好了（再点一次＝↺ 还没弄完） |

- **🎙 配音声音**（终裁新增，表上方一排）：5 个中文音色 chips——晓晓 / 晓伊 / 云希 / 云扬 / 云健（标「推荐」的晓晓是默认；点选即记 `dgen.voice`）＋「🎧 试听」（用所选音色念第一段原话——听感对不对比描述管用；Edge 才出声，非 Edge 弹一句人话）。

- **提示词口径**（demo 模板，真实扩展 AI 现拆现配词）：`竖屏 9:16 实拍短片，时长 5 秒左右。画面：{按段角色的场景句}。镜头：{运镜}。不要出现人脸口型；画面里不要出现任何文字。`
- **拆段数**（终裁口径）：**绝不按字数均分**——AI 先标重点 → 数重点 → 1 个→3 段 / 2~3 个→4 段 / 4+→5 段；角色表按段数配（3 段＝开场钩子·转折到你这行·收束引主页；4 段中间插「把料讲完」；5 段再加「讲透专业那句」），AI 漏给角色由段序兜底补全；引流稿里那句「转法句」（`drainPick.turn`）拆段时当硬约束传给 AI（那句所在段必须落「转折到你这行」）。
- 底部：`← 回 ② 改稿`（段留着，回来接得上）/ 进度行（`还差 N 段没生成（x/N）` → 全勾变 `✓ N 段都生成好了`）/ `🎬 拼片配音，标成「代发」`（**全勾才解锁**，没全勾灰着带原因）。

### 拼片 → 落档（标「代发」）

- 全勾后点「🎬 拼片配音，标成「代发」」：落 `filmDocs`（kind＝`文案直出视频`、`gen:true`、key＝档案 id）＋ `filmKind` 镜像 ＋ 字效编辑器那份账 `xhsFilmDocs[档案id]`（scenes＝各段文本、voice＝所选音色）＋ **配音 mp3 下到本机**（所选音色把整篇稿子念一遍，`配音-{音色名}-{标题}.mp3`，剪映里直接当旁白轨；非 Edge/网络失败不拦拼片）＋ 回写 `out`（`已出：文案直出视频（N 段拼片＋{音色名}配音）`）＋ 状态「代发」＋ 自动排位子 ＋ 回档案。
- 拼片口径（对老板的说法）：片段**按稿子顺序接起来**，字幕＋**所选配音**，这些都是自动的。

### 入口改写（独立画片台去掉）

- 写稿改完稿出口（视频线）：按钮「🎬 备好画面和提示词，标成「代发」」→ **「🎬 拆段出词 →」**，原地进第 3 站（不再跳独立画片台）。
- 档案「下一步」状态机（`npArNext`，引流视频线三态）：`🎬 拆段出词（还差 N 段）`（没拆或还有段没打勾） → `🎬 拼片配音`（段全勾但还没拼）→ `📖 发布教程`（已出片）；点都直落写稿流第 3 站。
- 「画片台」独立视图（`v-dgen`）整块下线；教程（`note-guide.js` DV）六步＝拆段出词（重点→3~5 段→提示词）→ 一段段复制进豆包 → 打勾 → 选音色拼片（mp3 下本机＋标「代发」）→ 剪映拼（片段按序接＋拖入配音＋字幕）→ 发布。
- 六卡（新建笔记）里这张卡：`🎬 图生视频` → **`🎬 文案直出视频`**（「稿子直接拆成几段，每段配好一段提示词——复制贴进豆包生成片段，回来拼成片。」）。

## 三、数据落点（已按此落地）

- 档内 `w.dgen = { segs: [{role, text, prompt, done}], points: [{t, why}], voice, src, updatedAt }`（**旧 `clips` 形状作废**；老档没有 `segs` 就当空、下次进页重拆）。`segs[].role`＝段角色名、`text`＝稿子原话、`prompt`＝给豆包的提示词（可改）、`done`＝打勾；`points`＝AI 标的重点（chip 展示，段数照它拆）；`voice`＝完整音色名（如 `zh-CN-YunxiNeural`，空＝默认晓晓）；`src`＝拆段时那份稿子快照（与当前稿不一致＝自动重拆）。
- 落档走 `npArchiveData` 打包 / `npArchiveCoerce` 清洗 / `npArchiveSave` 粘性（脏数据防丢）；拆段即刻落档——档案那行当场认「还差 N 段」。
- 拼片 → `w.filmDocs = [{id, kind:'文案直出视频', key:档案id, gen:true, updatedAt}]` ＋ `w.filmKind='文案直出视频'` ＋ `w.path='video'` ＋ `xhsFilmDocs[档案id] = {title, script, scenes: segs.map(s=>({text, t:0})), voice, outAt, updatedAt}`（字效编辑器那份账，档案那行据此标「🎬 已出片」）。
- AI 契约（background.js `genNoteDvSegs`）：输入平台/标题/稿子/转法句；输出 `{"重点":[{"句","为什么"}],"段":[{"角色","原文","提示词"}]}`；角色表按段数配（3/4/5 段型），漏给由段序兜底；提示词缺约束补「不要出现人脸口型；画面里不要出现任何文字。」、空提示词补通用词＋按角色运镜。

### 新口径（demo ?v=65 已展示）

- ③ 站名：**拆段出词 → 🎬 分镜出词**（其余站点名不动）。
- **进页即排好**：AI 先按旁白把全片排成 3~5 个分镜（沿用 §二 角色表：开场钩子 / 把料讲完 / 转折到你这行 / 讲透专业那句 / 收束引主页，边界对在句子缝上），每个分镜带 t0–t1 时间与时长；**总长≈稿子字数 ÷ 语速（4.6 字/秒）**——按晓晓念完估。
- **照 15 秒切条**：整条 ≤15 秒原样 1 条；超过的按句缝拆成 `ceil(时长/15)` 条（尽量均分、每刀落在句子缝上，每条 ≤15 秒）；切完再把 ≤5 秒的小条并进相邻条（合起来 ≤15 秒，优先并前一条）。
- **分镜条**（表上方，一格一个分镜、宽度按时长排）：落点标注「＝第 N 条 / 拆 M 条 → 第 a–b 条 / 并进第 N 条」；页头一句说清这一版怎么切的（如「第 2、4、5 个分镜超 15 秒，各拆开；第 3 个分镜只有几秒，并进旁边那条一起拍」）。
- **生成条表（3 列）**：

  | 生成条 | 这一段讲什么（旁白原话） | 给豆包的提示词 · 复制 · 传回来 |
  |---|---|---|
  | 第 N 条 ＋ 角色（· 前半段/后半段）＋ a–b 秒 · 约 X 秒 ＋ ⏳待生成 / ✓传回来了 | 该条对上的旁白原文（下面一行小字：『这条对上 a–b 秒这段旁白——整篇稿子晓晓一次念完』＋有并入时『第 X 个分镜并进来一起拍』） | 提示词带「时长约 X 秒」；拆出来的条带「（这条只拍这个分镜的前半段…／这条接着上一条的画面…）」，可改 ＋ 📋 复制提示词 ＋ ⬆ 传回来（＋demo 演示 ✨） |

- 页脚：`还差 N 条没传回来（x/N）…` → 全传回 `✓ N 条都传回来了——拼片配音（旁白念完的为准：镜头按旁白裁齐＋字幕＋晓晓配音）`；拼片走完 `已出：文案直出视频（N 条拼片＋晓晓配音）`；档案行「🎬 成片预览」、预览 mark「🎬 分了 N 条」。
