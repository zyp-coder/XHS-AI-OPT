# AI雕兄 · 运营体系文案稿（海报「怎么破」用）

> 用途：商业海报「怎么破」板块的文案。先审文字，过关后再排到海报上。

## 一、断症 —— 不是拍脑袋，用 6 个维度给你账号“照一遍”

1. **定位诊断**：你到底“卖什么、卖给谁”？定位清不清、够不够垂直、人设立没立起来。
2. **人群诊断**：内容在服务谁？是写给目标客户，还是写给了同行/自己爽。
3. **频率诊断**：多久一篇、什么时段发，合不合理，能不能“跳一跳够得着”。
4. **选题诊断**：选题踩不踩目标人群的痛点，有没有一条主线。
5. **内容硬伤诊断**：标题有没有钩子、封面点不点得进、开头留不留得住人。
6. **历史归因**：把你发过的笔记翻一遍，哪篇爆了、哪篇沉了，规律是什么，直接抄对的。

**诊断完，直接给你 4 样，照着做就行：**
- **人设方向**：你到底是谁、立哪种人设、为什么——人设先立起来。
- **笔记结构（最关键）**：**不同账号给不同的结构**——起步期要吸睛、成熟期要转化，按你的阶段和人群单单独搭，绝不套流水线模板。走“破冰立人设 → 点痛示警 → 实证建信任 → 教方法 → 展示产品 → 收割转化”，先说什么、后说什么，一步排清。
- **选题清单**：引流探饵 / 信任干货 / 转化成交三类，每一条都能直接当标题。
- **发布节奏**：一周几篇、什么时段发。

一句话：断症不是给你说“挺好”，是给你一套“你这个号该怎么做”的完整方案。

## 二、练剑 —— 内容不靠灵感，靠一套可复制的生产流程

1. **选题怎么选**：从“卖点 × 人群 × 场景”里去挖，配选题库，挑这一篇最该打的点，不贪多、不泛泛。
2. **结构怎么搭**：8 节点工作流——内容赛道 → 选题 → 标题 A/B/C → 正文 7 段 → 标签 → 配图 → 发布节奏 → 成稿。你只点选，AI 出候选。
3. **文案怎么来**：从你的产品知识库（真实数据、功能点、个人经历）里组装，具体有信息量，不是通用 AI 的空喊。
4. **配图怎么生成**：自动选图生成、自动填标题/正文/标签，一键成稿。
5. **发布怎么管**：到点提醒你发哪一篇，节奏不乱，不用盯。

## 三、截流 —— 只捞“主动露出需求”的人，捞一个成一个

1. **商机怎么挖**：扫评论区，只挑“主动露出需求”的（求助 / 疑问 / 被坑），宁缺毋滥，不硬蹭。
2. **心理怎么认**：先识别每个人的买前心理——问价 / 犹豫 / 被坑 / 观望 / 货比三家…共 12 类。
3. **话术怎么给**：按心理匹配最对味的话术，文案来自知识库，不像广告。
4. **防封怎么控**：人话铺 + 随机 + 拟人节奏，一条条像真人一对一。
5. **成交怎么通**：高意向自动进获客清单，AI 画像分级，定向私信，人工确认才发，一路跟到成交。

## 四、复盘 —— 数据留痕，让闭环越跑越准

- 今天发了多少、本周多少、累计多少，AI 一条条记账。
- 每一条记录：哪篇笔记、回了谁、用了什么话术，随时回看、一键复制。
- 看板 + 日志 + 获客清单，成本透明、去向清楚。
- 客户反馈又喂回断症，下一轮选题和话术越调越准。

## 五、一句话串起来：它是一套“闭合”体系，不是几个散功能

- 断症的方向 → 决定练剑往哪打；
- 练剑产的内容 → 就是截流的机会池（评论区里才有商机）；
- 截流捞到的客户反馈 → 又喂回断症复盘，调整下一轮选题和话术；
- 你只做一件事：**看复盘、定方向、确认成交**。剩下的苦活累活，AI 雕兄全包。
