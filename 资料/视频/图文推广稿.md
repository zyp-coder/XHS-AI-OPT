## 屏2 · 核心能力 自动获客：队列「口径 × 节奏」

**卖点（文案）——本屏两大杀手锏**：

> **🧭 全部未灌过**：看到笔记就灌。适合快速起量——AI 逐篇打开、扫评论、发话术，灌过的自动跳过。
>
> **🔥 只追涨势**：不是盲目群发！**连续点赞采样记录每篇笔记的点赞变化**，只挑**"正在增长 / 快速增长"**的热门笔记下手——蹭的是正在火的流量，评论区活跃、转化更高。**绝不浪费在点赞还躺着不动的笔记上**。
>
> 节奏再单独选一档：**一遍跑完**＝从队首连跑到队尾，想冲量用这个；**定时轮**＝每隔 N 分钟跑一项，把量摊开到一天。
>
> 想冲量就「全部未灌过 + 一遍跑完」，想精准蹭热度就「只追涨势 + 定时轮」——两个参数自由组合。跑量上限（每轮几篇、每篇几条、冷却几小时）在「设置 → 一键灌水」自己填，你是运营总监不是发帖机器。

**截图指引**：
- **操作A**：大窗 → 🎯 获客 → 🔁 队列，顶栏「口径 × 节奏」两个下拉展开
- **命名**：`02_队列_口径节奏`
- **捕捉重点**：队列页顶栏两个下拉的选项（全部未灌过 / 只追涨势；一遍跑完 / 定时轮）+ 额度概览

- **操作B（进阶）**：点「🤖 开始」，看队列里「▶ 正在跑」的实时进度
- **命名**：`02b_队列_运行中`

## 屏3 · 核心能力 AI 挖商机：知识库驱动 + 12 种评论打法

**卖点（文案）——本屏两大杀手锏**：

> **📚 知识库驱动，越用越像真人**：把你的产品资料、真实数据、个人经历录进知识库，AI 生成话术时**强制引用真实内容**——具体数字、功能点、操作步骤。话术有温度、有依据，**不像广告，像老朋友的经验之谈**。
>
> **🎯 先定评论目的，再挑打法**：这批商机整体想要什么，六选一——卖产品 / 品牌种草 / 主页涨粉 / 互动涨赞 / 蹭热点 / 综合自动。
>
> **🧭 12 种打法，看菜下饭**：实用教程 / 避雷防坑 / 对比测评 / 数据科普 / 钩子反驳 / 评价补充 / 反向共情 / 共情共鸣 / 借势热点 / 情绪带赞 / 提问互动 / 求教自嘲。
> 问教程的就给他步骤，怕踩坑的先讲坑位，在纠结的帮他对比，纯玩梗的接个梗——同一批里不同评论换不同招，刷一圈根本看不出是批量。
>
> 每条话术卡上标着用的是哪一招（如「获客·实用教程流」），另附一段前置分析说明为什么这么回。

**截图指引**：
- **操作**：大窗 → 🎯 获客 → 工作台，扫完当前笔记显示商机卡
- **命名**：`03_挖商机_话术卡`
- **捕捉重点**：商机条数统计 + 话术卡上的**打法标签** + 一段前置分析 + 话术正文
