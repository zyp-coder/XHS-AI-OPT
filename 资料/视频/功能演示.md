## 屏1 · 它是干什么的：一条龙帮你获客

**卖点文案**：
> AI雕兄 是一款装在浏览器里的小红书获客插件。你只需把产品资料录进「知识库」、登录自己的小红书账号，它就在你这个账号里替你干活：先诊断想清楚发什么 → 找到想要你产品的客户 → 替你在评论区发像真人一样的回复 → 用私信把围观的路人变成咨询的客户。
> - 🔍 找客户：自动搜关键词相关笔记，扫评论区，挑出"主动表现出需求"的人
> - 💬 发评论：AI 按你的产品资料生成像真人一样的回复，自动发送，自然不招黑
> - 📩 私信成交：高意向客户进「获客清单」，AI 帮你写私信、持续跟进，直到成交
> - 🧰 也能发笔记：向导写笔记（卖点→人群→话题→挑稿→改稿→发稿），改稿改到满意、一键复制；要图给画面表、要视频给口播稿

- 推荐文件名：`01_笔记评论区.png`
- 捕捉重点：打开任意笔记，重要评论自动高亮

## 屏2 · 自动获客：队列「口径 × 节奏」一键开跑

**卖点文案**：
> **🔥 队列：口径 × 节奏**。关键词、笔记类型、盯的账号都排进队列，点一下「开始」，它按计划一项项跑完。
> - **口径**：全部未灌过（看到就灌，灌过的自动跳过）/ 只追涨势（只挑点赞增长中的热门笔记，蹭正在火的流量）
> - **节奏**：一遍跑完（一次把队列跑到底）/ 定时轮（每隔 N 分钟跑一项，不占用你盯屏的时间）
> - **跑量上限自己设**：每轮最多处理几篇、每篇最多总评论、冷却几小时
> - 跑完自动记账，每篇标 ✅成功 / ⚠️无商机跳过 / ❌失败，正在跑哪一项实时可见

## 屏3 · AI 挖商机：知识库驱动 + 12 种评论打法

**卖点文案**：
> **📚 知识库驱动**：把你的产品资料、真实数据、个人经历录进知识库，AI 生成话术时**强制引用真实内容**——具体数字、功能点、操作步骤，不像广告。
>
> **🎯 先定目的，再挑打法**：这批商机整体想要什么，六选一——卖产品 / 品牌种草 / 主页涨粉 / 互动涨赞 / 蹭热点 / 综合自动。
>
> **🧭 12 种打法，看菜下饭**：实用教程 / 避雷防坑 / 对比测评 / 数据科普 / 钩子反驳 / 评价补充 / 反向共情 / 共情共鸣 / 借势热点 / 情绪带赞 / 提问互动 / 求教自嘲。问问题的就教他，纠结的先共情，玩梗的就接梗——同一批里不同评论换不同招。
>
> **🎲 每条都带标签和理由**：话术卡上标着它用的是哪一招（如"获客·实用教程流"），另附一段前置分析说明为什么这么回，条条像真人一对一，不刷屏、防厌倦。

**截图占位**：
- 推荐文件名：`03_挖商机_话术卡.png`
- 捕捉重点：商机条数统计 + 话术卡上的打法标签 + 前置分析

## 屏4 · 账号诊断：先想清楚该发什么（断症核心）

**卖点文案**：
> 做号最怕方向错=白努力。「账号诊断」七步走完（基础设置 / 说话风格 / 问卷 / 人设 / 产品卖点 / 知识库 / 规划），
> 答完一次问卷就自动同步，⑦ 规划直接给你一套能照做的内容计划：
> - 📚 内容规划：账号类型、讲什么内容、主要人群、建议页数与每页作用（先说什么后说什么一步排清）
> - 📅 发布节奏：一周几篇、一天里几点发，跳一跳够得着的频率
> - 🎯 选题池：一条条能直接当标题的选题
> - 📋 深度评估报告：定位 / 内容方向 / 更新节奏先看哪个、哪里最该改

- 推荐文件名：`08_账号诊断.png`
- 捕捉重点：⑦ 规划 · 内容规划结果 + 深度评估报告

## 屏5 · 发笔记：从卖点一路走到出图文 / 出视频

**卖点文案**：
> 发笔记不是等灵感，是往下走：卖点什么、讲给谁听、聊什么话题、落成稿子、出图文还是出视频。
> - 🧭 全程点选：卖点 → 人群 → 话题 → 挑稿 → 改稿 → 发稿，全程点选不填词，每层可「换一批」，发过的话题不重复
> - ✍️ 一整套成稿：3 个候选标题（强钩/悬念/干货）+ 正文 + 5-8 个标签 + 建议发布时段
> - 🤖 成稿先停一下：不满意就手改，或写一句要求让 AI 改一版（换标题、改标签都行，改坏了能改回上一版），定稿再往下走
> - 📋 落地到发布：复制发布文案（标题+正文+标签），粘到小红书就能发
> - 🖼 要图给提示词：出「封面 + 配图」两段出图提示词，拿去千问 / 即梦等 AI 出图工具出图
> - 🎬 要视频出口播稿：同一篇成稿写成口播稿，带进「出片台」（弹窗左栏「发笔记 → 🎬 出片台」，点「拿去出片」就地切过去）本机配成竖版视频（不装剪辑软件）
