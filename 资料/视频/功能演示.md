## 屏1 · 它是干什么的：一条龙帮你获客

**卖点文案**：
> AI雕兄 是一款装在浏览器里的小红书获客插件。你只需把产品资料录进「知识库」、登录自己的小红书账号，它就在你这个账号里替你干活：先诊断想清楚发什么 → 找到想要你产品的客户 → 替你在评论区发像真人一样的回复 → 用私信把围观的路人变成咨询的客户。
> - 🔍 找客户：自动搜关键词相关笔记，扫评论区，挑出"主动表现出需求"的人
> - 💬 发评论：AI 按你的产品资料生成像真人一样的回复，自动发送，自然不招黑
> - 📩 私信成交：高意向客户进「获客清单」，AI 帮你写私信、持续跟进，直到成交
> - 🧰 也能发笔记：先由「账号诊断」出笔记规划，AI 帮你写文案、自动配图，一键发布或定时提醒

**截图占位**：
- 推荐文件名：`01_笔记评论区.png`
- 捕捉重点：打开任意笔记，重要评论自动高亮

## 屏2 · 智能推广：冷启动 + 循环计划

**卖点文案**：
> **🧊 冷启动**：看到笔记就灌。搜索关键词，AI 逐篇打开、扫评论、发话术，已灌过的自动跳过，日发 20 篇轻松跑量。
>
> **🔄 循环计划**：每 N 分钟自动扫描一轮，连续点赞采样记录每篇笔记点赞变化，只挑"正在增长/快速增长"的热门笔记下手——蹭正在火的流量。
>
> 两种策略 = 想冲量用冷启动，想精准蹭热度用循环计划。

## 屏3 · AI 挖商机：知识库驱动 + 12 类心理话术

**卖点文案**：
> **📚 知识库驱动**：把你的产品资料、真实数据、个人经历录进知识库，AI 生成话术时**强制引用真实内容**——具体数字、功能点、操作步骤，不像广告。
>
> **🎯 12 类买前心理画像**：问价 / 冲动 / 求测评 / 被坑 / 求助 / 好辩 / 拖延 / 观望 / 高价值 / 货比三家 / 想学 / 沉默。
>
> **🧠 对心坎下刀**：不同心理状态下用不同话术切入，直击 TA 此刻最容易被说动的那一点，远比群发一套有效。
>
> **🎲 随机发射**：心理匹配后再随机换语气，条条像真人一对一，看不出是批量，防封防厌。

**截图占位**：
- 推荐文件名：`03_挖商机_话术卡.png`
- 捕捉重点：商机条数统计 + 按 12 类心理画像匹配的话术卡

## 屏4 · 账号诊断：先想清楚该发什么（断症核心）

**卖点文案**：
> 做号最怕方向错=白努力。「账号诊断」读你近期的笔记表现 + 你的产品资料，一次给你三件事：
> - 🩺 发笔记频率建议：一周几篇、什么时段发、为什么，跳到跳一跳够得着的节奏
> - 🎯 选题清单：引流探饵 / 信任干货 / 转化成交三类，每一条都能直接当标题
> - 🗂 笔记规划（先后有序）：破冰立人设 → 点痛示警 → 实证建信任 → 教方法 → 展示产品 → 收割转化，先说什么后说什么一步排清

**截图占位**：
- 推荐文件名：`08_账号诊断.png`
- 捕捉重点：账号诊断结果页（频率建议 + 选题清单 + 笔记规划）

## 屏5 · 发笔记：按账号诊断的规划发

**卖点文案**：
> 账号诊断先给你一份笔记规划，这里就按规划发笔记。
> - 🗂 按规划选选题：照账号诊断出的笔记规划挑这一篇该发的，方向不偏
> - ✍️ AI 生成文案：选知识库素材 + 引导话题，自动成文，可复制或直接发布
> - ⏰ 定时提醒：设定提醒时间，到点通知你该发布哪一篇，保持更新节奏不用盯
> - 🖼 自动配图填表：标题 / 正文 / 标签 / 配图全自动填好，一键确认发布
