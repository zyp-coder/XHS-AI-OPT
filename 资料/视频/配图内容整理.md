## 二、断症（配图②·上半）

**版块主标题：** 🩺 断症
**副标题：** 先用一个六维雷达，把你的账号“照一遍”
**内容说明：** 不是拍脑袋给建议，是把你这号「该怎么做」先摸清楚，再动手，方向对了每篇才不白写。

**六大维度（雷达图，每轴一个）：**

| 轴 | 主标题 | 内容说明 |
|---|---|---|
| ① | 定位 | 你这号到底是“卖什么、给谁”，清不清、够不够垂直、人设立没立起来。 |
| ② | 人群 | 你内容在服务谁？是写给目标客户，还是写给了同行、写给了自己爽。 |
| ③ | 频率 | 多久一篇、什么时段发，合不合理，能不能“跳一跳够得着”。 |
| ④ | 选题 | 选题踩不踩目标人群的痛点、有没有一条主线。 |
| ⑤ | 内容硬伤 | 标题有没有钩子、封面点不点得进、开头留不留得住人。 |
| ⑥ | 历史归因 | 把你发过的笔记翻一遍，哪篇爆、哪篇沉，规律是什么，直接抄对的。 |

**断症完，直接给你这 5 样（每样都有用、都能落地）：**

1. 🧍 **帮你立人设** 丨 副标题：通过 AI 多轮问答带你立起来
   内容：你到底是谁、立哪种人设、为什么立——人设先立住，后面所有话术才有“这个账号的我”。
2. 💎 **帮你提炼卖点** 丨 副标题：你的产品到底卖什么、好在哪
   内容：把卖点理成一页说得清的话，后面笔记和评论才讲得准、讲得不像广告。
3. 📚 **帮你整理知识库** 丨 副标题：把产品/专业知识理成“弹药库”
   内容：真实数据、步骤、结论做成 AI 可直接引用的库，话术才具体、专业、不空喊。
4. 🗂 **笔记规划 + 架构 + 发布节奏** 丨 副标题：这一整个月该发啥、怎么发
   内容：破冰立人设 → 点痛示警 → 实证建信任 → 教方法 → 展示产品 → 收割转化；再配上「一周几篇、什么时段」的节奏。
5. 🔖 **主页重设计** 丨 副标题：让路过的人一眼知道你是干嘛的
   内容：简介、头像、封面重排，人设和承接（怎么联系你）一眼立住。

## 三、练剑（配图②·下半）

**版块主标题：** 🏗️ 练剑
**副标题：** 内容不靠灵感，靠一套生产流水线
**内容说明：** 每一篇从选什么题、排什么结构、做封面到配图，都有方法可循，可复制、不靠感觉。

**选题 —— 四步动作：**
1. ① **按产品卖点出发** 丨 内容：从你卖的东西里找能打的角度。
2. ② **选人群（分人群单独总结话术）** 丨 内容：同一卖点，对不同人群要用不同的表达，一对一。
3. ③ **选话题** 丨 内容：挑这个人群此刻最关心、最能接住的话题。
4. ④ **汇总话术** 丨 内容：卖点 × 人群 × 话题 拧成一篇，直接能发。

**笔记结构 —— 按账号类型设计（品类矩阵）：**

| 账号类型 | 副标题 | 内容说明 |
|---|---|---|
| 虚拟资料 | 极简 1-3 页（大字报/目录） | 封面痛点+结果、价值目录、最后引导领取 |
| 实物评测 | 4-5 页（红黑榜对比型） | 封面对比、痛点避坑、核心横评、给出选购建议 |
| 场景种草 | 4-6 页（场景代入型） | 封面勾人、还原痛点场景、产品融入、真实体验 |
| 干货教程 | 5-7 页（步骤教学型） | 封面效果、前置准备、分步拆解、避坑提示、总结收藏 |
| 合集盘点 | 4-6 页（清单资源型） | 封面数字+人群、清单概览、逐一介绍、优先级、引导收藏 |
| 情感经历 | 4-6 页（经验复盘型） | 封面反差、真实故事、金句观点、价值升华、互动引导 |

**封面：** 背景 + 文案（账号 + 人设 + 标题 + 引流）丨 一张图把「你是谁 + 这篇讲啥 + 为什么要看 + 怎么联系」全说清。
**配图：** 卖点素材配图 + 文案素材 丨 先把产品和卖点配成图，再配文字素材，图文拼好直接能用。
**内容用料：** 文案/配图全部由产品知识库 + 真实经历组装（系统级强制引用具体数据，不空喊）——这是通用 AI-Skill 做不到的护城河。

## 四、截流（配图③）

**版块主标题：** 🎯 截流
**副标题：** 只捞「主动露出需求」的人，捞一个成一个
**内容说明：** 不去硬蹭，专接评论区那些真正想买、在问、被坑过的人。

**四步流水线：**
1. ① **找有需求的人** 丨 内容：扫评论区，只挑「求助 / 疑问 / 被坑 / 好奇」的，宁缺毋滥。
2. ② **分析他的人格** 丨 内容：先识别他的买前心理，属于下面 12 类里的哪一类。
3. ③ **对味下话** 丨 内容：按你的卖点 + 人设，生成最对他那款心理的话术。
4. ④ **给到他** 丨 内容：拟人节奏、逐字打字发出去，不招黑不封号，再进获客清单跟进到底。

**12 类买前心理（认准了才知道怎么撩）：**
| 心理类型 | 副标题（怎么撩） | 内容说明（判断信号） |
|---|---|---|
| 问价 | 报实价 + 讲清值在哪 | 一上来直接问“多钱”的人，先给方案别绕 |
| 冲动 | 顺势给好评证，帮他下决心 | 说“想买、有点心动”的，推一把 |
| 求测评 | 给真实横评数据 | 求推荐、求对比 VS 的，用数据说话显得懂 |
| 被坑 | 共情 + 避坑干货 | 说自己之前被骗过、踩过坑的 |
| 求助 | 先解决，再自然带产品 | 直接求支招、求帮忙的 |
| 好辩 | 不硬怼，借机补充观点立人设 | 爱抬杠、爱挑刺的，礼貌服软反立专业 |
| 拖延 | 给他一个不拖延的理由 | 说“想买但再看看/等发了工资”的 |
| 观望 | 拿数据帮他做判断，别催 | 在旁边看、犹豫不决的 |
| 高价值 | 高段位共鸣，匹配身份 | 有预算、显眼、身份感强的人 |
| 货比三家 | 摆差异化优势，帮他下结论 | 在多家之间比价格的 |
| 想学 | 给步骤教学，显专业 | 想问“怎么弄、怎么操作”的 |
| 沉默 | 自然提一次产品，等互动 | 只点赞围观、不说话的路人，别硬撩 |

**生成一句话话术，靠这几样素材（系统怎么玩）：**
- 🧍 人设：以「这个账号的我」第一人称在说
- 💎 卖点：产品卖点随话术自然带出
- 📚 产品知识库：强制引用具体数据/步骤，不空喊
- ✍️ 话术打法库：12 类打法看菜下饭，不套同一套
- 🎙️ 口吻样本：模仿你的语气，压 AI 腔
- 🗣️ 口癖词：随机口癖，条条像真人
- 🚫 合规红线：评论不直导站外，防封
- 📥 获客清单：高意向自动入池，定向跟进

**核心公式：** 拟人又专业 ＝ 人设 ＋ 卖点 ＋ 产品知识库 ＋ 话术打法 ＋ 你的口吻语气 —— 这套真实素材，通用 AI-Skill 给不了。
