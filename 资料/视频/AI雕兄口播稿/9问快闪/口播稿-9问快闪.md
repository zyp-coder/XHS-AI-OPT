## 录制用纯文本（11 段，段间空行）

老板您好。没投广告、没买流量，15 天承接 1000 多个真人。做您这行，9 个问题绕不开。

第一问：流量到底多大？小红书每天 8 亿次搜索——砍到您的城市和行业，每月还有 4300 个带购买意图的人，您一个都没接。

第二问：效果咋样？有人发笔记问「哪家好」，您的号就接上话；私信接着跟，您点头才发。客户名单里看得见。

第三问：怎么做的？四步——账号诊断、发笔记、评论区捞客、客户名单。

第四问：跟代运营、AI 工具比呢？代运营是模板，AI 工具按次收钱；这套用您自己的资料。

第五问：同行也在用吗？同行在捞，您只是看不见。池子是公共的——晚一天，少接一天。

第六问：不懂小红书怎么办？账号、内容、评论区、客户，系统都管——您每天 30 分钟。

第七问：会违规吗？红线摆明面上：站内只走主页简介和私信，不刷量、不硬广。

第八问：凭什么信我？这套系统是我先给自己做的，弯路我先走一遍。后台数据我摆出来。

第九问：价钱怎么算？按月付费，装在您自己的浏览器里：基础版 239、升级版 399、全功能 539。

拿不准选哪档？联系我免费做个测评。看主页简介，或私信我。

## 连贯性（每幕给下一幕留钩子）

- 幕1 报完成绩就抛「9 个问题绕不开」→ 2~10 幕逐条兑现；每幕以「第 N 问：」起头，听感上有节奏、可跳看。
- 幕2 落在「您一个都没接」（痛点）→ 幕3「效果咋样」正是老板的下一个疑问；
  幕3 的「您点头才发」「客户名单」又是幕5 竞品对比、幕4 四步的前置事实。
- 幕4 报四步 → 幕5「比呢」顺势解释凭什么用这套；幕6「晚一天少接一天」制造紧迫 →
  幕7、幕8 打消「没人手、怕违规」两个顾虑 → 幕9 用后台实拍兜底信任 → 幕10 才谈钱。
- 幕10 报完三档接「拿不准？」→ 幕11 收口免费测评，落点与长版片一致。

## 合规

- 承接只走「看主页简介 / 私信我」：全片无微信、无链接、无二维码。
- 效果数据（15 天 1000+ / 累计 1,412）**只出现在画面小字**，且就近带「效果因人而异」；**配音里不出现数字承诺**。
- 私信表述固定为「您点头才发」；漏斗数字沿用传单口径（4300/月）；全篇敬称「您」。
- 用语按 `资料/推广物料/使用说明.md` 口径表：评论区捞客 / 客户名单 / 按次收钱 / 真人节奏。
- 传单侧已定稿（2026-09-21）：背面只剩**微信码**（加微信发 3 分钟演示），不再放视频二维码；
  本片用于**地推现场/主页置顶**，不印在纸上。

**④ BGM**（两段：幕1-5 低沉氛围 → 幕6-11 律动，交叉淡化 3s 以 45.9s 为中心）：

  ```

    "资料/视频/AI雕兄口播稿/配音/bgm/A-低沉氛围-Vastness.mp3:0:45.9" \
    "资料/视频/AI雕兄口播稿/配音/bgm/B-律动-MinimalTechno01.mp3:45.9:95.93" \
    --out "资料/视频/AI雕兄口播稿/配音/bgm/BGM-9问-两段.m4a"

  python3 scripts/dev/render_video.py \
    --bgm-add "…/9问快闪/AI雕兄-9问-成片-封面首帧.mp4" \
    --bgm "资料/视频/AI雕兄口播稿/配音/bgm/BGM-9问-两段.m4a" \
    --out "…/9问快闪/AI雕兄-9问-成片-封面首帧-带BGM.mp4"
  ```

  切点 = 封面 1.5s +（`0.8 + starts[5] − 0.3`）= 1.5 + 0.8 + 43.89 − 0.3 = 45.9s，即第 5 问换幕那一刻；
  末段结束秒就是片长（晓晓版 95.93s，换音色后照 `.starts.json` 重算）。
  **踩过的坑**：给「封面首帧版」补 BGM 不能直接喂 `[0:a]`——那个成片的旁白是音轨整体后移 2.28s 实现的，
  滤镜会把偏移归零又在写文件时扣掉，结果旁白提前 2.3s、片尾少 2.3s（`--bgm-add` 已修：先 `asetpts=N/SR/TB` 再按偏移 `adelay`）。
  出完用交叉相关抽查配音落点（实测 +2.30s）与音轨长度（应等于片长）。
