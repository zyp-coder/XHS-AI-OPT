# AI雕兄 · 口播稿「发视频版」（10 幕 · 约 90s）

> 定位：一条讲「发视频」这条线的口播稿——同一篇口播稿，从点「出视频」进「出片台」，到一条竖版成片落在自己电脑上。
> 用途：平台发布（功能演示片）、发给已接触的准客户，也可作为谈单时讲「出视频」这一环的口头稿。
> 与发笔记稿的分工：一篇稿子落两条路——`口播稿-发笔记.md` 讲**图文这条**（复制成稿 / 导出封面 / 自己发），
> 本稿讲**视频这条**（出片台：口播稿 → 分幕 → 配音 → 出片）。两片可单独看，也可连播（接法见文末「出片说明」）。
> 与系统优势总结稿的分工：优势稿讲「这套系统凭什么」（八句话总述）；本稿是**功能深挖**，只讲出视频这一环，不重复讲评论区捞客、也不报价。
> 与 9 问快闪的区别：9 问是「问答式」（一屏一问）；本稿是「陈述式」（一条流程走到底）。
> 发布用文案（标题 / 正文 / 标签）：待写；要发平台时按 `系统优势总结/发布文案-系统优势总结.md` 同一套路出门（小红书轨 + 抖音轨）。
> 如需出片：竖屏页生成器与发笔记稿同批写（`scripts/dev/gen_note_page.py` 再加一组 `SCENES`，两片共用一套动效骨架）
> → 晓晓配音 → `render_video.py` → `prepend_cover.py` → `build_bgm.py`；每幕 `<p>` 即本稿口播文本（唯一真源），画面小字见下表右列。

## 录制用纯文本（10 段，段间空行）

很多人不发视频，不是不想发，是嫌麻烦：配音、字幕、画面，弄一条要大半天。其实这几步，现在都能省了。

路还是从发笔记那条来：口播稿写好，点「出视频」，稿子原样进「出片台」。分幕、配音、出片，几步走完。

第一步分幕：一行句子就是一幕，它自动拆好；每一幕屏幕上放哪几个字、重点词标哪个、版式怎么排，都能改。

第二步配音：五种音色随您挑，语速四档；挑好先试听，不合适随时换。

第三步风格：底色、主色、字体、重点词怎么标，都是现成的旋钮，还有四套配好的整风格——调好它会记住，下次出片直接沿用。

点「出片」，配音和画面一起合成一条竖版成片，等它跑完自动下载到您电脑上；片长按真配音算准，不会音画错位。

全程在您自己的电脑上完成：稿子、成片都留在本机，不用上传素材，也不用装剪辑软件。

稿子不满意，在发笔记那边说一句就改一版；换音色、改文案也不用重出，出片台里点一下重算就行。

它不替您想爆款，它替您把「发视频」这件事，变成点几下就能跑完的一步。

拿不准？联系我免费做个测评——方向对不对，做一次就知道；不合适，不勉强。看主页简介，或者私信我。

## 素材出处（内部核对用）

- **入口**（幕 2）：`popup.js` L756-759 的 `🎬 出视频`（`editionFeatureOn('videoFilm')` 才出现；**独立按钮、不进四层工作流**）
  → `npOpenFilm`（L776-781）`chrome.tabs.create` 打开 `extension/video.html`，把口播稿一起带过去；
  没带稿就沿用上次的（`video.js` 的 `KEY_SCRIPT = 'xhsFilmScript'`，进页面读回）。
  提示词包里那段「口播稿」另带出口「🎬 拿这篇出视频」（L1600-1616，`k === 'voice'` 且开关开才渲染）。
- **分幕**（幕 3）：`extension/lib/video/scenes.js` 的 `Scenes.fromScript` —— **离线按标点拆，不要网、不要 key**
  （每行 ≤14 字、每幕 14~32 字、一句一行、幕名取首句、重点词挑末句或 CTA）；面板里每幕还能改
  「屏幕上的字 / 分几行 / 重点词 / 版式（居中 / 左对齐 / 要点 / 数字）」（`video.js` `renderScenes`）。
- **配音**（幕 4）：`extension/lib/video/voices.js` 五种音色（晓晓 / 晓伊 / 云希 / 云扬 / 云健）
  + `video.js` `RATES` 四档语速（稳 / 正常 / 快 / 更快）；「试听这条」= `audition()`，
  念过的按 `voiceKey` 缓存，出片直接复用，不重复念。
- **风格**（幕 5）：`extension/lib/video/styles.js` —— `Renderer.FIELDS` 12 个旋钮
  （底色 / 主色 / 字体 / 字重 / 字号 / 行距 / 重点词 / 质感 / 光晕 / 编号 / 节奏 / 品牌名）
  + 四套整风格 `Renderer.PRESETS`（A 深色品牌橙 / B 深色鎏金 / C 米白纸感 / D 浅灰科技）；
  「存为默认风格」把风格与音色写进 `chrome.storage.local`（`xhsFilmStyle` / `xhsFilmVoice`），下次进来自动带出。
- **出片**（幕 6）：`video.js` `make()` —— `Voice.speak` 逐幕念出**真秒数** → `Voice.timeline` 现排时间轴
  → `Renderer.renderFrame` 逐帧 → `Encoder.encode`（`mp4-muxer.js`）出 1080×1920 MP4；
  文件名 `成片-<MMDD-HHMM>.mp4`（L258）自动下载，状态行「完成 XMB · Ys · 已下载」。
  片长按真配音算（`showEst()` 显示「N 幕 · 约 Xs（已按真配音算过）」）——换音色 / 改文案会把时间轴清掉重算，所以「不用重出」。
- **本机**（幕 7）：`extension/video.html` 头部 tip「口播稿 → 分幕 → 配音 → 出片，**全程在这台机器上跑，不上传任何东西**」；
  出片全程在扩展页面里跑，**没有服务端**（控制台已整体删除，见 `资料/小红书AI引流系统-知识体系总览.md` §一）。
  **内部注意**：免费配音走 Edge 通道（`build.js` L382 `useEdge = !!features.videoFilm`；`EdgeTTS.isEdge()` 判不是 Edge 时页内会提示）
  ——**对外不提浏览器名**，只说「不装剪辑软件」。
- **改稿**（幕 8）：`popup.js` `npVoiceRewrite`（L790-819）——「说一句就改一版」，只留一层回退（`_npVoicePrev`），
  改完写回 `_npPackResult.voice`（L812）；手改 textarea 也回写（L1188-1191）。出视频带过去的就是这份稿。
- **档位（内部，不进本片）**：出片台随 `videoFilm` 走 = **三档全开**（2026-10-09 五十四改起，三档预设均 `videoFilm: true`）。本片**不报价、不提档位**。

## 合规自查

- 承接只走「主页简介 / 私信我」：全稿无微信、无链接、无二维码。
- **不承诺效果**：幕 9 明写「它不替您想爆款」；画面小字如出现效果类字样，就近带「效果因人而异」（录单时用户仍需挂「效果因人而异」小字）。
- **不出现「自动发布 / 定时发布」**：幕 6「自动下载」指**成片落回本机**，不是代发；发布动作由用户自己在小红书完成。
- **不提音色名与具体片长**（幕 4 只说「五种音色、语速四档」）；**不提浏览器名**（免费配音走 Edge 是客户机限制，见素材出处）。
- 用语按 `资料/推广物料/使用说明.md` 口径表：发笔记 / 成稿 / 出视频 / 出片台 / 本机；
  无「截流 / 私域 / 客户池 / 拟人 / 灌水」等词，也无平台对抗性词（防封 / 反爬 / 规避 / 养号 等）。
- 全篇敬称「您」；全稿**不含平台词**（无「小红书」「视频号」），两轨可共用同一份稿与画面。
