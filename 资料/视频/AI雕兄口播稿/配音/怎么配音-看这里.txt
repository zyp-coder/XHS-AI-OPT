【一】改词 → 重新配音
  1. 改该片动效页里每幕的 <p>（口播唯一真源）。页有生成器的先改 SCENES 常量再重跑生成器
     （长版页无生成器，直接改页；9问/短版/优势 的生成器在 scripts/dev/gen_qa9_page.py、
     gen_short_page.py、gen_adv_page.py——只改 HTML 的话重跑一次就回退）。
  2. python3 scripts/dev/tts_voice.py \
       --html "资料/视频/AI雕兄口播稿/<片子>/<页>.html" \
       --voice zh-CN-XiaoxiaoNeural --rate "+20%" --gap 0.5 \
       --out "资料/视频/AI雕兄口播稿/配音/配音-<片>-晓晓.mp3"
     逐幕合成、缓存命中只补改动的幕；产出 m4a/.mp3 + .starts.json（每幕精确起止，渲染按它卡点）。

【二】出成片（画面按配音精确分幕换幕）
  python3 scripts/dev/render_video.py \
    --html "D:/AIproject/小红书运营/资料/视频/AI雕兄口播稿/<片子>/<页>.html" \
    --audio "资料/视频/AI雕兄口播稿/配音/配音-<片>-晓晓.m4a" \
    --out "资料/视频/AI雕兄口播稿/<片子>/AI雕兄-<片>-成片.mp4"
  --html 要绝对路径；报告里看「分幕校验/时长校对」两行，偏差几十毫秒内属正常。
  渲染共用 成片/_frames——同一时间只跑一个渲染；它会重写 成片/封面-01.jpg 等抓帧样张，
  跑前备份（如有旧封面首帧依赖）跑后删掉。

【二·B】BGM（曲子都在 配音/bgm/）
  **换片长必须重算切点**：切点 = 0.8 + starts[N] − 0.3（接封面再 +1.5，交叉淡化 3s 以切点为中心）；
  末段结束秒就是片长（= 0.8 + 配音总长 + 尾 1.4 + 封面 1.5）。starts[N] 在 .starts.json 里。
  两段拼（9问/短版/优势）：
    python3 scripts/dev/build_bgm.py \
      "…/bgm/A-低沉氛围-Vastness.mp3:0:<切点>" "…/bgm/B-律动-MinimalTechno01.mp3:<切点>:<片长>" \
      --out "…/bgm/BGM-<片>-两段.m4a"
  三段拼（长版 A→B→C 温暖钢琴收尾）命令见口播稿/成片目录里的记录。
  已出好片只补音乐（不重渲染画面、约 1 分钟）：
    python3 scripts/dev/render_video.py --bgm-add "…/成片.mp4" --bgm "…/bgm/BGM-<片>-两段.m4a"
  说明：不做「说话时音乐自动避让」——剪映自带 ffmpeg 的 sidechaincompress 实测同一段素材压得时多时无、
        不可复现，所以改成固定垫底电平（-18dB，脚本自动量人声/音乐平均电平再定标，换歌不用手调音量）；
        不够长会循环铺满。BGM 总长必须 = 带封面的片长，短了会在片尾循环出瑕疵。

【三】接封面首帧（封面静止 1.5s + 原片；旁白延后 2.3s 进；BGM 从 0 起）
  python3 scripts/dev/prepend_cover.py \
    --cover "资料/视频/AI雕兄口播稿/成片/封面-<片>-9x16.jpg" \
    --video "资料/视频/AI雕兄口播稿/成片/AI雕兄-<片>-成片-无声.mp4" \
    --voice "资料/视频/AI雕兄口播稿/配音/配音-<片>-晓晓.m4a" \
    --bgm "资料/视频/AI雕兄口播稿/配音/bgm/BGM-<片>-两段.m4a" \
    --out "资料/视频/AI雕兄口播稿/<片子>/AI雕兄-<片>-成片-封面首帧-带BGM.mp4"
  产出后把它旁边的「…-封面首帧-带BGM-无声.mp4」改名成「…-封面首帧-无声.mp4」（无音乐版）。
  封面图出图：python3 scripts/dev/gen_cover.py -v <版> -H 1920 --suffix=-9x16（不带后缀 = 3:4 版）。
  版号见 AI雕兄-封面.html：a~d 长版备选（长版用 定稿A+C）、e = 9问快闪、f = 优势总结、
  g = 9问快闪抖音版、h = 优势总结抖音版。

【四】备选：自己录 / 剪映朗读（当前不用）
  想换真人声：录好的音频丢进 配音/ 走【二】出片（没有 .starts.json 时脚本自动改用语音停顿检测分幕）。
  想让剪映朗读：《AI雕兄-配音-粘贴版.txt》整段贴进剪映「文本朗读」生成配音，导出后同样走【二】。
  克隆音（配音-我的声音.m4a）为历史产物，只在 成片/旧-克隆音版/ 的旧成片音轨里留档。

【五】如果改了讲解词
  改页里 <p>（唯一真源）→ python3 scripts/dev/gen_voice_paste.py 重建《AI雕兄-配音-粘贴版.txt》。
  （长版反向稿《AI雕兄-配音稿-竖屏.md》由 gen_voice_script.py 从页生成。）

【六】抖音轨：改完小红书页必须重派生
  python3 scripts/dev/gen_douyin_pages.py
  它读四个小红书页，按内置 RULES 表把平台词换成中性说法（只盯视频号→只盯自己的号、
  小红书→小某书/线上、真人加到产品 / 私域→承接真人用户 …），写到旁边的「…-抖音版.html」。
  映射里有哪条对不上、或写完还剩「小红书/视频号/私域/微信」，脚本直接报错不出文件——
  所以**别手改抖音页**，改小红书页再重派生。派生完配音/渲染/BGM/封面流程与小红书轨完全一致，
  只是路径带「-抖音版」「-晓晓-抖音」，BGM 切点按抖音自己的 .starts.json 重算（两轨词不同、时长不同）。
  已知残留：画面里的搜索截图是真实平台 UI，没有品牌字，但「问点点」这类功能名细看能认出来；
  介意就换 <img> 里的图。派生只换文字、不动样式，但换完长短会变，出片后照样过一眼接触表看有没有撑破版。
