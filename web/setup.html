看图文教程（每一步点哪里）→ 第一次装，建议开着教程一步步对
在文件夹里这两步动的是下载下来的文件，跟浏览器没关系
1
先解锁，再解压到一个自己记得住的文件夹
右键下载好的 zip →「属性」→ 最下面勾「解除锁定」→「确定」，再右键 →「全部解压」， 解到一个固定的地方，比如 D:\小红书助手-执行器\。 不勾「解除锁定」，里面的装我.bat 会带着“来自网络”的记号被 Windows 拦。这个解压出来的文件夹别删、别挪——以后更新、卸载都要回到它里面双击。
✓ 解压出来的文件夹里，直接看得见 manifest.json 和 装我.bat。
2
双击「装我.bat」，记住窗口里那句路径
进文件夹双击 装我.bat。它会自己把程序放到固定位置、把路径复制到剪贴板、再打开扩展页。 弹「Windows 已保护你的电脑」就点「更多信息」→「仍要运行」；弹的是「智能应用控制已阻止」、只有“不运行”没有“仍要运行”，这条就走不通了，改按装机教程第 ⑦ 条手动装（不用双击）。
✓ 窗口里出现「已放好：C:\Users\…\XhsHand\…」就对——这句就是下一步要加载的路径（已经帮你复制好了），这个窗口先别关。
✗ 窗口说「没找到 Chrome 或 Edge」：先装 Chrome，再双击一次这个文件。
在浏览器里这两步都在浏览器的扩展页里点，跟文件窗口无关
3
扩展页：打开开发者模式，加载刚才那个文件夹
扩展页一般已经自动打开了；没打开就在地址栏输 edge://extensions（Chrome 输 chrome://extensions）回车。
① 打开页面右上角的「开发者模式」开关——变成蓝色才算开，开了下面才会多出按钮；
② 点「加载解压缩的扩展程序」→ 选文件夹的窗口里按 Ctrl+V（路径已复制）→ 点「选择文件夹」。
✓ 列表里出现「小红书助手 · 执行器」那张卡片，带一长串 ID，＝装好了。
✗ 没出现卡片：多半选错层级了——要选的那个文件夹里得直接看得见 manifest.json，不是它的上一层，也不是里面的子文件夹。
4
点执行器图标「挂上」，这个浏览器别关
点浏览器工具栏上的执行器图标（没看到就点右上角的拼图🧩，把它钉到工具栏）；服务器和配对号都已经填好 → 点「🔗 挂上」。
这个浏览器别关：关了就不干活，网页上派的单会排着，回来接着跑。
✓ 面板上出现 🟢 在线待命；回这一页刷新也会显示在线。

常见问题

重启几次后，扩展变灰 / 被停用了（Edge 有这毛病）
新版 Edge 有时会把手动装的扩展「偷偷禁掉」。装好的文件夹里带了个小工具：把 Edge 完全关闭 → 双击「已放好：…」那个文件夹里的「Edge-防禁用.bat」→ 再打开浏览器，就好了。 （那个文件夹在哪：双击「装我.bat」的窗口里写着。）嫌麻烦就直接用 Chrome，一样的装法、没这毛病。
挂线时提示「还没到能装执行器的档位」
这个号还是免费档。执行器是 239 起的档位带的——找给你开通的人办；开通后这一页的下载按钮和配对号就会点亮。
配对号填不对 / 换电脑了怎么办？
你那份安装包配对号已经填好，不用抄。换电脑：新电脑照四步装好、挂上就行——一个号挂一台，旧的那台自动作废（正在跑的活也会停下）。
它会乱动我的账号吗？
不会。它只干网页上派的活（发笔记 / 获客 / 日常浏览 / AI客服），全在你这台浏览器里跑；频率还有「账号安全」挡位拦着，不会疯跑。服务器只下单、记账，不碰你的账号。
