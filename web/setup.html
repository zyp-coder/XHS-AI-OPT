① 下载约 1.2 MB

⬇️ 下载执行器（zip） 所有人共用同一个包；包里带「装机-看这里.txt」和一键小工具，解压先看说明书。

② 三步装上Edge / Chrome 都一样

1
解压到一个固定文件夹
比如 D:\小红书助手-执行器\。解压完里面能看到 manifest.json、panel.html。 （以后别挪这个文件夹，挪了要重新加载。）
2
浏览器里加载
地址栏输 edge://extensions/（Chrome 用 chrome://extensions/）→ 打开「开发者模式」→ 点「加载解压缩的扩展」→ 选中刚才那个文件夹。 （列表里出现「小红书助手 · 执行器」＝成功，建议把它固定到工具栏。）
3
填配对号挂线
点工具栏上的执行器图标 → 服务器地址已经填好了 → 填上面那个配对号（点「复制」）→ 点「🔗 挂上」→ 变成 🟢 在线待命 就是挂上了。 （之后网页上点「发 / 开始」，这只手就去干活；别关这个浏览器——关了就不干活，单会排着，回来接着跑。登录过期会停下来等你扫码，不会硬跑。）

③ 常见问题

重启几次后，扩展变灰 / 被停用了（Edge 有这毛病）
新版 Edge 有时会把手动装的扩展“偷偷禁掉”。包里带了个小工具：把 Edge 完全关闭 → 双击包里的「Edge-防禁用.bat」→ 再打开浏览器，就好了。 嫌麻烦就直接用 Chrome（chrome://extensions/），一样的装法、没这毛病。
挂线时提示“还没到能装执行器的档位”
这个号还是免费档。执行器是 239 起的档位带的——看下面「档位」那张表，找给你开通的人办；开通后这一页就会出现下载按钮和配对号。
配对号填不对 / 换电脑了怎么办？
配对号一串字符，照抄就行，别漏字。换电脑：新电脑照三步装好、填同一个配对号挂上就行——一个号挂一台，旧的那台自动作废（正在跑的活也会停下）。 旧电脑不用了就丢了、或者你想把码换掉：找给你开通的人，在后台换一个码，旧的当场失效。
它会乱动我的账号吗？
不会。它只干网页上派的活（发笔记 / 获客 / 日常浏览 / AI客服），全在你这台浏览器里跑； 频率还有「账号安全」挡位拦着，不会疯跑。服务器只下单、记账，不碰你的账号。
