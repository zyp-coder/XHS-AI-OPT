开始之前三件事先确认

浏览器只能用 Chrome 或 Edge。360、QQ、搜狗、夸克这些装不了。
安装包登录装机页就能下到你专属那份，配对号已经填在里面，不用抄。

四步装完

1登录，下载你自己那份安装包约 1.4 MB

打开装机页，用领号时的手机号登录，点「⬇️ 下载我的安装包（zip）」。 这个包只给你这台电脑用，配对号已经在里面了。

看到这个就对：文件列表里多出一个 小红书助手-执行器.zip（文件名可能带你的名字）。
别去问别人要包——每人的包不一样，用错包会挂到别人的号上。
2先解锁，再解压，双击「装我.bat」窗口先别关

右键这个 zip →「属性」→ 窗口最下面勾上「解除锁定」→「确定」，再解压。 不勾这一步，解压出来的「装我.bat」会带着“来自网络”的记号，被 Windows 拦一下。

右键包 →「全部解压」，进到解压出来的文件夹，双击 装我.bat。 它会自己把程序放好、把文件夹路径复制到剪贴板，再把扩展页打开。

弹「Windows 已保护你的电脑」就点「更多信息」→「仍要运行」。 弹的是「智能应用控制已阻止」这种、只有“不运行”没有“仍要运行”的，见下面第 ⑦ 条（换一条不用双击的装法）。

看到这个就对：小黑窗里写着「已放好：…\XhsHand\你的代号」，浏览器自动跳到扩展页。
这个小黑窗别急着关——第 4 步选文件夹时，路径就是从它这里粘过去的。

卡住了看这里七种最常见的

① 找不到「开发者模式」开关
它在扩展页的右上角，不在右上角那三个点里。地址栏直接敲 chrome://extensions（Edge 是 edge://extensions）就能到这一页。 窗口太窄时按钮会被挤到下面，把浏览器拉宽或按 Ctrl+- 缩小一点。
② 列表里没出现执行器 / 提示清单文件缺失
这是选错文件夹了。你选的那个文件夹里必须直接能看见 manifest.json—— 不是它的上一层，也不是里面的 lib 之类子文件夹。最稳的办法：回到第 2 步的小黑窗， 它写着「已放好：」后面那一整条路径，原样粘进去就是对的。
③ 双击装我.bat 被 Windows 拦下来
分两种，看弹窗上有没有「更多信息」：
① 有「更多信息」→ 点它 →「仍要运行」，这就是普通下载拦截，一次就过。
② 写的是「智能应用控制已阻止」、按钮只有“不运行”、根本找不到“仍要运行”——这种关不掉，别硬试，照第 ⑦ 条走。
另外，解压前先右键 zip → 属性 → 勾「解除锁定」，能省掉一大半这种拦截。
④ 双击后闪一下就没了 / 提示没找到浏览器
说明这台电脑上没装 Chrome 或 Edge，或者被杀毒软件拦了。先装 Chrome（推荐），再双击一次； 如果杀软弹窗问，选「允许」。还不行，把窗口里的原话拍给我。
⑤ 点「挂上」变红、提示连不上
依次看三样：① 面板里「服务器」那格是不是 http://8.222.157.6/；② 电脑能上网、没开公司代理； ③ 这个号是不是还在档位里（免费档不能挂）。三样都对还红，把红字原话发我。
⑥ 用几天后扩展变灰 / 被浏览器停用了
这是 Edge 的老毛病——它会把手动装的扩展偷偷禁掉。两个办法： 换 Chrome（最省事，一样的装法、没这毛病）；或者把 Edge 完全关掉 → 双击装好的那个文件夹里的 「Edge-防禁用.bat」→ 再打开浏览器。装到哪了：第 2 步小黑窗里写着那个路径。
⑦ 智能应用控制拦死了，双击根本不弹「仍要运行」
这是 Windows 11 的智能应用控制在拦：它一旦是“开”的状态，设置里是关不掉的，只能重装系统才恢复可关。 所以这类机器不要走双击，改成手动搬一下，四步，一样能用：
① 解压、改名：把 zip 解压到桌面，把解压出来的文件夹改名成你的代号（就是安装包文件名去掉 .zip 那一串）。
② 搬进固定位置：地址栏粘 %LOCALAPPDATA%\XhsHand\ 回车（提示找不到就先在这个位置新建一个 XhsHand 文件夹），把改好名的文件夹拖进去。
③ 加载扩展：打开扩展页（Edge 是 edge://extensions，Chrome 是 chrome://extensions）→ 右上角「开发者模式」打开 →「加载解压缩的扩展程序」→ 粘 %LOCALAPPDATA%\XhsHand\你的代号 →「选择文件夹」。
④ 挂上：点工具栏上的执行器图标 →「挂上」，变绿就好。
这么装的没设开机自启：要设就在地址栏粘 shell:startup 回车，把文件夹里的 boot-start.vbs 拖进去。
更新：新包解压后把里面的文件全选、复制，粘进 %LOCALAPPDATA%\XhsHand\你的代号 覆盖，再到扩展页点「重新加载」。
不用了：删掉那个文件夹，扩展页里点「移除」。

掉线、换电脑、不用了

面板变灰 / 显示离线
打开装执行器的那个浏览器，点执行器图标，重新点「挂上」。如果提示登录过期，按它说的扫码登一下小红书，再点挂上。
换一台电脑
新电脑照这四步装一遍、挂上就行——一个号挂一台，旧的那台自动作废（正在跑的活会停下）。 装机页登录同一个号，下载的仍然是你的专属包。
不用了，怎么退干净
在扩展页找到「小红书助手 · 执行器」，点「移除」；再双击装好的文件夹里的「卸载.bat」把文件删掉。两步都做完就干净了。
我们这边发了新版本
装机页下载新的包 → 双击包里的「更新.bat」（覆盖文件，配对号不掉）→ 回扩展页点一下卡片上的「重新加载」。
