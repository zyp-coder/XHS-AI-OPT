功能模块讲解每个模块有哪些页、从头走一遍

▾
从写稿到发出去：AI 写稿、出图、出片、排期发布，每篇留档。
任务配置

出稿前的两张默认表，定一次全按它走。

  • 内容基调：4 种基调挑一种：怎么铺垫、何时上广告、占多少、写多长。
  • 出图风格：画面风格、印记、配文版式，出图照这张表。
笔记档案

写过的每篇都在这留档，草稿也在。

  • 开始一篇：点「✍️ 新建笔记」，填产品和方向 → AI 出样稿 → 挑一份改成你的话 → 定稿。
  • 接着做：每行一颗「下一步」，写到哪步直接送过去。
  • 看全貌：图文/视频、写到哪步、排到哪天，一张表看清。
发布台

排 + 发一条线。

  • 发布队列：按每周排法滚 3 周；点「＋ 排一篇」从档案挑，标「代发」自动进最早空位。
  • 到点自己发：到点自动发；视频篇发三家、图文篇两家。
  • 笔记规划：每周几篇、分几阶段、每阶段讲什么，AI 帮排。
素材库

备料的地方，一类一个集合。

  • 视频段和图片混放，空集合标「待补充」。
  • 点进去看料、传图、连播；写稿出片直接取。
复盘

发完回头看的地方。

  • 选题盘点：哪类知识、哪个角度讲过、哪些没讲，按分类看。
  • 已发复盘：发过的数字趋势都在这，看哪篇在涨。
从头走一遍：定基调 → 新建笔记、挑样稿 → 定稿（多平台各改写一版）→ 出图/出片 → 发布台排期 → 到点发 → 复盘。
按关键词刷笔记、扫评论区，把想买的人挑出来接话。
任务配置

告诉系统去哪找、找什么样的人。

  • 词池：搜什么词、跑哪几类笔记、多久跑一次。
  • 盯的账号：同行/对标主页放进来，也跟着刷。
  • 推广目标与承接：评论区接话带什么去向。
队列

到点的活排队，串着自动跑。

  • 「词×类型」和盯的账号都进队；还有「日常浏览」随机刷首页。
  • 在跑、待跑、没到点、已完成，一眼看清。
  • 不想等，可手动来一轮。
工作台

接话就发生在这。

  • 当前评论区里，谁想买、谁问价，替你挑出来。
  • 挑中人一键接话；现场搜词也在这页。
笔记池

刷过的笔记都进池子留底。

  • 按类型标状态，点开就去看评论区、接话。
  • 哪轮扫的、发了多少、哪些没打开，都能回来补。
设置

跑的时候多快、多密。

  • 操作挡位、每步停多久、每轮跑多少、多久不重复。
  • 顺手关注开不开。
从头走一遍：配好词和账号 → 到点自动刷 → 想买的进工作台接话 → 笔记池留底可补 → 设置调节奏。
评论、点赞、私信都收拢到这；AI 帮你盯私信、照话术回。
任务配置

定 AI 开口说话的样子。

  • 渠道基调 / 成交引导：AI 说话带什么去向、怎么往成交带。
  • 话术配置：客服话术都存这；「试问答」先试它回得像不像你。
通知

平台动静的第一落点。

  • 评论、赞、收藏、关注、新粉丝都在这。
  • 每条能直接回评 / 让 AI 拟话 / 去触达。
消息

私信往来都在这。

  • 对方进线等你回；你先开口的等对方回。
  • AI 照话术拟好回复，你过一眼发出去。

从头走一遍：定好去向和话术 → 开「AI客服监听」→ 新评论、点赞、私信自动收进通知/消息 → AI 拟好回复，你过一眼发出。
