## 一、录屏参数（统一基线）

| 项目 | 建议值 | 说明 |
|---|---|---|
| 分辨率 | 1920×1080 (16:9) | 竖版内容的绝对标准，小红书也吃得下 |
| 帧率 | 30fps | 录屏足够，60fps 文件大且没必要 |
| 码率 | 10-15 Mbps | OBS：设置→输出→录制，x264 高速 |
| 编码 | H.264 (.mp4) | 剪映/PR 原生流畅，避免 HEVC 兼容问题 |
| 浏览器窗口 | 固定 1280×800，居中 | 四周留黑边剪掉即可，保证比例统一 |
| 鼠标 | 打开 OBS→光标下拉大可见 | 演示操作要看得清 |
| 音轨 | 旁白单独录一条音轨 | 建议匿名音量小、口播占比大 |

**录屏顺口溜**：分辨率不缩、窗口固定、留黑边好剪、旁白分离。

## 四、剪辑小技巧

1. **分 3 段剪**：装扩展 / 配置 / 灌水，三段各自节奏，合成后再铺旁白，比地毯式一次录完好控。
2. **加节奏空拍**：每个大字切出时留一拍空音，字幕呼吸感更好。
3. **灌水段可用加速**：自动跑的中段观感久，可 2x-4x 加速 + 保留发布成功一帧正常速度，冲击力强。
4. **导出设置**：短视频 1080P·30fps·H.264；若发小红书横屏/竖屏按平台再裁。
