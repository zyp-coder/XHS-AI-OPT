## 📝 给多模态模型的处理指令（可直接复制）

> 把以下内容喂给你的多模态模型（豆包等），告诉它基于这些截图做视频：

```
请基于以下截图素材，帮我制作一条 2分30秒 的小红书AI引流工具宣传片。

素材列表见上方表格。画面顺序：
1. scene1-note  → 引出痛点（刷评论效率低）
2. scene2-popup → 核心卖点（AI挖商机+3套话术）
3. settings-basic → 配置演示（30秒填三样）
4. settings-ai → AI配置（测试连接通过）
5. scene3-autowater → 一键灌水全自动（大亮点）
6. settings-tenant → 多产品切换
7. scene2-popup 回放 → CTA收尾

风格：轻快、科技感、大字卡点。每个场景停留 3-5 秒，
配合口播节奏切镜。BGM 用 up-tempo 轻快节奏。

输出要求：
- 给出每个画面的精确入点/出点时间
- 每个画面配什么大字标题
- 转场效果建议
```
