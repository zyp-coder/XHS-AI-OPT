🏗️ 练剑 —— 内容不靠灵感，靠生产流水线
从选什么题、排什么结构，到封面配图、用哪份资料，都有方法可循。
✏️ 选题 · 四步动作 —— 卖点 × 人群 × 话题，拧成一篇能发的
①
按卖点出发
从你卖的东西里，找这条最值得打的角度
②
选人群
同一条卖点，对不同人群单独写话术，一对一
③
选话题
挑这个人群此刻最关心、最能接住的话题
④
汇总话术
卖点×人群×话题 拧成一篇，直接能发
🧱 笔记结构 · 按账号类型设计 —— 不同号，不同结构，不套模板
📦 虚拟资料
极简 1-3 页
封面痛点+结果 → 目录证明干货 → 引导领取，决策成本低。
🧪 实物评测
4-5 页红黑榜
封面对比 → 避坑 → 核心横评 → 明确选购建议。
🌿 场景种草
4-6 页代入
封面勾人 → 痛点场景 → 产品融入 → 真实体验。
📘 干货教程
5-7 页步骤
封面效果 → 准备 → 分步拆解 → 避坑 → 引导收藏。
🎁 合集盘点
4-6 页清单
数字封面 → 清单概览 → 逐一介绍 → 优先级排序。
💛 情感经历
4-6 页复盘
反差封面 → 真实故事 → 金句 → 价值升华 → 互动。
🖼 封面 + 🎞 配图
封面
背景 + 文案
账号＋人设＋标题＋引流，一张图把「你是谁 ＋ 这篇讲啥 ＋ 为什么看」一次说清。
配图
卖点素材＋文案素材
先把产品和卖点配成图，再配文案素材，图文拼好直接能用，省事不出错。
📚 知识库整理重点 —— 让每句文案都有据可依
📦 产品简述 / 卖点
一句话说清你这产品是啥、好在哪
🔢 真实数据 / 额度
话术引用具体数字，有干货不空喊
🛠 操作步骤 / 路径
能教人“怎么用”，专业感拉满
👤 个人经历 / 案例
像“过来人”在说话，不像广告
📐 品类矩阵 / 账号类型
决定笔记结构怎么搭
💬 话术模板
参考话术，直接套用少走弯路
系统玩法：按评论关键词做两阶段检索（先标题+标签粗筛、加角色加权，再做内容精选），只把最相关几条注入 AI —— 所以每句都能落到你的真数据上。这套真实素材，通用 AI-Skill 给不了。
