# 新生儿黄疸数值多少要就医？

我家宝宝出生第3天，脸上开始发黄。
护士来一测，黄疸值15。
我老婆当场就哭了。

医生说先观察，多吃多拉就能退。
但网上查了一堆，越查越害怕。

后来搞明白了：生理性黄疸不用慌，病理性才要就医。

生理性：出生后2-3天出现，10-14天消退
病理性：出生24小时内出现，数值持续升高

参考值（足月儿）：
第1天<5mg/dL → 安全 | 第3天<10mg/dL → 安全
第5天<13mg/dL → 安全 | 第7天<15mg/dL → 安全

当时我家15就在临界线上，
我每天用自己做的「新手宝妈+工具箱」小程序的黄疸记录功能，

打开微信→搜新手宝妈+工具箱→建档后点黄疸记录：
- 每天输入黄疸数值
- 自动判断在哪个风险区间
- 生成变化曲线，复查给医生看

看着曲线一天天降下来，心才放下来。
