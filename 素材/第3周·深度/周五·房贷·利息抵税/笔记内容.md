# 房贷利息抵个税 每个月能省多少钱？

我有个同事还了3年房贷，不知道利息能抵个税。
我说你亏大了，3年的都没填。
他补填完退了4000多块。

房贷利息抵扣个税的规则：
- 每月定额扣1000元
- 最长扣240个月（20年）
- 必须是首套房

每月能省多少，看你税率：
税率3%→月省30元 | 10%→月省100元
20%→月省200元 | 25%→月省250元
- 30%→月省300元

操作很简单：个税APP→专项附加扣除→住房贷款利息
