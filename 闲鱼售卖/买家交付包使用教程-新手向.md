
## 3. 第①步　装 Chrome + 开通 DeepSeek 拿 API Key

**A. Chrome 浏览器**
- 电脑上还没有就装一个：搜"Chrome 下载"，认准官网 `www.google.com/chrome` 下载安装。
- 装好后，打开小红书网页版 `https://www.xiaohongshu.com` 登录你的账号。

**B. 开通 DeepSeek 拿 API Key（约 5 分钟）**
1. 打开 `https://platform.deepseek.com`，注册并登录。
2. 左侧菜单找「**API Keys**」→ 点「**创建新密钥**」。
3. 复制那串 **`sk-xxx...`**（⚠️ **只显示一次，先拷贝到备忘录存好**，丢了得重建）。
4. 按你预计的用量充一点钱（AI 按用量计费，一次话术才几百 Token，很便宜）。

> ✅ 拿到 `sk-` 开头的这串，第③步向导要粘。没有它，AI 无法帮你写话术。

## 4. 第②步　解压 + 开发者模式加载扩展

**A. 解压安装包**
- 把你收到的 **zip 压缩包解压**到一个固定文件夹（⚠️ **别放临时目录**，删了就失效）。
- 解压后你会看到一个文件夹，里面是扩展文件 + `使用说明.txt / .html`。

**B. 加载到 Chrome（只需做这一次）**
1. 打开 Chrome，地址栏输入 `chrome://extensions` 按回车。
2. 打开右上角「**开发者模式**」开关。
3. 点「**加载已解压的扩展程序**」→ 选择你**解压后那个文件夹**。
4. 成功后浏览器右上角出现插件图标，建议点「📌」固定住。

> ⚠️ 这一步 Chrome 必须开"开发者模式"，这是浏览器规则，所有类似工具都一样，装上后正常使用不受影响。

## 5. 第③步　首次设置向导（激活）

1. 在 Chrome 打开小红书网页 **并登录你的账号**。
2. 点右上角**插件图标**，会自动进入「首次设置」向导。
3. 按顺序填：
   - **① AI 配置**：选提供方（默认 DeepSeek），粘贴第①步拿到的 `API Key` → 保存 → 点「测试连接」，显示成功即 OK。
   - **② 产品信息**：填你要推广的产品 / 服务名 + 一句简介。
   - **③ 推广目标**：选一个（卖产品 / 品牌种草 / 主页涨粉 / 互动涨赞等）。
   - **④ 绑定账号验证**：先在浏览器打开**你这个号自己的「我的」主页**并保持开着 → 回来点「验证」→ 通过即解锁可用。
4. 以后要改配置，随时回插件窗口右上角「⚙️ 设置」里改。

## 6. 第④步　账号诊断 6 步，把账号理清楚（新手必看）

> ⭐ **强烈建议先跑一遍**。它会把一个"没运营经验的人根本想不到要准备"的东西，**一步步问齐、帮你理好**，后面 AI 写话术、帮你出方案才靠谱。

进「插件 → 账号诊断」，跟着 6 步走：

1. **① 账号资料**：点「抓取我的主页」，自动读你的昵称 / 简介 / 发过的笔记。
2. **② 人设 / 说话风格**：答 **5 大问**——你是谁、有什么经历、最拿手的干货、账号定位、想要的人设感；再贴几条你真实发过的评论当**口吻样本**、填几个**口癖词**，AI 就学着像你说话。答得越细，整理出的人设越像你本人。
3. **③ 产品卖点**：答几问——产品是什么、帮人解决什么、最大的优势、能证明价值的数字案例。
4. **④ 知识库**：把你产品的**真实数据、目标客户的顾虑、亲历案例、行业数字、2-3 个专业观点**录进去。AI 写话术时**强制引用这些真实内容**，话术才有干货、不像广告。**这块是整个系统的核心燃料，越细越专业。**
5. **⑤ 内容规划 & 封面**：AI 帮你定讲什么、写给谁、做几页、多久发一篇，连封面都出方案。
6. **⑥ 深度报告**：汇总成一份**照着做就行**的整改方案。

> 不想细答也能跳过/少答，但**知识库、人设、卖点越全，后面效果越好**。

## 7. 第⑤步　正式开跑：找笔记 → AI 挖商机 → 发话术

**方式 A：打开具体某篇笔记手动看**
1. 打开一篇你想运营的笔记（可以是你的，也可以是对手/同行/相关话题的）。
2. 点插件窗口「🔄 刷新」→ 自动提取评论 → AI 挖出商机标出来。
3. 看 AI 生成的话术，满意就点该条「一键发送」（**每条都要你人工确认才发**）。

**方式 B：一键灌水（批量自动，进阶）**
- 在插件左侧添加你想搜的**关键词列表**（按你的档位上限），点「🔎 搜索」批量找笔记，再由「冷启动 / 循环计划」自动跑。
- 两种策略：**冷启动**= 搜词批量跑量冲量；**循环计划**= 每 N 分钟扫点赞变化，**专蹭正在快速增长的热门笔记**。
- 有防重复、自动跳过自家号、上限保护，跑完能看到成功 / 无商机 / 失败统计。

> ⚠️ 自动话术**只用于第一次触达**；对方回复你之后，**请你自己手写跟进**，别用自动话术硬接——这是防封和成交的关键。

## 8. 进阶玩法

**📚 知识库（最重要）**
- 设置 → 知识库，把你的产品资料、真实数据、个人经历、话术模板都录进去，分角色打标签，还能导入导出、多产品独立。知识库越细，AI 越专业。

**🎯 线索管理（私域CRM，很多同类没有）**
- 评论扫出来的商机，一键进「获客清单」→ AI 画像分级（高/中/低意向）→ 生成一对一私信（首句会引用对方评论）→ 状态漏斗：待私信 → 已发送 → 已回复 → 已成交，全程可追。
- 私信前**请人工核对话术再发**，别无脑群发。

**💬 评论跟进**
- 通知页把纯时间戳的通知流按用户整理成聊天式对话，AI 判断该不该回、何时时机成熟做一次销售。铁律：自动话术只用于第一次，回评后手写。

**💧 一键灌水**
- 设置 → 一键灌水，配好关键词和调度参数，配合左侧搜索批量跑。

**🏢 多产品（全功能版专属）**
- 一个产品一个"租户"，配置 / 知识库 / 话术 / 获客记录整套隔离，顶部下拉秒切，房贷 + 宝妈 + 情感同跑互不干扰。

**🔀 多模型**
- 设置 → AI 配置，可在 DeepSeek / OpenAI / 通义 / 硅基流动间切换，日常用 DeepSeek 既快又省。用量、Token、成功率后台实时可查，成本透明。

## 9. 常见问题 FAQ

| 问题 | 解答 |
|---|---|
| 点了没反应？ | 确认当前标签页是**小红书网页**（`xiaohongshu.com`），扩展只在小红书页面生效。 |
| 生成话术失败？ | 回「设置 → AI 配置」点「测试连接」，检查 Key 有没有填错、余额够不够、网络通不通。 |
| 提示"授权已到期"？ | 联系我续期或换新包。 |
| 提示"账号校验未通过"？ | 打开小红书网页版，点右上角头像进入**本人「我的」主页**（有"编辑资料"的那页），保持打开再回来验证；非绑定号会锁。 |
| 提示"授权文件校验失败"？ | 安装包可能被动过，找我重新要一份。 |
| 关键词没全部搜？ | 一键灌水是按列表**顺序逐个**执行的，看当前进度是否第一个还没跑完。 |
| 会不会封号？ | 按真人节奏就基本没事；新号先养 1-2 周、一台机器一个号、一个号一天 ≤10 条、不走极端操作。 |
| AI 花多少钱？ | 一次话术约几百 Token，后台能实时看调用次数和 Token 用量，很省。 |

## 10. ⚠️ 风控红线 & 免责声明

**请一定遵守（防封号，也是成交之道）**
- 频率调低、间隔拉长并**随机化**；别同一篇反复刷、别新号一上来大批量。
